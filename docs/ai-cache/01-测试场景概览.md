# AI 缓存规则 - 测试场景概览

## 模块概述

AI 缓存规则模块负责 AI 网关应答缓存策略的集合级配置。该模块为**集合级**（非单条 CRUD）配置：`PUT /ai-cache-rules` 以整体替换语义提交全部规则，数组顺序即优先级顺序，首条命中生效。

本批次页面由**单表格页改为 Tab 双页**：「缓存规则」Tab（原集合级规则列表）与「语义设置」Tab（单例全局设置，独立接口 `GET/PUT /ai-cache-semantic-settings`）。规则新增「语义缓存」开关（规则集合内每条规则的语义缓存，默认关闭）。规则集合与语义设置为**两个独立接口**，生命周期解耦，不可耦合提交（清空规则不影响语义设置）。

|功能区域|说明|
|---|---|
|缓存规则 / 语义设置 Tab|页头为 Tab 双页；切换 Tab 后页头副标题与右上角按钮随 Tab 分叉（规则 Tab：进入/退出编辑模式 + 提交并生效；设置 Tab：编辑/取消/保存）|
|规则列表|展示规则名称、生效条件、缓存键策略、缓存 TTL、最大请求体、最大缓存值、语义缓存、操作 共 8 列；按数组顺序（优先级）展示|
|视图/编辑双模式|规则 Tab 支持视图模式与编辑模式切换；视图模式只读并可查看，编辑模式可新增/编辑/删除并「提交并生效」|
|新增与编辑|抽屉表单配置规则名称、生效条件、缓存键策略、缓存 TTL、最大请求体、最大缓存值、语义缓存（Switch）|
|查看|独立只读抽屉，纯文案展示 7 项字段（含语义缓存），无任何输入控件与必填标记|
|删除与清空|编辑模式下删除单条规则或清空全部规则，提交后整体生效|
|语义设置|单例全局设置，查看态纯文案展示 Top K / 相似度阈值 / 阈值比较关系；编辑态三字段表单；按钮「编辑 / 取消 / 保存」；缺行返回默认值对象|
|字段校验|对必填、长度、集合内唯一、可编译、取值范围进行前端校验；语义设置校验「Top K」1-10、「相似度阈值」0-2、「阈值比较关系」四枚举（大小写敏感）|

**导航路径**：路由管理 → 功能增强 → AI 缓存规则（页面路由名 `AICacheRule.list`）。

集合级写语义：无 `/{id}`、无分页、无 `enabled`/`priority` 字段；删除即从集合数组移除，`{"rules":[]}` 表示清空。

语义设置接口：`GET /ai-cache-semantic-settings`（缺行返回默认值对象 `{top_k:1, threshold:0.15, threshold_relation:"lt"}`）、`PUT /ai-cache-semantic-settings`（单例单行覆盖式 upsert）；`resource_type=ai_cache_semantic_settings`；响应含只读创建时间 / 更新时间（RFC3339），提交时忽略。

**核心变更依据**：

- 2026-10-12（变更记录 `modifications/2026-10-12-readonly-admin/ui-code-changes.md`）：引入「系统管理员（只读）」角色（后端以 `role` 枚举取代 `is_admin`，新增 `system_admin_readonly`）。只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**（实现为全局指令 `v-has`，只读登录态给元素加 `.v-has-hidden { display:none !important; }`），仅保留只读入口（查看 / 详情 / 查询）。`pages/ai-cache.html` 只读视角**保留「查看」**，**隐藏「添加规则 / 进入(退出)编辑 / 保存」**；「语义设置」Tab 的「编辑 / 保存」写入口一并隐藏。新增只读视角用例 AC-RO-01~03。
- 2026-10-22（变更记录 [2026-10-22-desc-bytes-and-cache-cond-unique/ui-code-changes.md](../../../ai-gateway-web/design-docs/modifications/2026-10-22-desc-bytes-and-cache-cond-unique/ui-code-changes.md)；接口契约 `ai-cache-rules.md` §1/§2.1/§2.2）：本轮两处契约变更落到本模块。**（A）`rules[].cond` 集合内唯一**——同一集合内不得重复（**逐字节比较**），重复时 `PUT` 返回 `422 Param Illegal: duplicate ai cache rule cond: <cond>` 且集合零变更；前端在「本地保存」时按 `name` 查重后再按 `cond` 查重（编辑排除自身），「提交并生效」时对整集合再做一次 `cond` 唯一校验，命中均提示「生效条件已存在，集合内必须唯一」、抽屉不关闭/不入集合、不发 `PUT`。**（B）逐规则时间戳不再返回**——响应**不返回** `rules[].created_at`/`rules[].updated_at`（整组替换语义），请求体携带这两个键按未知字段忽略，操作审计时间见 `GET /operation-logs`；旧口径「提交后重新 GET 回填只读时间」作废。**处置：只改既有用例、不新增编号** —— `cond` 唯一并入 AC-C-09 / AC-C-10 / AC-L-15 / AC-V-03，时间戳口径改写 AC-C-13 / AC-D-07 / AC-DEL-04 / AC-V-11。

## 配置顺序

AI 缓存规则不依赖其他模块的属主数据，可独立配置；但缓存规则的生效依赖网关侧的条件编译能力与缓存存储。

```text
进入 AI 缓存规则列表 → 「缓存规则」Tab → 查看/编辑模式切换 → 新增/编辑规则（本地草稿）
                                │
                                └── 提交并生效（PUT /ai-cache-rules 整体替换）
                                                │
                                                └── 重新 GET /ai-cache-rules 刷新集合（响应不含逐规则时间戳）

「语义设置」Tab → 编辑 → 保存（PUT /ai-cache-semantic-settings 单例覆盖，独立于规则集合）
```

- **集合级提交**：`PUT /ai-cache-rules` 单事务整体替换全部规则，后端对规则名称与生效条件 `cond` 做集合内唯一校验（均逐字节比较，重复即 `422`，集合保持原状）
- **优先级顺序**：数组顺序即匹配顺序，首条命中生效；新增规则默认置顶（数组头部）
- **缓存豁免**：缓存键策略为「缓存豁免（disabled）」命中时不读不写缓存并阻断后续规则
- **逐规则时间戳**：响应**不返回** `rules[].created_at`/`updated_at`，提交体也不携带（携带按未知字段忽略）；操作审计时间见 `GET /operation-logs`
- **语义设置独立性**：语义设置走独立单例接口 `PUT /ai-cache-semantic-settings`，与规则集合生命周期解耦，二者不可耦合提交（清空规则 `{"rules":[]}` 不影响语义设置）

## 测试数据准备

|数据类别|准备内容|用途|
|---|---|---|
|缓存规则集合|至少 2 条规则，含不同缓存键策略取值|列表展示、编辑、删除、排序|
|规则名称|`cache-rule-01`、`cache-rule-02`|唯一性、查重、回显|
|生效条件|`default_t()`、`req_path_in("/v1/chat/completions", false)` 等可通过编译且**互不相同**的表达式|校验、查重、回显|
|空集合|`{"rules": []}`|空列表、清空、提交|
|语义设置|默认值对象 `{top_k: 1, threshold: 0.15, threshold_relation: "lt"}`|查看/编辑/保存/校验/缺行回退|

- **规则名称**：1-128 字符，集合内唯一，示例 `cache-rule-01`
- **生效条件**：BFE 条件表达式，须能通过 `condition.Build` 编译，示例 `default_t()`；**集合内唯一（逐字节比较，不做 trim 归一）**。既有回归造数默认 `cond` 恒为 `req_path_in("/v1/chat/completions", false)`（`api/ai-cache-api-utils.js:166`），构造多条规则时**必须显式给出不同 `cond`**
- **缓存键策略**：`lastQuestion`（默认）/ `allQuestions` / `disabled`
- **缓存 TTL**：非负整数，0 表示不过期，示例 `0` / `3600`
- **最大请求体**：正整数，默认 `1048576`
- **最大缓存值**：正整数，默认 `1048576`
- **语义缓存**：布尔，默认 `false`；缓存键策略为「缓存豁免（disabled）」时被忽略（不报错）
- **逐规则时间戳**：响应**不返回** `created_at`/`updated_at`，提交体不携带（携带按未知字段忽略）；操作审计时间见 `GET /operation-logs`
- **语义设置**：单例，字段 Top K（整数 1-10，默认 1）、相似度阈值（浮点 0-2，默认 0.15）、阈值比较关系（`lt` 默认 / `lte` / `gt` / `gte`，大小写敏感）；响应另含只读创建时间 / 更新时间
