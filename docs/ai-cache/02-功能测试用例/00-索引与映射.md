# AI 缓存规则模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。验收文案以 **design 原型**（`prototype-design/pages/ai-cache.html`）与 `src/i18n/zh.js` 的 `aiCache` 命名空间为准。

本模块为**集合级**配置：接口仅 `GET /ai-cache-rules` 与 `PUT /ai-cache-rules`，无 `/{id}`、无分页、无 `enabled`/`priority`；数组顺序即优先级顺序，首条命中生效。字段校验依据 `design-docs/api-define/OpenAPI接口定义/ai-cache-rules.md` §1。页面为 **Tab 双页**：「缓存规则」（本集合级规则，8 列）+「语义设置」（单例全局设置，独立接口 `GET/PUT /ai-cache-semantic-settings`，见 [5. 语义设置](./05-语义设置.md#5-语义设置)）；规则集合与语义设置生命周期解耦，不可耦合提交。

- 02 用例文件内章节序号统一为 `## N. <章节名>`，与本索引「详细用例文件列表」一一对应；正文小节号与**用例编号后缀一致**（如 §6 = AC-RO-01 所在的第 6 章，§7.1 = AC-DR-01）。
- 用例编号前缀与来源：`AC-L`（列表与双模式 List）、`AC-C`（新增与编辑 Create/Edit）、`AC-D`（查看 Detail）、`AC-DEL`（删除与清空 Delete）、`AC-V`（字段校验 Validation）、`AC-S`（语义设置 Semantic）、`AC-RO`（只读管理员视角 Readonly）、**`AC-DR`（拖拽排序与离开拦截 Drag & Route-leave）**。
- `AC-DR` 于 2026-10-16 登记：取自本模块 07 章节「拖拽排序与离开拦截」，`DR` = Drag（拖拽排序）+ 离开（Route-leave）双语义；与路由管理 `RT-D`（规则详情/编辑）不同前缀，避免跨模块串号。
- 每个用例标题形如 `### AC-X-NN：<标题>`，标题本身即为页内锚点（本索引链接的 `#…` 与之对应，沿用各模块既有的 `#<编号>-<标题>` 连字符写法）。
