## 5. 语义设置

语义设置为**单例全局设置**，接口 `GET/PUT /ai-cache-semantic-settings`（`resource_type=ai_cache_semantic_settings`），单行覆盖式 upsert；与规则集合 `GET/PUT /ai-cache-rules` 为**独立接口**，生命周期解耦，不可耦合提交。字段校验依据 `design-docs/api-define/OpenAPI接口定义/ai-cache-semantic-settings.md` 与 `AICache/index.vue` 的 `semanticRules`。

> **接口契约 vs UI 编辑态（务必区分，避免「必填」歧义）**：
>
> - **接口契约（OpenAPI）**：Top K / 相似度阈值 / 阈值比较关系 三字段均为「**非必填**；未传时默认 `1` / `0.15` / `lt`」——API 层允许缺省并以默认值落库，用于程序化调用与接口级测试。
> - **UI 编辑态**：表单将三字段按**必填**渲染（rule `required: true` → label 前红色 `*`），且 `validInt` / `validFloat` / 枚举校验器对 `value === '' / null / undefined` 一律拦截，用户无法留空提交。
> - 二者**不矛盾**：接口级用例断言「缺省字段 → 默认值」，UI 用例断言「留空 → 校验拦截」。
