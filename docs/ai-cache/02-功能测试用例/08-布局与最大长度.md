> **背景（2026-11-02）**：项目无视觉回归测试（见 [覆盖缺口清单 §27](../../覆盖缺口清单.md)）。本文件用 **DOM 指标断言**（`utils/layout.js`）覆盖 AI 缓存规则满载（规则名 128）与长错误文案场景。

## AC-LAY-01 规则名满载行布局（P1）

- **测试数据**：mock 空集合 → 编辑模式 → 本地保存规则名 128 字符（不写后端）；afterEach `createAiCacheTestCleanup` 兜底重置为空规则集。
- **步骤**：
  1. 本地保存 128 字符规则名（表达式 `default_t()`）；
  2. 规则表格容器无横向溢出；
  3. 规则名单元格行数 ≤3 行，或 ellipsis 截切实效；
  4. 规则行高度 ≤ 单行基线（~47px）3 倍。
- **预期**：通过（2026-11-02 修复后真实通过）。
- **修复记录（2026-11-02）**：原缺陷——128 字符规则名折行约 10 行（scrollHeight=209px / lineHeight=21px，实测）。修复：`AICache/index.vue` 规则名列 `ellipsis: true` + render span `.cell-ellipsis` + `title` 悬浮全文。**同批缺陷**：EM-LAY-02 / PR-LAY-01 / RT-LAY-01 / TM-LAY-01（详见覆盖缺口清单 §二十七）。
- **自动化**：`tests/ai-cache/test_08_ai_cache_layout_max_length.spec.js`
