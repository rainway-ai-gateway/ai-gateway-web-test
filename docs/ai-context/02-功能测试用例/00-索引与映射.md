# AI 上下文压缩模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。验收文案以 **UI 源码**（`src/modules/AIContext/`）与 `src/i18n/zh.js` 的 `aiContext` 命名空间为准。

本模块含两个**相互独立**的接口：

- **压缩规则**为**集合级**配置：仅 `GET /ai-context-rules` 与 `PUT /ai-context-rules`，无 `/{id}`、无分页、无 `name`/`enabled`/`priority`；数组顺序即优先级顺序，首条命中生效；`{"rules": []}` 表示清空；响应**不返回**创建时间/更新时间。字段校验依据 `design-docs/api-define/OpenAPI接口定义/ai-context-rules.md` §1。
- **全局设置**为**单例**配置：`GET /ai-context-settings` 与 `PUT /ai-context-settings`（单行 upsert），共 8 个字段（含 `rewrite` 嵌套两项）；缺行时 GET 返回默认值对象（HTTP 200）。字段校验依据 `design-docs/api-define/OpenAPI接口定义/ai-context-settings.md` §1。

两个接口**不可耦合提交**：保存规则不得连带提交设置，反之亦然。
