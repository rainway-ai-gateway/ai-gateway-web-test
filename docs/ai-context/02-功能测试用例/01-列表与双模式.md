### AX-L-03：数组顺序即展示顺序

**功能模块**: 列表与双模式  
**优先级**: P0  
**用例编号**: AX-L-03

#### 前置条件

- 集合内存在至少 3 条规则，且生效条件互不相同

#### 测试步骤

1. 记录接口 `GET /ai-context-rules` 返回的规则集合数组顺序
2. 进入列表页，逐行读取「生效条件」列

3. 列表不做任何前端重排（无按条件/档位排序）

### AX-L-06：列表搜索与筛选

**功能模块**: 列表与双模式  
**优先级**: P1  
**用例编号**: AX-L-06  
**设计依据**: `src/modules/AIContext/index.vue` `buildRuleColumns`（`searchable` / `searchType:select`）；`ai-context-rules.md`（集合级接口无分页参数）

#### 前置条件

- 集合内存在生效条件可区分的多条规则，且包含不同压缩档位取值

#### 测试步骤

1. 进入列表页
2. 在「生效条件」列搜索框输入某条规则的生效条件关键字
3. 清空关键字，改用「压缩档位」列的下拉筛选，选择「裁剪 + lite 改写（balanced）」
4. 取消筛选，观察列表恢复

#### 预期结果

1. 搜索/筛选基于 `GET /ai-context-rules` 返回的集合数据在前端完成（集合级接口无分页参数）
2. 「生效条件」为文本搜索列（`searchable`），输入关键字后仅保留匹配行

4. 选择「裁剪 + lite 改写（balanced）」后仅保留该档位行，取消筛选后恢复全量
5. 无匹配时表格展示空数据状态

### AX-L-14：提交并生效

**功能模块**: 列表与双模式  
**优先级**: P0  
**用例编号**: AX-L-14  
**设计依据**: `ai-context-rules.md` §2.1 `PUT /ai-context-rules`；`src/i18n/zh.js` `aiContext.submitSuccess`

#### 前置条件

- 已进入编辑模式，且集合内规则均为合法数据（生效条件非空且集合内唯一）

#### 测试步骤

1. 在编辑模式修改或新增规则
2. 点击「提交并生效」
3. 观察请求与页面状态

#### 预期结果

1. 提交调用 `PUT /ai-context-rules`，请求体为 `{rules: [...]}`（整体替换语义，非单条更新）
2. 请求体规则集合与当前本地集合一致（`buildRulePayload` 基于本地集合克隆），数组顺序即优先级
3. 提交成功后提示「提交并生效成功！」（`submitSuccess`）
4. 页面自动回到视图模式（`rulesMode='view'`），并重新调用 `GET /ai-context-rules` 刷新列表
5. 请求体不含创建时间 / 更新时间（见 AX-C-10、AX-DEL-04）
