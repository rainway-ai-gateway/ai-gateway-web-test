### AX-D-01：查看抽屉纯文案展示

**功能模块**: 查看  
**优先级**: P0  
**用例编号**: AX-D-01  
**设计依据**: `src/modules/AIContext/index.vue`（`onViewRule`、查看 Drawer）；`src/modules/AIContext/components/RuleView.vue`；`src/i18n/zh.js` `aiContext.viewTitle/colCond/colMode/colMaxTokens/colReserveTokens`

#### 前置条件

- 页面处于视图模式，集合内存在至少 1 条规则

#### 测试步骤

1. 点击某行「查看」按钮
2. 观察抽屉标题与 4 行内容的 label 与取值

#### 预期结果

1. 打开 Drawer，标题为「查看压缩规则」（`aiContext.viewTitle`）
2. 内容为 `RuleView`，含 4 行 `info-row`，label 依次为：生效条件（`colCond`）、压缩档位（`colMode`）、预算上限（`colMaxTokens`）、预留输出（`colReserveTokens`）
3. 生效条件值使用等宽字体展示（`expression-value`），无值时展示 `-`
4. 抽屉宽度 `:width="60"`，遮罩可点击关闭（`:mask-closable="true"`）
5. `currentRule` 为该行 `cloneDeep` 快照

### AX-D-04：查看抽屉关闭与数据切换

**功能模块**: 查看  
**优先级**: P1  
**用例编号**: AX-D-04  
**设计依据**: `src/modules/AIContext/index.vue`（查看 Drawer `@on-close="currentRule = null"`；`v-if="viewVisible && currentRule"`）

#### 前置条件

- 集合内存在至少 2 条生效条件不同的规则

#### 测试步骤

1. 点击规则 A「查看」，打开抽屉
2. 关闭抽屉（点遮罩或关闭按钮）
3. 点击规则 B「查看」

3. `RuleView` 仅在 `viewVisible && currentRule` 为真时渲染，避免渲染空对象或旧数据
4. 关闭与重新打开过程无写请求，不影响集合

### AX-D-05：查看抽屉零值与空值展示

**优先级**: P1  
**用例编号**: AX-D-05

#### 前置条件

### AX-D-06：查看抽屉与列表展示数据同接口响应一致性-全字段核对

**功能模块**: 查看  
**优先级**: P1  
**用例编号**: AX-D-06  
**设计依据**: `ai-context-rules.md` §2.2（`GET /ai-context-rules` 返回结构）；`src/modules/AIContext/index.vue`（`fetchRules`、列表与抽屉同一集合数据源）

#### 前置条件

- `GET /ai-context-rules` 返回非空集合
- 保存完整响应 JSON 以便逐字段比对

#### 测试步骤

1. 记录 `GET /ai-context-rules` 响应中的 `Data.rules` 数组
2. 逐行核对列表「生效条件/压缩档位/预算上限/预留输出」列
3. 点击任一行「查看」，核对该规则 4 项展示值

#### 预期结果

1. 列表与查看抽屉的展示值均来源于同一次 `GET` 响应的对应元素
2. 生效条件、压缩档位文案一致；预算上限、预留输出格式化后一致
3. 数组顺序一致（列表第 N 行 ↔ 响应 `rules[N]`）
4. 响应**不含**创建时间/更新时间，UI 亦不展示；规则 `id` 不出现在响应中
