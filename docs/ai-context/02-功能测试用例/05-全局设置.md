## 5. 全局设置

> **接口契约 vs UI 编辑态（务必区分，避免「必填」歧义）**：
>
> - **接口契约（OpenAPI，`ai-context-settings.md`）**：8 字段（触发阈值 / 保留最近图片数 / 工具结果最大字符数 / thinking 块策略 / 文本估算系数 / 图片估值 token / 改写强度 / 保护 token 存活率）均为「**非必填**；未传时默认 `0.7` / `2` / `2000` / `trim-all-but-last` / `4` / `1200` / `lite` / `0.95`」——API 层允许缺省并以默认值落库，用于程序化调用与接口级测试。
> - **UI 编辑态**：`SettingsForm.vue` 将 8 字段按**必填**渲染（`ruleValidate` 中 `required: true` → label 前红色 `*`），且 `num = value => (value === '' || value === null || value === undefined ? NaN : Number(value))` 使空值经 `isNaN` 一律拦截，用户无法留空提交。
> - 二者**不矛盾**：接口级用例断言「缺省字段 → 默认值」，UI 用例断言「留空 → 校验拦截」。
