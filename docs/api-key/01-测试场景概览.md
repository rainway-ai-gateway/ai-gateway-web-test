# API-Key管理 - 测试场景概览

## 模块概述

API-Key管理模块负责创建、管理AI网关系统的API访问凭证，支持配置配额计划和限流策略，并挂载到特定的Entity上。创建后 Key 值仅显示前 10 位（脱敏展示）。

| 功能区域 | 说明 |
| --------- | ------ |
| API-Key列表 | 展示全部凭证，Key 脱敏展示，支持按 Key ID/Key值/描述/状态/配额类型/配额/限流状态/挂载Entity搜索与筛选 |
| API-Key创建 | 填写描述，可选过期时间、允许子网（含 IPv6）、允许模型，配置配额计划和限流策略，挂载 Entity |
| API-Key编辑 | 修改描述、配额计划、限流策略、挂载 Entity（支持 clearable 清除） |
| API-Key删除 / 重置配额 | 删除凭证（含确认/取消）、重置配额余额 |
| 配额与限流校验 | 配额总量边界、TPM/RPM 规则字段校验、RMB 单位配额（4 位小数、9000 万上界）、限流至少配置一项 |
| 详情页一致性 | 详情页全字段与接口数据一致（AKD-01） |

---

## 配置顺序

API-Key 处于配置链路**末端**，依赖 Entity 类型与 Entity 组织：

```text
Entity类型管理 → Entity组织管理 → API-Key管理
```

- 挂载 Entity 需先创建 Entity（EM-E-02）
- E2E 全流程（EM-K-30）依赖类型与组织配置，自动化见 [Entity管理模块场景四](../entity-management/01-测试场景概览.md#场景四跨模块场景串联journey) EM-J-01

## 场景测试设计

本模块采用**场景测试**方法，从真实用户的使用流程出发，模拟管理员为内部程序或外部用户创建API访问凭证的完整操作。

### 场景三：管理员配置API-Key

**场景描述**：管理员为内部程序或外部用户创建API访问凭证，配置配额和限流策略，并挂载到特定的Entity上。

**涉及测试场景**：

| 步骤 | 操作 | 对应场景编号 | 优先级 |
| ------ | ------ | ------------ | -------- |
| 1 | 进入API-Key管理页面，查看列表及Key脱敏展示 | EM-K-01、EM-K-19 | P1/P0 |
| 2 | 打开创建表单，验证默认值 | EM-K-20 | P0 |
| 3 | 点击"添加"，填写描述，创建API-Key | EM-K-02 | P0 |
| 4 | 验证描述必填校验 | EM-K-03 | P1 |
| 5 | 配置过期时间、允许子网（含IPv6）、允许模型 | EM-K-21~EM-K-23 | P0/P1 |
| 6 | 创建带配额计划和限流策略的API-Key，验证边界与联动 | EM-K-04~EM-K-05、EM-K-24~EM-K-26 | P0 |
| 7 | 创建挂载Entity和不挂载Entity的API-Key | EM-K-06~EM-K-07 | P0/P1 |
| 8 | 创建无限配额和带过期时间的API-Key | EM-K-08 | P1 |
| 9 | 创建过程中取消操作 | EM-K-09 | P1 |
| 10 | 按Key ID、Key值、描述、状态、配额类型、配额、限流状态、挂载Entity筛选API-Key | EM-K-10~EM-K-12、EM-K-15b/15c | P1 |
| 11 | 编辑API-Key，验证数据回填，修改描述/配额/挂载 | EM-K-13~EM-K-14、EM-K-27 | P1/P0 |
| 12 | 点击行查看API-Key详情 | EM-K-28 | P1 |
| 13 | 删除API-Key（含确认/取消） | EM-K-17 | P0 |
| 14 | 重置API-Key配额余额及校验 | EM-K-18、EM-K-29 | P1 |
| 15 | E2E：创建→编辑→重置配额→删除（自动化见 EM-J-01） | EM-K-30 | P0 |
| 16 | 配额/并发边界校验（小数、上界、下界） | EM-K-26~EM-K-28、EM-K-31、EM-K-44 | P0 |
| 17 | TPM/RPM 规则字段校验（必填、范围、上界） | EM-K-32~EM-K-48 | P0 |
| 18 | TPM/RPM 组合重复、规则名称长度 | EM-K-49~EM-K-51 | P0/P1 |
| 19 | RMB 单位配额小数校验、4 位小数边界、total_token 必须整数 | EM-K-52~EM-K-54 | P0 |
| 20 | RMB 单位配额详情展示、列表用量展示 | EM-K-55~EM-K-56 | P0/P1 |
| 21 | RMB 配额 9000 万上限与边界校验 | EM-K-57、EM-K-58、EM-K-60 | P0/P1 |

**测试目标**：验证管理员能否顺利创建、编辑、删除API-Key，配额和限流策略配置是否正常，挂载Entity功能是否正常，支持 RMB 单位配额（小数精度、展示）。

> **说明**：系统不提供列表内禁用/启用 API-Key 操作（无 EM-K-15/16）。

### 场景六：详情页全字段一致性验证（API-Key）

**场景描述**：验证 API-Key 详情页展示的每一个字段都与接口返回的数据一致，覆盖基本信息、配额信息、限流信息、时间信息等所有字段。

**涉及测试场景**：

| 步骤 | 操作 | 对应场景编号 | 优先级 |
| ------ | ------ | ------------ | -------- |
| 1 | 创建带完整配置的 API-Key（配额 + 限流 + 挂载 Entity）→ 编辑触发 update_time → 验证详情页所有字段（含 RMB 单位动态展示） | AKD-01 | P0 |

**测试目标**：验证详情页字段与接口数据的一致性，包括：

- 基本信息：描述、Key ID、Key 值（前 10 位）、状态、挂载 Entity
- 配额信息：无限配额、配额总量、已使用、剩余量、配额单位（支持 RMB 单位动态展示）、重置周期
- 限流信息：限流状态、TPM 规则、RPM 规则
- 时间信息：创建时间、更新时间（Bug 1.1 检测）

> Entity Org 侧详情一致性用例（EOD-01）见 [Entity组织管理](../entity-management/02-功能测试用例/07-详情页一致性验证.md)。

### 变更回归：限流规则名称校验（EM-CV-05~08）

**变更描述**：限流规则（TPM/RPM）`name` 校验变更——长度 1–128；字符集 `[a-zA-Z0-9_-]`；同一策略内不能重复；**创建后不可修改**。

**涉及测试场景**：

| 用例编号 | 用例名称 | 优先级 |
| --------- | --------- | -------- |
| EM-CV-05 | 限流规则 name-字符集校验 | P0 |
| EM-CV-06 | 限流规则 name-长度边界（1–128） | P1 |
| EM-CV-07 | 限流规则 name-同策略内唯一 | P0 |
| EM-CV-08 | 限流规则 name-创建后不可修改 | P1 |

> 用例正文见 [05-变更回归-名称校验](./02-功能测试用例/05-变更回归-名称校验.md)。该组用例同时覆盖 Entity 组织侧（见 [Entity管理模块](../entity-management/02-功能测试用例/08-变更回归-名称校验.md)）。
