# API-Key管理 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中场景三、场景六（AKD）与变更回归的**功能拆解与详细描述**。

> 本模块为 Entity管理模块拆分出的独立子模块；跨模块场景（Journey/E2E）与字段校验矩阵见 [Entity管理模块索引](../../entity-management/02-功能测试用例/00-索引与映射.md)。
> 用例编号沿用 Entity管理模块场景三编号（EM-K-xx）。

## 与场景概览的映射关系
