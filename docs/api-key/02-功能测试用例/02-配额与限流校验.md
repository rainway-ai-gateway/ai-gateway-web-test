### 3.32 TPM/RPM 规则字段校验

**功能模块**: API-Key管理  
**优先级**: P0  
**用例编号**: EM-K-32 ~ EM-K-43  
**自动化**: `test_03_api_key_rate_limit_fields.spec.js`

#### 前置条件

- 已登录并进入 API-Key 管理
- 创建 API-Key 表单中**启用限流 = 是**，并已添加对应 TPM/RPM 规则行

> **序号说明**：同 [§2.26](#226-tpmrpm-规则字段校验)；API-Key 文案为「第 **n** 条规则…」（不含 TPM/RPM 前缀）。

#### 校验矩阵

1. **EM-K-32 · TPM 规则名称**：输入留空 → 预期「第{n}条规则名称不能为空」
2. **EM-K-33 · TPM 时间窗口(分)**：输入 `0` → 预期「第{n}条规则时间窗口范围为1-360分钟」
3. **EM-K-34 · TPM 时间窗口(分)**：输入 `361` → 预期「第{n}条规则时间窗口范围为1-360分钟」
4. **EM-K-35 · TPM 滑动步长(分)**：输入 `0` → 预期「第{n}条规则滑动步长范围为1-360分钟」
5. **EM-K-36 · TPM 滑动步长(分)**：输入 `361` → 预期「第{n}条规则滑动步长范围为1-360分钟」
6. **EM-K-37 · TPM 最大Token数**：输入 `0` → **允许为 0**（合法下界；见 test_03_api_key_rate_limit_fields）
7. **EM-K-38 · TPM 最大Token数**：输入 `9223372036854775808` → 预期「第{n}条规则最大Token数超出允许范围」
8. **EM-K-39 · RPM 规则名称**：输入留空 → 预期「第{n}条规则名称不能为空」
9. **EM-K-40 · RPM 时间窗口(分)**：输入 `0` → 预期「第{n}条规则时间窗口范围为1-360分钟」
10. **EM-K-41 · RPM 时间窗口(分)**：输入 `361` → 预期「第{n}条规则时间窗口范围为1-360分钟」
11. **EM-K-42 · RPM 最大请求数**：输入 `0` → **允许为 0**（合法下界；见 test_03_api_key_rate_limit_fields）
12. **EM-K-43 · RPM 最大请求数**：输入 `9223372036854775808` → 预期「第{n}条规则最大请求数超出允许范围」

#### 字段取值约定

与 [EM-E-26~EM-E-37](#226-tpmrpm-规则字段校验) 一致；API-Key 错误文案使用「第{n}条规则…」格式。
