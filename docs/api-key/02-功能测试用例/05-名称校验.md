## 7. 限流规则名称校验（2026-08-24 / 08-25）

> 变更背景：
>
> **限流规则（TPM / RPM）`name` 校验变更**：长度 1–128；字符集限制为 `[a-zA-Z0-9_-]`；同一 `RateLimitPolicy` 内不能重复；**创建后不可修改**（编辑时名称禁用）。
>
> 接口依据：`00-common.md` §17 EntityName、§10 TPMConfig、§11 RPMConfig；`entities.md` §2.1 创建约束。
>
> 本文件为 API-Key 模块副本（Entity 组织模块的对应用例见 [entity-management 08-名称校验](../../entity-management/02-功能测试用例/08-名称校验.md)）。

### EM-CV-05：限流规则 name-字符集校验

**功能模块**: 名称校验  
**优先级**: P0  
**用例编号**: EM-CV-05

#### 前置条件

- 打开创建 / 编辑 API-Key，启用限流策略并添加 TPM / RPM 规则

#### 测试步骤

依次输入以下规则名称并触发校验：

1. `tpm_1min`、`Tpm-1min`、`rpm_2024` → 预期通过（`[a-zA-Z0-9_-]`）
2. `tpm 1min`、`tpm.1min`、`tpm@1`、`tpm中文` → 预期**拦截**（仅允许 `[a-zA-Z0-9_-]`）

#### 预期结果

- 规则名称字符集限制为 `[a-zA-Z0-9_-]`；含空格 / `.` / `@` / 中文等字符拦截并提示
- 与 `00-common.md` §10/§11 一致

### EM-CV-07：限流规则 name-同策略内唯一

**功能模块**: 名称校验  
**优先级**: P0  
**用例编号**: EM-CV-07

#### 前置条件

- 打开创建 / 编辑 API-Key，已添加一条 TPM 规则 `tpm_1min`

#### 测试步骤

1. 再添加一条 TPM 规则，名称同样填 `tpm_1min`
2. 提交

#### 预期结果

- 同一 `RateLimitPolicy` 内规则名称不能重复；重复时拦截并提示（TPM 内与 RPM 内分别唯一）

### EM-CV-08：限流规则 name-创建后不可修改

**功能模块**: 名称校验  
**优先级**: P1  
**用例编号**: EM-CV-08

#### 前置条件

- 存在一条已创建、含限流规则（TPM / RPM）的 API-Key 记录

#### 测试步骤

1. 编辑该记录，进入限流策略配置
2. 尝试修改已有规则的名称字段

#### 预期结果

1. 已有规则的名称字段**只读 / 禁用**（创建后不可修改）
2. 可修改规则的其他字段（model、window_minutes、max_tokens/max_requests、step_minutes）
3. 新增规则的名称可输入
