# 批量任务（Batch Tasks）模块 - 测试场景概览

## 模块概述

批量任务模块提供系统管理员对 provider 原生 OpenAI Batch API（`/v1/files` + `/v1/batches`）透传任务的**只读管控 + 取消**能力，对应接口端点：`GET /batches`（列表）、`GET /batches/{batch_id}`（详情）、`POST /batches/{batch_id}/cancel`（取消）、`GET /batch-files/{file_id}?provider=`（文件元数据）。

**一期范围**：仅管控（列表 / 详情 / 取消 / 文件元数据查询），**不包含批量任务的创建**（创建走 provider 透传，不经控制面），因此页面**无「新建」入口**。

对应接口文档：`design-docs/api-define/OpenAPI接口定义/batches.md`；对应原型：`design-docs/prototype-design/pages/batches.html`。

| 功能区域 | 说明 |
| --- | --- |
| 批量任务列表 | 筛选栏（任务状态 / 服务商 / API Key ID / 创建时间起止）+ **主键游标分页**（`cursor` / `limit` / `next_cursor`）表格；列 = 批量任务ID / 服务商 / API Key ID / Entity ID / 状态(tag) / 请求计数 / 用量 / 预留金额 / 结算金额 / 结算状态(tag) / 创建时间 / 操作（详情 / 取消） |
| 批量任务详情 | 右侧抽屉（70% 宽），5 个 panel 卡片：基本信息 / 状态与计数 / 用量与记账 / 文件与时间 / 批量文件（含 `batch_files` 表格） |
| 取消批量任务 | 二次确认后 `POST /batches/{batch_id}/cancel`，置 `status=cancelling` + `settle_status=released`；终态任务取消按钮 `disabled` |
| 权限 | Feature `FeatureBatch` + `ActionRead`（列表 / 详情 / 文件查询）、`ActionCancel`（取消，写 operation_logs） |

**核心变更依据**（2026-10-10 UI 变更，变更记录 `modifications/2026-10-10-batch-tasks-and-key-reencrypt/ui-code-changes.md`）：

- v0.11.0 首次引入批量任务模块（列表 / 详情 / 取消 / 文件元数据 4 接口）。
- 列表采用**主键游标分页**（`cursor` / `limit` / `next_cursor`），**不使用**全局通用 `page` / `page_size` 分页参数。
- 金额字段（`reserve_units` / `settle_units`）为 **1e-8 定点整数**（单位 RMB），UI **原样展示，不做 ÷1e8 换算**。
- `product_name` 由认证中间件**强制注入**，只读展示。
- 一期**不含创建**；取消依赖控制面 → provider **出网**可达，无出网时取消退化为不可用（502）。
- 菜单入口：「消费者管理」（`consumer.admin.list`）下新增「批量任务」（`BatchTask.list`），位于「API Key」后、「Entity」前。
- 2026-10-12：引入「系统管理员（只读）」角色（`role` 枚举取代 `is_admin`，新增 `system_admin_readonly`）；只读视角**全站隐藏写操作按钮**，仅保留只读入口，前端由全局 Vue 指令 `v-has` 实现。批量任务页（`pages/batches.html`）只读仅保留「详情」，隐藏「取消任务」。

## 配置顺序 / 依赖关系

批量任务为**管控 / 审计类模块**，不阻塞其他模块配置，但其数据由数据面透传产生、其取消依赖出网：

```text
provider 侧批任务创建（透传，不经控制面）
        │ 数据面记账（预留 / 结算）
        ▼
批量任务列表 / 详情 / 文件元数据查询
        │ 出网可达时
        ▼
取消批量任务（POST cancel → provider cancel 端点）
```

| 关系 | 说明 |
| --- | --- |
| 数据面透传 → 批量任务记录（**被动依赖**） | 批量任务由 provider 透传创建并记账；控制面仅管控，无创建入口 |
| 批量任务 → API Key / Entity（**弱引用**） | 列表按 `api_key_id` / `entity_id` 过滤；不校验其存在性（软关联） |
| 取消 → provider 出网（**强前置**） | 降级部署无出网时 `POST cancel` 退化为不可用（502），任务仅支持展示 |

## 场景测试设计

### 场景一：管理员查看批量任务列表

**场景描述**：系统管理员进入批量任务列表页，使用筛选栏定位任务，通过游标分页浏览，核对表格列与金额口径。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 进入批量任务列表页，验证列表加载与游标分页参数 | BT-L-01 | P0 |
| 2 | 按任务状态筛选（单值枚举） | BT-L-02 | P0 |
| 3 | 按服务商筛选 | BT-L-03 | P1 |
| 4 | 按 API Key ID 筛选（回车触发） | BT-L-04 | P1 |
| 5 | 按创建时间范围筛选（起 / 止 + 查询） | BT-L-05 | P1 |
| 6 | 组合筛选（状态 + 服务商 + 时间） | BT-L-06 | P2 |
| 7 | 重置筛选条件 | BT-L-07 | P1 |
| 8 | 表格 12 列展示，状态 / 结算状态 Tag 颜色正确 | BT-L-08 | P0 |
| 9 | 金额列原样展示 1e-8 定点整数（不换算） | BT-L-09 | P0 |
| 10 | 上一页 / 下一页游标翻页与按钮置灰 | BT-L-10 | P1 |
| 11 | 空列表展示 | BT-L-11 | P2 |
| 12 | 列表接口数据与页面展示一致性 | BT-L-12 | P0 |

**测试目标**：验证列表游标分页、筛选、列展示与金额口径与接口定义一致。

### 场景二：管理员查看批量任务详情

**场景描述**：管理员在列表点击「详情」，打开右侧抽屉（70% 宽），核对 5 个 panel 卡片字段与 `batch_files` 表格。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 点击「详情」打开抽屉（标题「批量任务详情」） | BT-D-01 | P1 |
| 2 | 详情 5 卡片字段与接口数据一致 | BT-D-02 | P0 |
| 3 | 批量文件表格展示（file_id / provider / purpose / filename / bytes+格式化 / created_at） | BT-D-03 | P1 |
| 4 | 无批量文件时显示「-」 | BT-D-04 | P2 |
| 5 | `sync_source=redis`（回源）时结算类字段未就绪不报错 | BT-D-05 | P1 |
| 6 | 详情 404（任务不存在或已清理）给可读提示 | BT-D-06 | P1 |
| 7 | 关闭抽屉（遮罩 / X） | BT-D-07 | P2 |
| 8 | 详情接口数据与页面展示一致性 | BT-D-08 | P0 |

**测试目标**：验证详情抽屉字段完整性与接口一致，条件字段（空值 / 回源）正确展示。

### 场景三：管理员取消批量任务

**场景描述**：管理员对非终态任务发起取消，验证二次确认、状态流转、终态置灰与错误边界（409 / 502 / 404）。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 点击「取消」弹出二次确认 | BT-C-01 | P1 |
| 2 | 确认取消成功，`status=cancelling`、`settle_status=released` | BT-C-02 | P0 |
| 3 | 终态任务取消按钮 `disabled`（`title="终态任务不可取消"`） | BT-C-03 | P0 |
| 4 | 取消 409（已终态 / 他实例处理中）提示 | BT-C-04 | P1 |
| 5 | 取消 502（provider 不可达 / 无出网）提示 | BT-C-05 | P1 |
| 6 | 取消 404（任务不存在或已清理）提示 | BT-C-06 | P2 |

**测试目标**：验证取消交互、状态流转与错误边界与接口 §3.3 一致。

### 场景四：只读管理员视角（写操作隐藏）

**场景描述**：以「系统管理员（只读）」登录，验证批量任务页（列表 + 详情）所有写操作入口（取消）被隐藏、仅保留只读「详情」入口与只读控件（筛选 / 查询 / 重置 / 翻页）。

| 步骤 | 操作 | 对应编号 | 优先级 | 生命周期 |
| --- | --- | --- | --- | --- |
| 1 | 只读视角列表工具栏无任何写入口，只读控件（筛选 / 查询 / 重置）保留 | BT-RO-01 | P0 | 草案 |
| 2 | 只读视角列表操作列「取消」隐藏、「详情」保留 | BT-RO-02 | P0 | 草案 |
| 3 | 只读视角详情抽屉为纯只读，无任何写入口 | BT-RO-03 | P0 | 草案 |

**测试目标**：验证只读视角下批量任务页写操作（取消）全部隐藏、只读「详情」入口保留，与变更记录 §3.4（`pages/batches.html` 只读仅保留「详情」）一致。

## 测试数据准备

| 数据类别 | 准备内容 | 用途 |
| --- | --- | --- |
| 非终态任务 | 数据面透传创建后处于 `in_progress` 等状态 | BT-C-01 / BT-C-02 |
| 终态任务 | `completed` / `cancelled` 等 | BT-C-03 / BT-L-08 |
| 含文件任务 | `batch_files` 有 `batch_input` / `batch_output` 元素 | BT-D-03 |
| 无文件任务 | `batch_files` 为空数组 | BT-D-04 |
| 回源任务 | `sync_source=redis`、结算字段未就绪 | BT-D-05 |
| 分页数据 | ≥ 2 页（每页 20 条，`PAGE_LIMIT=20`） | BT-L-01 / BT-L-10 |

**字段取值约定**（以 `batches.md` §2.1 / §2.2 为准）：

- **`status`**：`validating` / `queued` / `in_progress` / `finalizing` / `completed` / `expired` / `failed` / `cancelled` / `cancelling`；终态 = `completed` / `expired` / `failed` / `cancelled`。
- **`settle_status`**：`reserved`（已预留）/ `settled`（已结算）/ `released`（已释放）。
- **`usage_source`**：`download`（输出文件下载回读）/ `reconcile`（对账）。
- **`sync_source`**：`redis`（BATCH_TASK 回源）/ `log`（日志对账落库）。
- **`reserve_units` / `settle_units`**：1e-8 定点整数（单位 RMB），原样展示。
- **`next_cursor`**：空串表示无更多数据。
- **`batch_files[].purpose`**：`batch_input` / `batch_output` 等 provider 枚举。
