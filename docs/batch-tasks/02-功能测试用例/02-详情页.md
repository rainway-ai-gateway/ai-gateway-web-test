### BT-D-02：详情字段完整性与接口数据一致

**功能模块**: 批量任务详情
**优先级**: P0
**用例编号**: BT-D-02
**OpenAPI**: `GET /batches/{batch_id}`

#### 前置条件

1. 存在字段齐全的批量任务（含 `batch_files`）。
2. 已打开该任务详情抽屉。

#### 测试步骤

1. 核对「基本信息」卡片字段。
2. 核对「状态与计数」卡片字段。
3. 核对「用量与记账」卡片字段。
4. 核对「文件与时间」卡片字段。
5. 逐项与接口返回数据比对。

#### 预期结果

1. 「基本信息」含：批量任务ID（`batch_id`）、服务商（`provider`）、API Key ID（`api_key_id`）、Entity ID（`entity_id`）、产品名称（`product_name`）、透传端点（`endpoint`）。
2. 「状态与计数」含：状态（Tag）、请求总数（`request_counts.total`）、已完成请求数（`request_counts.completed`）、失败请求数（`request_counts.failed`）、估算行数（`est_lines`）。
3. 「用量与记账」含：输入 token 数（`usage_input_tokens`）、输出 token 数（`usage_output_tokens`）、用量来源（`usage_source`）、预留金额（`reserve_units`，1e-8 定点整数 RMB，原样展示不做 ÷1e8 换算）、结算金额（`settle_units`，同口径）、结算状态（`settle_status`）、预留结余（`over_reserved`）、同步来源（`sync_source`）。
4. 「文件与时间」含：输入文件ID（`input_file_id`）、输出文件ID（`output_file_id`）、创建时间（`created_at`）、更新时间（`updated_at`）、终结时间（`terminal_at`）。
5. 全部展示值与接口返回逐项一致；`product_name` 只读展示。
6. 详情抽屉内**无任何帮助图标**：2026-10-20 UI 改版已移除全部「?」图标（DOM 中不存在 `span[title]` 与 `.batch-help-icon`）。

#### 测试数据

- 字段口径见 `batches.md` §2.1

### BT-D-03：批量文件表格展示

**功能模块**: 批量任务详情
**优先级**: P1
**用例编号**: BT-D-03
**OpenAPI**: `GET /batches/{batch_id}`（`batch_files`）

1. 打开详情，定位「批量文件」卡片。
2. 核对表头与行数据。
3. 核对文件大小列的格式化展示。

#### 预期结果

1. 「批量文件」卡片为表格，列含：文件ID（`file_id`）、服务商（`provider`）、用途（`purpose`）、文件名（`filename`）、大小（`bytes`，单位字节）、创建时间（`created_at`）。
2. 每行与 `batch_files` 元素一一对应；`purpose` 展示 provider 枚举值（如 `batch_input` / `batch_output`）。
3. 大小列以格式化单位展示（如 `1.00 MB`），与原始 `bytes` 一致。

#### 测试数据

- **`purpose`**：`batch_input` / `batch_output` 等
- **`bytes`**：字节数（≥0）

#### 测试步骤

1. 打开目标任务详情抽屉，抓取 `GET /batches/{batch_id}` 的完整返回体。
2. 逐卡片比对「基本信息」「状态与计数」「用量与记账」「文件与时间」的字段展示值。
3. 比对「批量文件」表格的逐行逐项展示值。
4. 逐一核对所有展示值与接口返回 JSON 的对应字段。

#### 预期结果

布局说明：详情页由「基本信息」「状态与计数」「用量与记账」「文件与时间」「批量文件」5 个 Card 组成。

字段比对（校验方式 = 文本一致 / 数值一致 / 数组逐项比对 / 时间戳转换一致，与接口返回 JSON 一致）：

- 基本信息
  - **batch_id**（文本一致）：与接口 `batch_id` 相同
  - **provider**（文本一致）：与接口 `provider` 相同
  - **api_key_id**（文本一致）：与接口 `api_key_id` 相同
  - **entity_id**（文本一致）：与接口 `entity_id` 相同
  - **product_name**（文本一致，只读）：与接口 `product_name` 相同
  - **endpoint**（文本一致）：与接口 `endpoint` 相同
- 状态与计数
  - **status**（文本一致，含中文（枚举）映射）：状态 Tag 文案与接口 `status` 映射一致，如 `completed` → 「已完成（completed）」
  - **request_counts.total**（数值一致）：请求总数与接口 `request_counts.total` 相同
  - **request_counts.completed**（数值一致）：已完成请求数与接口 `request_counts.completed` 相同
  - **request_counts.failed**（数值一致）：失败请求数与接口 `request_counts.failed` 相同
  - **est_lines**（数值一致）：估算行数与接口 `est_lines` 相同
- 用量与记账
  - **usage_input_tokens**（数值一致）：输入 token 数与接口 `usage_input_tokens` 相同
  - **usage_output_tokens**（数值一致）：输出 token 数与接口 `usage_output_tokens` 相同
  - **usage_source**（文本一致，枚举语义）：用量来源与接口 `usage_source` 相同（如 `download`）
  - **reserve_units**（数值一致，1e-8 定点整数原样展示）：预留金额与接口 `reserve_units` 原样相同（不做 ÷1e8 换算）
  - **settle_units**（数值一致，1e-8 定点整数原样展示）：结算金额与接口 `settle_units` 原样相同（不做 ÷1e8 换算）
  - **settle_status**（文本一致，含中文（枚举）映射）：结算状态 Tag 文案与接口 `settle_status` 映射一致，如 `settled` → 「已结算（settled）」
  - **over_reserved**（文本一致，布尔原样展示）：预留结余与接口 `over_reserved` 相同（如 `false`）
  - **sync_source**（文本一致，枚举语义）：同步来源与接口 `sync_source` 相同（如 `log`）
- 文件与时间
  - **input_file_id**（文本一致）：输入文件ID 与接口 `input_file_id` 相同
  - **output_file_id**（文本一致）：输出文件ID 与接口 `output_file_id` 相同（未完成时为空则以占位展示）
  - **created_at**（时间戳转换一致）：创建时间与接口 `created_at`（RFC3339）转换后的日期时间一致
  - **updated_at**（时间戳转换一致）：更新时间与接口 `updated_at`（RFC3339）转换后的日期时间一致
  - **terminal_at**（时间戳转换一致）：终结时间与接口 `terminal_at`（RFC3339）转换后的日期时间一致（未终结为空则以占位展示）
- 批量文件（数组逐项比对，逐行逐项；表格行数 = `batch_files` 元素个数）
  - **batch_files[].file_id**（文本一致）：文件ID 列与对应元素 `file_id` 相同
  - **batch_files[].provider**（文本一致）：服务商列与对应元素 `provider` 相同
  - **batch_files[].purpose**（文本一致，provider 枚举原样）：用途列与对应元素 `purpose` 相同（如 `batch_input` / `batch_output`）
  - **batch_files[].filename**（文本一致）：文件名列与对应元素 `filename` 相同
  - **batch_files[].bytes**（数值一致）：大小列展示 `bytes（格式化）`，原始字节数与对应元素 `bytes` 相同
  - **batch_files[].created_at**（时间戳转换一致）：创建时间列与对应元素 `created_at`（RFC3339）转换后的日期时间一致
