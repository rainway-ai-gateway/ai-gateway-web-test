## 2f. 只读视角

> 本章验证「系统管理员（只读）」（`role === "system_admin_readonly"`）登录后，AI 业务集群模块的写操作入口被隐藏、只读查看能力保留。
>
> 前端统一采用全局自定义指令 `v-has`：只读登录态下指令给元素加 `.v-has-hidden` 类（`display:none !important`）；表单挂 `v-has`，render 操作列用 `directives: [{ name: 'has' }]`。后端以角色强制（写操作返回 `403`）。
>
> 设计依据：`design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md`；接口依据：`auth.md`（`role` 枚举）。

---

### RM-BC-RO-01：只读管理员视角-写按钮隐藏

**功能模块**: AI业务集群  
**优先级**: P1  
**用例编号**: RM-BC-RO-01  
**设计依据**: `modifications/2026-10-12-readonly-admin/ui-code-changes.md`（§3.4 全站写按钮隐藏统一模式；`cluster-list.html` / `cluster-wizard.html`）；UI `src/utils/directive.js` 全局指令 `has`  
**OpenAPI**: `clusters.md`（写端点由后端按角色强制 `403`）

#### 前置条件

- 已存在只读账号（原型用户名 `viewer`，`role = system_admin_readonly`）
- 已存在系统管理员账号（原型 `admin`，`role = system_admin`）用于对照

#### 测试步骤

1. 以只读账号（`viewer`）登录，进入 AI 业务集群**列表页**
2. 观察工具栏按钮与列表操作列按钮
3. 点击某集群的「详情」，确认只读查看入口可用
4. 进入创建（或编辑）集群向导，观察向导底部按钮
5. 退出，改以系统管理员（`admin`）登录，重复步骤 1~4 对照

#### 预期结果

1. 只读视角列表页**隐藏**「添加集群」按钮；操作列**仅保留「详情」**，编辑 / 删除按钮隐藏
2. 只读视角向导内**隐藏「提交」**按钮，保留「下一步」「取消」
3. 只读视角「详情」可正常打开，只读查看能力保留、无写按钮残留
4. 系统管理员视角上述写按钮（添加集群 / 编辑 / 删除 / 提交）全部正常显示
5. 隐藏通过 `.v-has-hidden`（`display:none !important`）实现，与 `v-show` 共存不冲突；写操作在接口层由后端按角色返回 `403` 强制

#### 测试数据

- 只读账号：`viewer`（`role = system_admin_readonly`）
- 管理账号：`admin`（`role = system_admin`）

#### 补充说明

- 只读角色复用 admin 菜单（`nav key` 由 `role` 派生为 `admin_readonly`），页面可读
- 本次为「全站隐藏写按钮」，覆盖后端设计原「仅示范页隐藏、其余二期」的约定
- `role` 枚举取代旧 `is_admin`（bool），前端不做 `is_admin` 回退
