### BC-E-04：Provider 侧移除被引用 Key 被 409 拦截，集群回显完整

**优先级**: P1  
**设计依据**: 后端 `ProviderKeyRefChecker`（事务内回滚）；providers `PR-LINK-05` 的集群侧视角补位

#### 前置条件

- Provider A：模型 M1/M2、Key K1（集群引用 M1 与 K1，权重 100）

#### 测试步骤

1. `PATCH /providers/{name}` 尝试把 `keys` 置空
2. 读取服务商 Keys
3. 打开集群编辑向导第 4 步、查看详情页

#### 预期结果

1. PATCH 被拒，`ErrNum=409`（`Conflict: ... referenced by cluster ...`）
2. 服务商 Keys 未被移除（事务回滚）
3. **集群编辑回显完整**：所属服务商 = Provider A、转发模型 = M1、Keys 行 = K1/100；详情页「服务鉴权 Keys」表格 = K1/100
4. 与 providers `PR-LINK-05` 的差异：本用例的断言在集群侧 UI（编辑回显 + 详情表格），providers 侧只断言 API 引用不变

**未覆盖说明**：Provider 侧**移除被引用模型**的行为产品未定义（后端可能允许，届时集群编辑会因 `syncFormWithProvider` 把模型过滤为空）；待产品确认后补断言，当前不臆造预期。
