## 模块概述

证书管理模块负责 HTTPS 证书的上传与管理，是路由转发的安全前置依赖。

| 功能区域 | 说明 |
| --------- | ------ |
| **证书列表** | 展示证书名称、默认标识、过期时间；支持按名称/过期时间搜索 |
| **添加证书** | 上传证书与私钥文件，填写名称与描述；过期时间上传后自动预览 |
| **删除证书** | 删除非默认证书；默认证书删除按钮禁用 |
| **全局缺省证书** | 下拉切换默认证书 |

**路由**：`/cert`

## 核心变更依据

- [2026-10-12 只读管理员（系统管理员·只读）](../../../ai-gateway-web/design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md)：后端引入「系统管理员（只读）」角色（`role` 枚举取代 `is_admin`，新增 `system_admin_readonly`）；只读视角**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。前端由全局 Vue 自定义指令 `v-has` 实现（只读登录态给元素加 `.v-has-hidden { display:none !important; }`）。证书管理页只读保留列表只读查看，隐藏「添加证书」「删除」「全局缺省证书切换」等写操作。
