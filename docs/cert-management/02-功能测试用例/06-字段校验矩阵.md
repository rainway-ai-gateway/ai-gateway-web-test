## 6. 字段校验矩阵

### 6.1 证书添加表单校验规则

| 字段 | 校验规则 | 错误提示 | 触发条件 |
|------|---------|---------|---------|
| 证书名称 | 必填 | 「请输入证书名称」 | 为空时 |
| 证书名称 | 2-64 字符，字母/数字/`_`/`-`/`.`，首尾不能为 `_`、`-`、`.` | 「证书名称长度 2-64 字符…」 | 格式不合法时 |
| 证书名称 | 唯一性 | 接口返回错误（以实际文案为准） | 与已有证书重复时 |
| 描述 | 必填 | 「请输入描述」 | 为空时 |
| 描述 | 2-256 **字节**（按 UTF-8 字节计），不含控制字符 | 「描述长度 2-256 字节（按 UTF-8 字节计），不能包含控制字符」 | 字节数 <2 或 >256，或含控制字符时 |
| 过期时间 | 只读预览 | 未上传时显示「上传证书文件后自动解析」 | 上传证书后自动展示 |
| 证书文件 | 必填 | 「请上传证书文件」 | 未上传时 |
| 私钥文件 | 必填 | 「请上传私钥文件」 | 未上传时 |
| 设为默认 | 条件必填 | 接口返回「默认证书必须存在」 | 系统中无默认证书且未勾选时（UI 会自动勾选并禁用） |

#### 6.1.1 描述长度边界（UTF-8 字节口径）

> 规则备注：下列样本已并入既有用例 CM-C-04 的步骤与预期（[01-证书添加 §1.4](./01-证书添加.md)），不单独设编号。

| 输入样本 | UTF-8 字节数 | 预期 | 覆盖用例 |
| -------- | ------------ | ---- | -------- |
| `'a'` | 1 | 拦截（下界不足） | CM-C-04 |
| `'ab'` | 2 | 通过（下界） | CM-C-04 |
| `'a'.repeat(256)` | 256 | 通过（上界），`POST /certificates` 200 | CM-C-04 |
| `'a'.repeat(257)` | 257 | 拦截（越上界） | CM-C-04 |
| 200 个汉字 | 600 | 拦截（按字节判定，不发请求） | CM-C-04 |
| `'ab\tcd'` | 7 | 拦截（含控制字符） | CM-C-04 |

### 6.2 证书删除约束

| 场景 | 规则 | UI 表现 |
|------|------|---------|
| 删除默认证书 | 禁止 | 删除按钮 disabled + Tooltip「默认证书不可删除」 |
| 删除非默认证书 | 允许 | 弹出确认框后删除成功 |

### 6.3 缺省证书约束

| 规则 | 说明 |
|------|------|
| 全局唯一 | 必须有且只有一个默认证书 |
| 切换联动 | 切换新默认后，旧默认自动变为非默认 |
| 列表标识 | 默认证书行显示 Tag「全局缺省证书」 |

### 6.4 列表与搜索

| 列/搜索 | 说明 |
|--------|------|
| 证书名称 | 可搜索 |
| 设为默认 | 默认证书显示 Tag，不可搜索 |
| 过期时间 | 可搜索；服务端从 PEM 解析 |

## 7. OpenAPI 对照索引

> 对照 `ai-gateway-api/design-docs/api-define/OpenAPI接口定义/certificates.md`

| 字段/规则 | API 要求 | 02 覆盖 |
|-----------|----------|---------|
| `cert_name` | 必填，唯一，命名规范 | CM-C-03、CM-C-08 |
| `description` | 必填，2-256 字节（按 UTF-8 字节计），不能包含控制字符 | CM-C-04 |
| `is_default` | 必填，全局唯一 true | CM-C-09、CM-C-16 |
| `cert_file_content` | 必填 PEM | CM-C-06 |
| `key_file_content` | 必填 PEM | CM-C-07 |
| `expired_date` | 只读，服务端解析 | CM-C-05（预览）、列表展示 |
| `certificates/{name}/default` PATCH | 切换默认 | CM-C-16 |
| `certificates/{name}` DELETE | 禁止删除默认 | CM-C-13 |
