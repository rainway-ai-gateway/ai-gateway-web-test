2. 查看Entity组织列表表格

- 页面成功加载
- 列表正确显示Entity信息，包含以下列：
  - ID 列：显示 Entity 的 ID（可排序、可搜索）
  - Entity名称列：显示Entity名称
  - 类型列：显示Entity类型名
  - 父Entity列：显示父Entity名称（根节点显示"-"）

### 2.6 创建Entity-带限流策略

**功能模块**: Entity组织管理  
**优先级**: P0  
**用例编号**: EM-E-06

#### 测试步骤

1. 点击"创建Entity"按钮
2. 输入名称、选择类型
3. 在"限流配置"区域配置限流策略：
   - 启用限流：选择"是"
   - TPM规则：点击"添加规则"按钮，填写规则：
     - 规则名称：输入规则名（如"tpm_rule_1"）
     - 适用模型：选择"全部模型"（或从模型接口获取的具体模型）
     - 时间窗口(分)：输入1-360之间的数值（如1）
     - 最大Token数：输入任意正整数（如10000，显示为10,000，带千位分隔符）
     - 滑动步长(分)：输入数值（如1）
   - RPM规则：点击"添加规则"按钮，填写规则：
     - 规则名称：输入规则名（如"rpm_rule_1"）
     - 适用模型：选择"全部模型"（或从模型接口获取的具体模型）
     - 时间窗口(分)：输入1-360之间的数值（如1）
     - 最大请求数：输入1-360之间的数值（如100，显示为100，带千位分隔符），且必须小于等于最大Token数
   - 最大并发：下拉选择"不限制"/"封禁"/"限制并发数"（选择"限制并发数"后输入数值，如50），默认值为"不限制"
4. 点击"提交"按钮

#### 预期结果

- 创建成功，限流状态显示"已启用"
- 最大并发默认值为"不限制"（当三项都不填写时，需配合 TPM/RPM 规则才能满足限流要求）

#### 测试数据

- TPM规则名称：tpm_rule_1
- TPM时间窗口：1
- TPM最大Token数：10000
- TPM滑动步长：1
- RPM规则名称：rpm_rule_1
- RPM时间窗口：1
- RPM最大请求数：100
- 最大并发：50

### 2.14b Entity详情数据与接口一致性

**功能模块**: Entity组织管理  
**优先级**: P1  
**用例编号**: EM-E-14b

#### 前置条件

- 已登录系统并进入Entity管理页面
- 当前Tab为"Entity组织管理"
- 已创建父Entity和子Entity

#### 测试步骤

1. 通过接口创建父Entity和子Entity（子Entity的parent_id指向父Entity）
2. 通过接口获取子Entity详情（GET /entities/{id}）
3. 在列表中点击子Entity名称打开详情抽屉
4. 验证详情展示数据与接口返回一致：
   - 基本信息：名称、类型、父Entity名称
   - 配额信息：无限配额、配额不足时放行、配额总量、配额单位、已使用、剩余量、重置周期、使用进度

#### 预期结果

- 接口创建成功
- 详情抽屉正常打开
- 基本信息字段与接口返回一致：
  - 名称与 `name` 字段一致
  - 类型与 `type` 字段一致
  - 父Entity名称与 `parent_id` 对应的Entity名称一致
- 配额信息字段与接口返回一致：
  - 无限配额与 `quota_plan.unlimited` 一致
  - 配额不足时放行与 `quota_plan.allow_over_quota` 一致
  - 配额总量与 `quota_plan.quota` 一致（带千位分隔符）
  - 配额单位与 `quota_plan.quota_unit` 一致
  - 已使用与 `quota_plan.used` 一致（含百分比）
  - 剩余量与 `quota_plan.remaining` 一致（带千位分隔符）
  - 重置周期与 `quota_plan.reset_cycle` 一致
  - 使用进度条百分比与已使用/总量比例一致
