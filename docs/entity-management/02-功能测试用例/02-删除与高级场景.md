### 2.16 删除Entity-无下级

**功能模块**: Entity组织管理  
**优先级**: P0  
**用例编号**: EM-E-16

#### 前置条件

- 已登录系统并进入Entity管理页面
- 当前Tab为"Entity组织管理"
- 列表中存在一个没有下级Entity的Entity

#### 测试步骤

1. 在列表中找到没有下级的Entity，点击"删除"按钮
2. 观察确认弹窗显示
3. 确认弹窗内容为"是否删除Entity xxx?"（xxx为Entity名称）
4. 点击"确定"按钮
5. 观察弹窗关闭和列表刷新情况

#### 预期结果

- 步骤2-4：确认弹窗正常显示
- 步骤4-5：点击确定后，确认弹窗关闭
- 列表自动刷新，Entity已从列表中移除
- 页面显示"删除成功"提示信息
- **确认弹窗**：弹窗包含超长名称时文案正常展示，按钮可点击

#### 测试数据

- Entity名称：test-entity（无下级）

### 2.22 E2E-层级Entity与删除约束

**功能模块**: Entity组织管理（跨 Entity 类型 Tab）  
**优先级**: P0  
**用例编号**: EM-E-22  
**归属场景**: 场景二步骤15 / 场景四  
**自动化**: `test_05_entity_full_journey.spec.js`（第二条，`serial`）

**设计依据**: 复用 EM-T-02、EM-E-02、EM-E-07/EM-E-08、EM-T-14 的单步预期  
**实现状态**: 已对齐（`test_05_entity_full_journey`）

#### 前置条件

- 已登录系统
- **全程 UI 操作**（不使用 API 造数创建类型与 Entity）
- 测试数据使用运行时生成的唯一类型名/Entity 名

#### 测试步骤

1. 进入 **Entity 类型管理** Tab，UI 依次创建两个类型：
   - 父类型：级别 = 1
   - 子类型：级别 = 2
2. 切换至 **Entity 组织管理** Tab，UI 创建父 Entity（选择父类型，不选父 Entity）
3. 在同一 Tab UI 创建子 Entity：选择子类型，父 Entity 选步骤 2 的父 Entity
4. 切换回 **Entity 类型管理**，对**仍有关联 Entity 的父类型**执行删除：点击「删除」→ 确认弹窗点「确认」
5. 切换至 **Entity 组织管理**，UI 删除子 Entity，再 UI 删除父 Entity
6. 切换至 **Entity 类型管理**，UI 依次删除子类型、父类型

#### 预期结果

- 步骤 1~3：类型与 Entity 均创建成功；子 Entity 列表「父 Entity」列显示父 Entity 名称
- 步骤 4：系统**阻止删除**关联 Entity 的类型，显示「无法删除」类错误提示；类型仍在列表中（同 [EM-T-14](#114-删除entity类型-有关联entity)）
- 步骤 5：子、父 Entity 均从列表消失
- 步骤 6：两个类型均从列表消失

#### 测试数据

- **父类型**：运行时生成，如 `type_yyyyMMdd…`，级别 1
- **子类型**：运行时生成，级别 2
- **父 Entity**：运行时生成，如 `ent_yyyyMMdd…`
- **子 Entity**：运行时生成，父 Entity = 上项
