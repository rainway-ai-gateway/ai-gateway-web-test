## 7. 变更回归：名称校验（2026-08-24 / 08-25）

> 变更背景：
>
> 1. **Entity 名称（EntityName）校验变更**：仅允许**小写字母**、数字、`_`、`-`；不能以 `-`、`_` 开头或结尾；长度 1–64；不能包含空白字符；全局唯一。
> 2. **限流规则（TPM / RPM）`name` 校验变更**：长度 1–128；字符集限制为 `[a-zA-Z0-9_-]`；同一 `RateLimitPolicy` 内不能重复；**创建后不可修改**（编辑时名称禁用）。
>
> 接口依据：`00-common.md` §17 EntityName、§10 TPMConfig、§11 RPMConfig；`entities.md` §2.1 创建约束。

### EM-CV-01：Entity 名称-仅允许小写字母

**功能模块**: 名称校验  
**优先级**: P0  
**用例编号**: EM-CV-01

#### 前置条件

- 打开创建 Entity 抽屉

#### 测试步骤

依次输入以下名称并触发校验：

1. `ops` → 预期通过
2. `ops_team`、`ops-team`、`ops2024` → 预期通过
3. `Ops`、`OpsTeam`、`OPS` → 预期**拦截**（不允许大写字母）
4. `Ops Team` → 预期拦截（含空白字符）

#### 预期结果

1. 名称仅允许小写字母、数字、`_`、`-`；输入含大写字母时校验拦截并提示（如「名称仅支持小写字母、数字、_、-」）
2. 合法名称提交成功，`POST /entities` 返回 200

### EM-CV-05：限流规则 name-字符集校验

**功能模块**: 名称校验  
**优先级**: P0  
**用例编号**: EM-CV-05

#### 前置条件

依次输入以下规则名称并触发校验：

### EM-CV-08：限流规则 name-创建后不可修改

**功能模块**: 名称校验  
**优先级**: P1  
**用例编号**: EM-CV-08

#### 前置条件

- 存在一条已创建、含限流规则（TPM / RPM）的 Entity 或 API-Key 记录

#### 测试步骤

1. 编辑该记录，进入限流策略配置
2. 尝试修改已有规则的名称字段

#### 预期结果

1. 已有规则的名称字段**只读 / 禁用**（创建后不可修改）
2. 可修改规则的其他字段（model、window_minutes、max_tokens/max_requests、step_minutes）
3. 新增规则的名称可输入
