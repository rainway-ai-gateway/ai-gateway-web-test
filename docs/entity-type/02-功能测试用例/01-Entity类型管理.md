## 1. Entity类型管理

> **归属场景**: 场景一(管理员配置Entity类型)

### 1.1 Entity类型列表展示

**功能模块**: Entity类型管理  
**优先级**: P1  
**用例编号**: EM-T-01

#### 前置条件

- 系统已正常运行
- 已使用管理员账号登录系统

#### 测试步骤

1. 打开浏览器，访问AI网关管理控制台
2. 在左侧导航栏中，找到并点击"Entity管理"菜单项
3. 观察页面加载情况
4. 确认当前Tab为"Entity类型管理"（默认选中）
5. 查看页面中间区域的Entity类型列表表格

#### 预期结果

- 页面成功加载，显示"Entity管理"标题
- 页面顶部显示两个Tab页签："Entity组织管理"和"Entity类型管理"，默认选中"Entity组织管理"
- 左侧显示蓝色"创建Entity"按钮
- 下方显示搜索和筛选区域（见 EM-E-10~EM-E-12 及新增过滤项）
- Entity类型列表表格正确显示，包含以下列：
  - 类型名列：显示类型名（如dep2）
  - 描述列：显示类型描述（如"二级部门"）
  - 级别列：显示级别（如2）
  - 创建时间列：显示创建时间
  - 操作列：包含"编辑"（蓝色按钮）和"删除"（红色按钮）
- 页面底部显示分页控件
- **空态展示**：无数据时显示空态提示（如"暂无数据"），不显示空白表格
- **数据一致性验证**：通过接口创建Entity类型后，列表行展示的类型名、描述、级别与接口返回数据一致
- 长文本不破坏表格布局（截断或折行）
- **降级展示**：接口异常时显示友好错误提示，不白屏或无限 loading

#### 测试数据

- 类型名：dep2
- 描述：二级部门
- 级别：2
