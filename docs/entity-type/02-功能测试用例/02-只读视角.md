## 2. 只读管理员视角（写操作隐藏）

> 变更背景：后端引入「系统管理员（只读）」角色（`role` 枚举取代 `is_admin`，新增 `system_admin_readonly`）；只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。
>
> 前端实现：全局 Vue 自定义指令 `v-has`，只读登录态给元素加 `.v-has-hidden { display:none !important; }`（`src/utils/directive.js`、`src/assets/css/global.less`）。
>
> 接口 / 原型依据：`ai-gateway-web/design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md`（Entity 类型管理页只读隐藏「创建类型」「编辑」「删除」，保留列表只读查看）。  
> **归属场景**: 场景二（只读管理员视角（写操作隐藏））

**管理员视角对照**：管理员（`role === 'system_admin'`）可见「创建类型」按钮及操作列「编辑」「删除」写入口；只读视角下这些写操作均隐藏。

---

### EM-T-RO-01：只读视角「创建类型」按钮隐藏

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: EM-T-RO-01  
**设计依据**: `src/modules/Entity/components/EntityTypeList.vue`（「创建类型」Button 挂 `v-has`）

#### 前置条件

- 以「系统管理员（只读）」角色登录（`role === 'system_admin_readonly'`）
- 进入 Entity 管理页面，切换至「Entity类型管理」Tab

#### 测试步骤

1. 观察页头工具栏区域
2. 确认「创建类型」按钮是否存在
3. 尝试定位隐藏按钮（DOM / 键盘聚焦）

#### 预期结果

1. 「创建类型」按钮不可见（`display:none !important`）
2. 页面不提供任何新增类型的写入口
3. 搜索、分页等只读能力正常

#### 补充说明

- 对照管理员视角：管理员可见「创建类型」按钮。

---

### EM-T-RO-02：只读视角列表操作列「编辑」「删除」隐藏

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: EM-T-RO-02  
**设计依据**: `EntityTypeList.vue` 操作列「编辑」「删除」均挂 `directives:[{name:'has'}]`

#### 前置条件

- 以「系统管理员（只读）」角色登录
- Entity 类型列表中存在记录

#### 测试步骤

1. 观察某行操作列
2. 确认「编辑」按钮是否存在
3. 确认「删除」按钮是否存在

#### 预期结果

1. 操作列「编辑」「删除」按钮均不可见
2. 页面不提供任何修改 / 删除类型的写入口
3. 列表行数据（类型名、描述、级别、创建时间）正常展示

#### 补充说明

- 对照管理员视角：管理员操作列可见「编辑」「删除」按钮。

---

### EM-T-RO-03：只读视角列表只读查看能力保留

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: EM-T-RO-03  
**设计依据**: Entity 类型管理页只读保留列表查看（列表 / 搜索 / 分页）

#### 前置条件

- 以「系统管理员（只读）」角色登录
- Entity 类型列表中存在多条记录

#### 测试步骤

1. 查看 Entity 类型列表表格加载
2. 在搜索框输入类型名进行搜索
3. 切换分页
4. 核对列表数据与 `GET /entity-types` 返回一致

#### 预期结果

1. 列表正常加载，展示类型名 / 描述 / 级别 / 创建时间
2. 搜索、分页等只读操作可正常使用
3. 列表数据与接口返回一致
4. 全程无任何写操作入口出现

#### 补充说明

- 只读视角保留的是「查看」能力，不保留任何写操作；本页无「查看 / 详情」独立按钮，只读查看即列表本身。
