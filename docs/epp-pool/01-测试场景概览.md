# EPP 调度（EPP Schedule）模块 - 测试场景概览

## 模块概述

EPP（Endpoint Picker）调度模块负责管理 EPP 调度器的部署实例与集群分配关系，是「资源管理」菜单下的新增功能区域。页面分为两个页签：

1. **EPP 实例池（/epp-pool）**：树形表格查看/编辑实例组与实例，支持行内编辑、添加/删除组与实例、全量替换保存。
2. **EPP 调度分配（/epp-assignments）**：分配视图表格（按集群展开主/备实例）+ 未分配/空闲区域 + 手动覆写抽屉。

对应接口文档：`ai-gateway-web/design-docs/api-define/OpenAPI接口定义/epp-pool.md`、`epp-assignments.md`；对应原型：`ai-gateway-web/design-docs/prototype-design/pages/epp.html`。

> **关联模块**：
>
> - **AI 业务集群（Clusters）**：集群可将 `balance_mode` 设为 `EPP`，分配器自动为 EPP 模式集群选择实例组与主实例。
> - **模型服务商（Providers）**：Provider 的 `instance_pool`（后端模型服务实例）与 EPP 实例池（EPP 调度器进程地址）是两个独立概念。

---

## 配置顺序 / 依赖

```text
① 部署 EPP 调度器，在实例池中登记实例（EPP 调度器自身的进程地址）
        │
        ▼
② EPP 实例池全量替换保存（PATCH /epp-pool）
        │
        ▼
③ 查看 EPP 调度分配视图（自动分配 / 手工覆写）
```

**依赖说明**：

| 关系 | 说明 |
| --- | --- |
| EPP 实例池 → EPP 调度分配（强依赖） | 实例池是分配的基础数据来源；分配视图读取实例池做读时 join |
| AI 业务集群 → EPP 调度分配 | 仅 `balance_mode=EPP` 的集群出现在分配视图中 |

## 场景测试设计

### 场景一：管理员查看和管理 EPP 实例池

**场景描述**：管理员查看 EPP 实例池的树形表格视图，编辑实例组与实例，全量替换保存或取消还原。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 进入 EPP 调度页面，查看 Tab1「EPP 实例池」 | EP-POOL-01 | P0 |
| 2 | 树形表格展示：组列表展开显示实例 | EP-POOL-02 | P1 |
| 3 | 顶部统计：池名称、组数、实例数 | EP-POOL-03 | P1 |
| 4 | 编辑模式：修改组名/实例字段 | EP-POOL-04 | P1 |
| 5 | 编辑模式：添加组、添加实例、删除组、删除实例 | EP-POOL-05 | P1 |
| 6 | 保存（PATCH）/ 取消还原 | EP-POOL-06 | P0 |

**测试目标**：验证 EPP 实例池查看与编辑流程完整；保存为全量替换语义，取消还原正确。

> **验收要点**：导航路径「资源管理 → EPP 调度」；Tab1「EPP 实例池」默认激活；树形表格按实例组组织，点击箭头展开查看实例；顶部统计展示池名称、实例组数、实例总数；编辑模式下组名/实例字段可内联编辑，支持添加/删除组与实例；「保存」全量提交 PATCH，「取消」还原全部修改。

---

### 场景二：管理员查看 EPP 调度分配视图

**场景描述**：管理员查看 EPP 调度分配表格，查看统计汇总与未分配/空闲区域，手动覆写分配。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | Tab2「EPP 调度分配」视图表格展示 | EP-ASGN-01 | P0 |
| 2 | 集群名称搜索 | EP-ASGN-02 | P1 |
| 3 | 排序/分页 | EP-ASGN-03 | P1 |
| 4 | 统计汇总：已分配/未分配/空闲实例组数 | EP-ASGN-04 | P1 |
| 5 | 未分配集群区域（红色告警+降级提示） | EP-ASGN-05 | P1 |
| 6 | 手动覆写抽屉：选组+选实例+PATCH | EP-ASGN-06 | P0 |

**测试目标**：验证分配视图正确展示，搜索/排序/分页功能正常，手动覆写流程完整。

> **验收要点**：Tab2「EPP 调度分配」表格包含集群名称/实例组/主实例/备实例/状态/操作列；顶部统计展示已分配/未分配（红色告警）/空闲实例组数；未分配区域红色卡片提示「服务降级为 WRR」；手动覆写抽屉选择实例组+主实例 ID 后提交生效。

| 测试场景 | 前置条件 |
| --- | --- |
| EP-POOL-01~06 实例池管理 | EPP 实例池已存在（后端/接口生成），含至少 1 个实例组、实例 |

## 测试数据准备

| 数据类别 | 准备内容 | 用途 |
| --- | --- | --- |
| EPP 实例池 | 2~3 个实例组，每组 1~2 个实例 | 树形表格展示与编辑 |
| EPP 模式集群 | ≥2 个 `balance_mode=EPP` 的业务集群 | 分配视图展示与手动覆写 |
| 未分配集群 | 1 个刚切入 EPP 模式但尚未完成分配的集群 | 未分配区域红色告警展示 |
| 空闲实例组 | 1 个实例池中未承担分配的组 | 空闲实例组统计展示 |

| 数据项 | 说明 | 示例值 |
| --- | --- | --- |
| 实例池名称 | 由服务端配置 `DefaultEPPInstancePoolName` 提供 | `EPP.pool` |
| 实例组名 | 非空、池内唯一 | `g1`、`g2` |
| 实例 ID | 非空、池内全局唯一；对应 EPP `-instance-id` 启动参数 | `epp-a`、`epp-b` |
| 主机 | 合法主机名或 IPv4/IPv6 地址 | `10.0.0.1`、`epp-0.example.com` |
| 端口 | 1-65535 整数 | `9002` |
| `(host, port)` 组合 | 池内全局唯一 | — |
