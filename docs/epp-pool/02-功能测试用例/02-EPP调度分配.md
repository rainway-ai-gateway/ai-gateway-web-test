## 2. EPP 调度分配

> **归属场景**: 场景二
> **导航路径**: 资源管理 → EPP 调度 → Tab2「EPP 调度分配」
> **数据来源**: 分配视图来自 `epp_assignments`（cluster→group）与 `epp_instances`（/epp-pool）的读时校验：分配的组存在且非空方为有效，否则该 cluster 计入 `unassigned_clusters`
> **触发场景**: `balance_mode=EPP` 的集群出现在本视图中

### 2.1 Tab2 调度分配视图表格展示

**用例编号**: EP-ASGN-01 | **优先级**: P0

#### 前置条件

- EPP 实例池已配置，含 ≥2 个实例组（每组恰好 1 个实例）
- 存在 ≥2 个 `balance_mode=EPP` 的业务集群，且已有有效分配记录（每条记录含 `cluster` 与 `group`）

#### 测试步骤

1. 进入 EPP 调度页面，点击 Tab2「EPP 调度分配」
2. 观察分配视图表格的列结构与数据展示
3. 在搜索框中输入某集群名称，观察 URL 是否携带 `?cluster=xxx` 参数
4. 清空搜索框，观察 URL 参数恢复

#### 预期结果

- 表格包含列：集群名称、实例组、操作
- 集群名称：展示集群名
- 实例组：展示分配的实例组名（`clusters` 中的条目恒为有效组名）
- 操作：每行有「编辑」按钮
- 数据与 `GET /epp-assignments` 接口返回一致
- 搜索集群名称后，接口应携带 `?cluster=xxx` 查询参数；清空搜索后参数移除

#### 测试步骤

1. 进入 Tab2 分配视图
2. 在搜索框输入完整的集群名称
3. 清空搜索框
4. 输入部分名称（模糊匹配）
5. 输入不存在的名称

#### 预期结果

- 输入完整名称时，表格仅展示该集群的行
- 清空搜索框后，恢复展示全量集群
- 输入部分名称时，表格展示名称包含输入内容的集群（模糊匹配）
- 输入不存在的名称时，表格展示为空，提示「暂无数据」

#### 测试步骤

2. 观察页面顶部统计区域

#### 预期结果

- 展示「未分配集群」数量（`balance_mode=EPP` 但无有效分配的集群数，含从未分配与分配悬空）

### 2.6 手动覆写抽屉：选组+提交

**用例编号**: EP-ASGN-06 | **优先级**: P0

#### 前置条件

- 实例池含 ≥2 个实例组（每组恰好 1 个实例）
- 存在已分配的 EPP 集群

#### 测试步骤

##### Part A：正常覆写

1. 进入 Tab2 分配视图
2. 点击某集群行的「编辑」按钮
3. 观察抽屉表单字段：仅「实例组」下拉
4. 选择一个实例组
5. 点击「确认」提交

##### Part B：关联更新

1. 修改后再次打开该集群的抽屉，验证回显

##### Part C：校验场景

1. 实例组下拉选择空值后提交
2. 观察提交请求体仅含 `group_name`
3. 观察所选组在当前实例池中不存在/为空时的提交结果

##### Part D：跨模式持久化

1. 记录某个 EPP 集群当前的分配（如 group=g1）
2. 在集群基础信息中将 `balance_mode` 从 `EPP` 切回 `WRR`
3. 将 `balance_mode` 再切回 `EPP`
4. 进入分配视图，观察该集群的分配记录

#### 预期结果

##### Part A：正常覆写

- 抽屉弹出，表单仅「实例组」下拉（选项来自当前实例池中的组）
- 提交成功，Toast 提示「修改成功」，抽屉关闭
- 表格更新为新的分配数据
- `PUT /epp-assignments/{cluster}` 响应应包含 `epp_data` / `server_data_conf` 版本号递增

##### Part B：关联更新

- 再次打开该集群的编辑抽屉，表单预填上一次提交的实例组

##### Part C：校验场景

- 不选择实例组时提交被拦截，提示必填
- 请求体仅含 `{ group_name }`（不含 `primary_instance_id`），与 API 一致；`group_name` 须存在于 `/epp-pool` 且非空
- 所选组在实例池中不存在/为空时提交被拒绝（参数校验失败）
- `PUT /epp-assignments/{cluster}` 返回成功，视图同步更新

##### Part D：跨模式持久化

- 集群从 EPP 切回 WRR 后，分配记录在服务端**休眠保留**（不删除，仅不再展示）
- 集群从 WRR 切回 EPP 后，原有分配记录**自动恢复生效**，分配视图可见
