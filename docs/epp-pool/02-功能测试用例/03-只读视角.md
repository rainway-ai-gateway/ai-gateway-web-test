## 3. 只读管理员视角（写操作隐藏）

> 变更依据：`design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md`（已 Review 通过）。
> 后端以 `role` 枚举取代 `is_admin`（`system_admin` / `system_admin_readonly`）；只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。前端实现为全局指令 `v-has`：只读登录态下给挂载元素加 `.v-has-hidden { display:none !important; }`。
> 本模块依据变更记录 §3.4 / §4：`pages/epp.html` 只读视角**仅查看**，隐藏「编辑池 / 覆写编辑 / 确认」；`EppPool.Assignments` render 操作列写按钮加 `directives: [{ name: 'has' }]`。

### EP-RO-01：EPP实例池只读视角编辑入口隐藏

**功能模块**: EPP 实例池
**优先级**: P0
**用例编号**: EP-RO-01
**OpenAPI**: `GET /epp-pool`

#### 前置条件

1. 以**只读系统管理员**登录（`role=system_admin_readonly`），「资源管理 → EPP 调度」菜单可达。
2. Tab1「EPP 实例池」默认激活，实例池含 ≥1 个实例组 / 实例。

#### 测试步骤

1. 进入「资源管理 → EPP 调度」页，观察 Tab1「EPP 实例池」工具栏。
2. 逐项核对「编辑池」等编辑入口的可见性。
3. 检查树形表格是否出现行内编辑控件 / 添加 / 删除 / 保存按钮。

#### 预期结果

1. **隐藏**「编辑池」按钮（对应 EP-POOL-04 中管理员进入编辑模式的入口）。
2. 树形表格仅以**只读**方式展示组 / 实例（实例组名、实例 ID、主机、端口），不出现行内编辑控件。
3. **隐藏**「添加组」「添加实例」「删除」「保存」等写操作按钮（对应 EP-POOL-05、EP-POOL-06）。
4. 切换为系统管理员（`role=system_admin`）登录时，「编辑池」「添加组」「保存」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`
- 实例池：2~3 个实例组，每组 1~2 个实例

#### 补充说明

- 依据变更记录 §3.4：`pages/epp.html` 只读视角仅查看，隐藏「编辑池 / 覆写编辑 / 确认」。隐藏实现为全局指令 `v-has`（`.v-has-hidden { display:none !important; }`）。

### EP-RO-02：EPP调度分配只读视角覆写编辑入口隐藏

**功能模块**: EPP 调度分配
**优先级**: P0
**用例编号**: EP-RO-02
**OpenAPI**: `GET /epp-assignments`

#### 前置条件

1. 以**只读系统管理员**登录，切换至 Tab2「EPP 调度分配」。
2. 存在 ≥1 个 `balance_mode=EPP` 且已分配的集群。

#### 测试步骤

1. 进入 Tab2「EPP 调度分配」视图表格。
2. 观察每行行尾「操作」列。
3. 逐项核对「覆写编辑」写入口的可见性。

#### 预期结果

1. 操作列**隐藏**「覆写编辑」写操作入口（对应 EP-ASGN-06 中管理员打开覆写抽屉的入口）。
2. 表格集群名称 / 实例组 / 主实例 / 备实例 / 状态等列**正常只读展示**；统计汇总、未分配 / 空闲区域只读展示保留。
3. 管理员视角下操作列的「覆写编辑」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`
- 已分配 EPP 集群 ≥1 个

#### 补充说明

- 依据变更记录 §4：`EppPool.Assignments` render 操作列写按钮加 `directives: [{ name: 'has' }]`；只读视角操作列仅剩只读展示。

### EP-RO-03：EPP调度分配只读视角覆写抽屉确认按钮隐藏

**功能模块**: EPP 调度分配
**优先级**: P0
**用例编号**: EP-RO-03
**OpenAPI**: `PATCH /epp-assignments`

#### 前置条件

1. 以**只读系统管理员**登录，已进入 Tab2「EPP 调度分配」。

#### 测试步骤

1. 检查操作列是否提供可以打开「覆写编辑」抽屉的入口。
2. 尝试通过任何入口打开覆写抽屉。
3. 检查页面是否出现「确认」提交类按钮。

#### 预期结果

1. 只读视角下**无法打开**覆写编辑抽屉（覆写入口已隐藏）。
2. 抽屉内「确认」提交类写按钮**不出现**（对应 EP-ASGN-06 管理员的覆写提交入口）。
3. 只读视角**不发起** `PATCH /epp-assignments` 请求。
4. 切换为系统管理员（`role=system_admin`）登录时，「覆写编辑 → 确认」链路正常可用（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`

#### 补充说明

- 依据变更记录 §3.4：`pages/epp.html` 只读视角隐藏「编辑池 / 覆写编辑 / 确认」；提交类按钮挂全局指令 `v-has`，后端对 `PATCH /epp-assignments` 做 403 兜底。
