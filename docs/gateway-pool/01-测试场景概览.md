# AI 网关实例池（Gateway Pool）模块 - 测试场景概览

## 模块概述

AI 网关实例池是「资源管理」菜单下的**全局单例资源**：网关转发引擎实例的集合。池名由后端配置生成（`DefaultAIInstancePoolName`，如 `BFE.aipool`），UI 不提供实例池的创建/删除，仅支持在页面内**内联编辑**池内实例（机器名、IP/域名、端口）。

对应接口文档：`design-docs/api-define/OpenAPI接口定义/alb-pool.md`（`GET` / `PUT /alb-pool`）；对应原型：`design-docs/prototype-design/pages/instance-pool-ai.html`。

> **概念区分（重要）**：模型服务商（Providers）抽屉中的「实例池」（`instance_pool` 字段）是**服务商的后端模型服务实例**，与本模块的网关实例池（全局 `/alb-pool`）**是两个独立的对象**，互不依赖。业务集群移除「实例配置」步骤后，集群实例由 Providers 提供，也与本模块无关。
>
> 02 用例文档中的 `bfe_pools` / `GET /bfe-pools/{name}` 为历史命名，与 `/alb-pool` 指同一资源。

---

## 配置顺序

```text
AI网关实例池（全局单例，独立模块，与其他模块无依赖）
```

池由后端生成，UI 仅编辑池内实例；路由、业务集群、模型服务商均不直接引用本网关实例池。

## 场景测试设计

本模块采用**场景测试**方法：按管理员真实配置目标组织用例；单页编辑与校验写入 [02-功能测试用例](./02-功能测试用例/00-索引与映射.md)，此处定义编排与依赖。

### 场景一：管理员管理 AI 网关实例池

**场景描述**：管理员管理 AI 网关实例池（池本身由后端/接口生成），编辑实例池内实例。

| 步骤 | 操作 | 对应场景编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 编辑实例池内实例（内联编辑模式） | RM-GP-07 | P1 |
| 2 | 验证实例列表 ≤1 行时删除按钮禁用 | RM-GP-10 | P1 |
| 3 | 验证编辑时字段校验（必填、格式、范围、重复） | RM-GP-05、RM-GP-06、RM-GP-11、RM-GP-14、RM-GP-15 | P1 |
| 4 | 验证编辑回显与 OpenAPI 一致 | RM-GP-16 | P1 |

**测试目标**：验证实例池可正常编辑，编辑回显与 API 一致，字段校验正确。

> **验收要点**：导航路径「资源管理 → AI网关实例池」；点击顶部「编辑」进入内联编辑模式；实例表格含 机器名 / IP域名 / 端口 与操作列；提交成功显示 Toast 并恢复列表态；「取消」放弃修改。
