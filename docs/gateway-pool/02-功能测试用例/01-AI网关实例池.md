### 1.10 实例行删除门槛

**用例编号**: RM-GP-10 | **优先级**: P1

### 1.11 编辑时实例地址+端口组合不可重复

**用例编号**: RM-GP-11 | **优先级**: P1

#### 前置条件

- 已存在实例池（通过 API 创建），含 1 个实例行

#### 测试步骤

1. 点击「编辑」进入内联编辑模式
2. 点击「+ 创建」新增第二行实例
3. 填写第二行实例与第一行相同的 **地址 + 端口**（权重可不同）
4. 点击「提交」

#### 预期结果

- 提交被拦截，提示 **地址 + 端口** 组合不可重复（文案以 design 为准）
- 编辑表单保持打开状态，数据未更新

#### 补充说明

- 判定键为 `addr` + `port`；**权重不同不影响**重复判定
- 同地址、不同端口（如 `127.0.0.1:80` 与 `127.0.0.1:8080`）**允许**共存

### 1.15 编辑时实例地址格式校验

**用例编号**: RM-GP-15 | **优先级**: P1
**设计依据**: `design/gateway-pool/02-create-form-instance-ip-format.jpg`（待补）

#### 前置条件

- 已存在实例池（通过 API 创建）

#### 测试步骤

1. 点击「编辑」进入内联编辑模式
2. 修改实例行地址为以下**非法**值（可分步或 Parametrize）后点击「提交」：
   - **IPv4 非法**（[RFC 791](https://www.rfc-editor.org/rfc/rfc791)）：`256.1.1.1`（段超 255）、`1.2.3`（仅 3 段）、`1.2.3.4.5`（5 段）
   - **IPv6 非法**（[RFC 4291](https://www.rfc-editor.org/rfc/rfc4291)、[RFC 5952](https://www.rfc-editor.org/rfc/rfc5952)）：`gggg::1`（非十六进制）、`2001::db8::1`（`::` 出现两次）
   - **主机名/域名非法**（[RFC 1123](https://www.rfc-editor.org/rfc/rfc1123) §2.1、[RFC 1035](https://www.rfc-editor.org/rfc/rfc1035)）：`-bad.com`（标签以 `-` 开头）、`bad-.com`（标签以 `-` 结尾）、`###invalid`（非法字符）
   - **非裸地址字面量**：`http://10.0.0.1`（含 URI 方案）、`10.0.0.1:80`（端口应填端口列，不得写入地址字段）
3. 对照**合法**值应通过格式校验：`127.0.0.1`、`::1`、`2001:db8::1`、`backend.example.com`、`node-1`（单标签主机名）

#### 预期结果

- 非法地址提交被拦截，提示格式错误（文案以 design 为准）
- 编辑表单保持打开状态，数据未更新
- 合法对照值不因格式校验被拦截

#### 格式规范

- 见 [§3.1b](./03-字段校验矩阵.md#31b-实例地址格式规范rfc)

### 1.16 网关实例池编辑回显与 OpenAPI 一致

**用例编号**: RM-GP-16 | **优先级**: P1
**设计依据**: `design/gateway-pool/20260722131811.jpg`
**OpenAPI**: `GET /bfe-pools/{instance_pool_name}`

#### 前置条件

- 已存在实例池 `BFE.testpool{ts}`（通过 API 创建），含已知实例行（机器名、地址、端口）

#### 测试步骤

1. `GET /bfe-pools/BFE.testpool{ts}`，记录 `instances[]`（hostname、addr、port）
2. UI 点击列表页顶部「编辑」，进入内联编辑模式
3. 对照编辑表格：各实例行字段（机器名、地址、端口）

#### 预期结果

- 实例行 **机器名、地址、端口** 与 API `instances[]` **逐行一致**（顺序以 design 为准）
- 端口列直接展示端口数值，与 API `port` 一致
- **长文本布局**：编辑表单中预填超长值时正常展示，不破坏表单布局
- 映射见 [§3.7](./03-字段校验矩阵.md#37-uiopenapi-读回一致性)
