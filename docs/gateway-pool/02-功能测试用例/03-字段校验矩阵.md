### 3.1b 实例地址格式规范（RFC）

> 适用于 **AI网关实例池** 编辑表单「地址」列（OpenAPI 字段 `instances[].addr`；GUI 同时接受域名/主机名字面量）。验收以 design 为准；下表为 RFC 对齐的测试样本约定。

| 输入类型 | RFC 依据 | 合法规则 | 非法样本（02 必测子集） | 合法对照样本 |
| ---------- | ---------- | ---------- | ------------------------- | -------------- |
| IPv4 | RFC 791 | 点分四段，每段十进制 **0~255** | `256.1.1.1`、`1.2.3`、`1.2.3.4.5` | `127.0.0.1`、`10.0.0.1` |
| IPv6 | RFC 4291、5952 | 冒号十六进制；**至多一处** `::` 压缩 | `gggg::1`、`2001::db8::1` | `::1`、`2001:db8::1` |
| 主机名 / FQDN | RFC 1123 §2.1、1035 | 标签以字母数字开头/结尾；标签间 `.` 分隔；标签 ≤63 字符；总长 ≤253 | `-bad.com`、`bad-.com`、`###invalid` | `backend.example.com`、`node-1` |
| 非地址字面量 | — | 不得含 URI 方案或嵌入端口 | `http://10.0.0.1`、`10.0.0.1:80` | — |

#### 自动化实现要点

- 编辑回显：逐字段 `expect(ui).toEqual(api)`；端口直接映射 `port`
