# 意图配置模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。

用例覆盖 2026-09-27 AI 缓存镜像 / 意图分类变更涉及的 IntentConfig 模块全部交互；字段校验依据 `design-docs/api-define/OpenAPI接口定义/intent-config.md` §1／§2 的合法性条件，UI 行为依据 `ai-gateway-web/src/modules/IntentConfig/` 源码与原型 `design-docs/prototype-design/pages/intent-config.html`。

## 章节序号规则

- 02 用例文件内章节序号统一为 `## N. <章节名>`，与本索引「详细用例文件列表」一一对应。
- 用例编号前缀与来源：`IC-L`（全局配置与双模式）、`IC-Q`（问题新增与编辑）、`IC-D`（问题查看）、`IC-P`（保存并发布）、`IC-V`（字段校验）、`IC-RO`（只读管理员视角）、`IC-DR`（离开拦截与退出确认，DR = Dirty-guard / Route-leave，源自 `ai-gateway-web/design-docs/modifications/2026-10-16-intent-config-leave-guard/ui-code-changes.md`）；前缀取自 Intent Config，避免与既有模块冲突。
- 每个用例标题形如 `### IC-X-NN：<标题>`，标题本身即为页内锚点（`00-索引` 链接的 `#…` 与之对应）。
