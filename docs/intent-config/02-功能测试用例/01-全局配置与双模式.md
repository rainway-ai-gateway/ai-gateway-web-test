## 1. 全局配置与双模式

> 覆盖视图模式查看、视图 / 编辑双模式切换、全局最小置信度阈值、未发布 404 自动进入编辑模式与加载失败。依据 `src/modules/IntentConfig/index.vue`、原型 `intent-config.html` 与 `intent-config.md` §2.2。

---

### IC-L-01：进入意图配置页-已发布视图模式

**功能模块**: 全局配置与双模式  
**优先级**: P0  
**用例编号**: IC-L-01  
**设计依据**: `IntentConfig/index.vue` `fetchConfig()` / `mounted()`；`intent-config.md` §2.2

#### 前置条件

- 系统已发布过意图配置，`GET /intent-config` 返回 200（至少含全局最小置信度与问题列表）

#### 测试步骤

1. 打开浏览器并登录 AI 网关控制台
2. 导航至「路由管理 → 功能增强 → 意图配置」页面
3. 观察页面初始模式与全局配置卡片

#### 预期结果

1. 页面发起 `GET /intent-config` 且返回 200
2. 页面进入**视图模式**，不出现顶部「尚未发布」提示（`unpublishedHint` 不展示）
3. 「最小置信度」字段以纯文案展示接口返回值（如 `0.6`），非输入框
4. 页面不出现「退出编辑模式」「保存并发布」按钮，仅出现「进入编辑模式」

### IC-L-14：未发布404自动进入编辑模式

**功能模块**: 全局配置与双模式  
**优先级**: P0  
**用例编号**: IC-L-14  
**设计依据**: `index.vue` `fetchConfig()` 404 分支 + `mounted()`；`intentConfig.unpublishedHint`；`intent-config.md` §2.2

#### 前置条件

- 系统从未发布过意图配置，`GET /intent-config` 返回 404

#### 测试步骤

1. 进入意图配置页面
2. 观察页面模式、顶部提示与各项默认值

#### 预期结果

1. `GET /intent-config` 返回 404 被捕获，页面 `published=false`
2. 页面**直接渲染默认配置**：全局最小置信度为 0.6、问题列表为空；**不展示空态页面**

4. 顶部出现提示：「意图配置尚未发布，当前展示的是默认配置，点击右上角「保存并发布」后生效。」
