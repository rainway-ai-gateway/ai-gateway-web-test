## 2. 问题新增与编辑

> 覆盖「添加问题」抽屉的表单字段、「枚举（choice）」/「评分（score）」双类型、类型切换互斥重渲染、选项 / 档位增减与上限、问题名称唯一性、删除确认。依据 `src/modules/IntentConfig/components/QuestionForm.vue`、`index.vue` `onQuestionSubmit()`、原型 `intent-config.html` 与 `intent-config.md` §1。

### IC-Q-01：打开添加问题抽屉

**功能模块**: 问题新增与编辑  
**优先级**: P0  
**用例编号**: IC-Q-01  
**设计依据**: `index.vue` `onAddQuestion()`；`intentConfig.addTitle`

#### 前置条件

- 处于编辑模式，且当前问题数 < 10

#### 测试步骤

1. 点击「添加问题」按钮
2. 观察抽屉标题与表单字段

#### 预期结果

1. 打开抽屉，标题为「添加问题」
2. 抽屉内表单字段依次为：「问题名称（全局唯一）」「类型」「判定说明」「选项（1-10 项，选项名不含 |）」或「档位（1-10 档，低→高）」「最小置信度覆盖（可选，留空则使用全局门限）」
3. 底部操作区出现「保存」「取消」按钮
4. 类型默认选中「枚举（choice）」，选项列表初始为空并展示空态文案「暂无选项」

### IC-Q-02：新增「枚举（choice）」问题-成功

**功能模块**: 问题新增与编辑  
**优先级**: P0  
**用例编号**: IC-Q-02  
**设计依据**: `QuestionForm.vue` `handleSubmit()`；`index.vue` `onQuestionSubmit()`；`intentConfig.addDone`

#### 前置条件

- 处于编辑模式，且问题数 < 10，不存在同名问题

#### 测试步骤

1. 打开「添加问题」抽屉
2. 问题名称填写 `task_type`
3. 类型选择「枚举（choice）」
4. 判定说明填写「这条请求属于哪类研发任务？」
5. 选项列表添加两行：`coding` → 「编写或修改代码」、`qa` → 「问答与检索」
6. 最小置信度覆盖留空；点击「保存」

#### 预期结果

1. 表单校验通过后提交，抽屉关闭并提示「已添加问题」
2. 问题列表新增一行：名称 `task_type`、类型 Tag「枚举（choice）」、判定说明为所填文案
3. 新增项以「枚举（choice）」类型、选项列表承载；档位为空
4. 提交至后端时该问题的选项转为 `map<string,string>`（见 IC-P-02）；因未填单问题阈值，最小置信度覆盖不提交

### IC-Q-06：类型切换选项与档位互斥重渲染

**功能模块**: 问题新增与编辑  
**优先级**: P0  
**用例编号**: IC-Q-06  
**设计依据**: `QuestionForm.vue` `onTypeChange()` / `optionList` / `optionLabel`

#### 前置条件

- 打开「添加问题」抽屉

#### 测试步骤

1. 类型选择「枚举（choice）」，添加若干选项
2. 将类型切换为「评分（score）」
3. 再切换回「枚举（choice）」

#### 预期结果

1. 切到「评分（score）」时，选项列表被清空，表单该项标签变为「档位（1-10 档，低→高）」，按钮变为「添加档位」，空态文案变为「暂无档位」，占位符变为「档位名 / 档位描述」
2. 切回「枚举（choice）」时，档位列表被清空，标签恢复「选项（1-10 项，选项名不含 |）」，按钮为「添加选项」，空态「暂无选项」
3. 选项与档位**互斥**，同一问题不会同时持有两者
