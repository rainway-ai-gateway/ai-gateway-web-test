## 6. 只读管理员视角（写操作隐藏）

> 变更依据：`design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md`（已 Review 通过）。
> 后端以 `role` 枚举取代 `is_admin`（`system_admin` / `system_admin_readonly`）；只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。前端实现为全局指令 `v-has`：只读登录态下给挂载元素加 `.v-has-hidden { display:none !important; }`。
> 本模块依据变更记录 §3.4 / §4：`pages/intent-config.html` 只读视角保留「查看」，隐藏「添加问题 / 进入(退出)编辑 / 保存并发布」；`IntentConfig` 模板 `v-has` 上移至 `.ic-actions` 容器。

---

### IC-RO-01：意图配置页只读视角工具栏写按钮隐藏

**功能模块**: 全局配置与双模式
**优先级**: P0
**用例编号**: IC-RO-01
**OpenAPI**: `GET /intent-config`

#### 前置条件

1. 以**只读系统管理员**登录（`role=system_admin_readonly`），「路由管理 → 功能增强 → 意图配置」菜单可达。
2. 系统已发布过意图配置（`GET /intent-config` 返回 200）。

#### 测试步骤

1. 进入「意图配置」页面，观察页面工具栏 / 操作区（`.ic-actions`）。
2. 逐项核对「添加问题」「进入编辑模式」等写操作入口的可见性。

#### 预期结果

1. **隐藏**「添加问题」按钮（对应 IC-L-10 中管理员编辑模式可见的问题新增入口）。
2. **隐藏**「进入编辑模式」按钮，页面**恒停留视图模式**。
3. 全局阈值以纯文案展示、问题表格展示正常（只读查看能力保留）。
4. 切换为系统管理员（`role=system_admin`）登录时，「添加问题」「进入编辑模式」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`
- 已发布配置：含全局最小置信度与 ≥1 个问题

#### 补充说明

- 依据变更记录 §4：`IntentConfig` 模板 `v-has` 由 `<template>` 下移到内部真实元素或上移至外层容器 `.ic-actions`；只读登录态下加 `.v-has-hidden`（`display:none !important`）。

### IC-RO-02：意图配置页只读视角问题行写按钮隐藏

**功能模块**: 问题查看
**优先级**: P0
**用例编号**: IC-RO-02
**OpenAPI**: `GET /intent-config`

#### 前置条件

1. 以**只读系统管理员**登录，已进入意图配置页（视图模式）。
2. 问题列表存在至少一个问题。

#### 测试步骤

1. 观察问题表格每行「操作」列。
2. 逐项核对问题行写操作入口的可见性。
3. 点击问题行的「查看」入口。

#### 预期结果

1. 问题行操作列**隐藏**「编辑」「删除」等写操作按钮（对应 IC-L-08 编辑模式行操作）。
2. 问题行操作列**保留**「查看」只读入口，点击打开只读查看抽屉（全字段纯文案、footer 隐藏）。
3. 管理员视角下问题行操作列的「查看 / 编辑 / 删除」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 已发布配置：问题列表非空（含「枚举（choice）」与「评分（score）」各 ≥1 更佳）

#### 补充说明

- 依据变更记录 §4：IntentConfig render 操作列写按钮加 `directives: [{ name: 'has' }]`；显示分支收敛为 `mode === 'view'`，只读恒停留 view 模式，保留「查看」入口。

### IC-RO-03：意图配置页只读视角模式切换与提交按钮隐藏

**功能模块**: 保存并发布
**优先级**: P0
**用例编号**: IC-RO-03
**OpenAPI**: `GET /intent-config`、`PUT /intent-config`

#### 前置条件

1. 以**只读系统管理员**登录，已进入意图配置页。

#### 测试步骤

1. 观察页面是否存在「进入编辑模式」按钮。
2. 检查页面是否存在「退出编辑模式」「保存并发布」按钮。
3. 检查是否可通过任何入口进入编辑模式。

#### 预期结果

1. 「进入编辑模式」在只读视角**不可见**，无法进入编辑模式。
2. 「退出编辑模式」「保存并发布」提交类写按钮均**不出现**（对应 IC-P-01 中管理员的整体 `PUT` 发布入口）。
3. 由于恒停留视图模式，只读视角**不发起** `PUT /intent-config` 请求。
4. 切换为系统管理员（`role=system_admin`）登录时，「进入编辑模式 → 保存并发布」链路正常可用（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`

#### 补充说明

- 依据变更记录 §3.4：`pages/intent-config.html` 只读视角隐藏「添加问题 / 进入(退出)编辑 / 保存并发布」；模式切换与提交按钮挂全局指令 `v-has`，后端对 `PUT /intent-config` 做 403 兜底。
