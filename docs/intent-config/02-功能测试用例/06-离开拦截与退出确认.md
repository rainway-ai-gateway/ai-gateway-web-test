## 7. 离开拦截与退出确认

> 变更依据：`ai-gateway-web/design-docs/modifications/2026-10-16-intent-config-leave-guard/ui-code-changes.md`（本轮补齐）＋ `2026-10-15-rule-modules-drag-guard-copy/ui-code-changes.md` §4（三个兄弟模块 AI 缓存 / 流量镜像 / AI 上下文已落地的同形守卫）。
> 实现依据：`src/modules/IntentConfig/index.vue:215-226` 新增 `beforeRouteLeave`——`mode === 'edit' && isDirty` 时 `$Modal.confirm({ title: com.informationTips, content: intentConfig.exitConfirm, onOk: () => next(), onCancel: () => next(false) })`；`isDirty` 基于 `{ minConfidence, questions }` 与进入编辑模式时的快照比对（`:192-206` 定义快照比对、`:367-370` 在 `enterEditMode()` 时留快照）。
> 键位语义：本模块模式字段为 `mode`、脏标记为 `isDirty`（三个兄弟模块为 `rulesMode` / `isRulesDirty`、基于 `rules` 数组快照），文案 key 与「退出编辑模式」二次确认**共用同一串**（`intentConfig.exitConfirm`，`src/i18n/zh.js:1658` / `en.js:1755`），故本页两条用例的确认框正文相同、触发时机不同。
> **硬跳转不受拦截**：`beforeRouteLeave` 只作用于 vue-router 的**应用内跳转**（侧栏菜单、面包屑、页内链接等）；浏览器刷新、直接改 URL、`page.goto()` 属整页跳转，守卫不会执行（与路由规则页「SPA 的离开确认框不会拦硬跳转」同理）。自动化断言离开拦截必须点侧栏菜单，不能用直连 URL。

### IC-DR-01：离开拦截-编辑模式有未提交改动时点侧栏其它菜单

**功能模块**: 全局配置与双模式
**优先级**: P0
**用例编号**: IC-DR-01
**OpenAPI**: `GET /intent-config`（本用例全程不写后端）

#### 前置条件

1. 已进入「路由管理 → 功能增强 → 意图配置」页面，且意图配置**已发布**（`GET /intent-config` 返回 200），页面处于**视图模式**。
2. 已在编辑模式下改动全局「最小置信度」（或问题列表），即 `isDirty` 为真（字段改动仅存在于本地草稿，**未**点「保存并发布」）。

#### 测试步骤

1. 在**视图模式**（无未提交改动）下点击侧栏其它模块菜单（如「AI缓存规则」），观察是否弹出确认框、页面是否跳转。
2. 回到意图配置页，进入编辑模式并改动全局「最小置信度」，观察右上角按钮变为「退出编辑模式」+「保存并发布」。
3. 点击侧栏其它模块菜单，观察页面反应与 URL。
4. 在确认框中点「取消」，观察 URL 与页面状态、改动是否保留。
5. 再次点击侧栏其它模块菜单，在确认框中点「确定」，观察是否跳转到目标模块。

#### 预期结果

1. **负向对照**：步骤 1（视图模式、`isDirty` 为假）点击其它菜单**不弹确认框**，直接跳转到目标模块。
2. 步骤 3（编辑模式且 `isDirty` 为真）弹出确认框：标题为「信息提示」，正文为「当前有未提交的改动，退出编辑模式将丢弃这些改动，确认退出？」，且**此时 URL 尚未变化**（路由被守卫挂起，仍停留在 `/intent-config`）。
3. 步骤 4（点「取消」）→ `onCancel: () => next(false)`：弹窗关闭，**URL 一字不变**、页面仍停留在意图配置页，仍处于**编辑模式**，改动**保留**在本地草稿中（如阈值输入框仍为改动后的值）。
4. 步骤 5（点「确定」）→ `onOk: () => next()`：放行跳转，URL 变为目标模块（如 `/ai-cache-rules`），且不再命中 `/intent-config`。
5. 全程**不产生** `PUT /intent-config` 写请求：拖拽/改动都是本地草稿，离开时直接丢弃，后端配置未被修改。

#### 测试数据

- 管理员账号：`role=system_admin`（`conf.json` 默认账号）
- 已发布配置：`min_confidence` 取**环境快照值**（自动化前置经 `GET /intent-config` 读得），问题列表可为空数组
- 改动值（自动化）：`快照值 ≠ 0.6 ? 0.6 : 0.8`——避免环境阈值恰为默认值时「改动后仍脏」的前提失真
- 跳转目标（自动化）：侧栏「功能增强 / 消费方管理」下第一个可见的其它模块菜单（AI缓存规则 → `/ai-cache-rules`、流量镜像规则 → `/traffic-mirror-rules`、AI上下文压缩 → `/ai-context-rules`、批量任务 → `/batches`、API Key 管理 → `/api-key`）
- **数据策略（自动化）**：本 spec 全程只改本地草稿、**零写入**（用例内以请求监听断言无 `PUT /intent-config`）；`beforeAll` 用独立 admin context（`storageState=auth.json`）读环境快照，**仅当环境为未发布（404）**时才 `PUT` 造数 `{ min_confidence: 0.6, questions: [] }` 并在 `afterAll` 还原，环境已发布则直接复用、不造数不清理。

#### 补充说明

- 「取消后 URL 不变」的实现依据：`beforeRouteLeave` 的 `onCancel` 调用 `next(false)` 中断导航，vue-router 仅在守卫放行（`next()`）后才 `updateRoute` 改写 URL，故确认框弹出期间与取消之后 URL 均保持原值。自动化对「点击前 URL」逐字比对（非仅断言 `toContain`）。
- 侧栏菜单文案取自 i18n `nav.*`（`src/i18n/zh.js:180-185`：功能增强 / AI缓存规则 / 流量镜像规则 / 意图配置 / AI上下文压缩），菜单树来自后端 `meta`（节点结构见 `ai-gateway-runtime/conf/nav_tree.toml`）；`sidebarNav.openDefauleMenu()` 会展开全部一级子菜单，故目标菜单项无需先展开父级。
- 三个兄弟模块（AI 缓存 / 流量镜像 / AI 上下文）在 `docs/<module>/02-功能测试用例/07-拖拽排序与离开拦截.md` 的离开拦截用例（`DR-04`）走同一套断言口径与同一串文案；本模块的差异点是**改动来源为全局阈值**（单例资源、无规则数组，故无拖拽排序用例）。

### IC-DR-02：退出编辑模式二次确认

**功能模块**: 全局配置与双模式
**优先级**: P0
**用例编号**: IC-DR-02
**OpenAPI**: `GET /intent-config`（退出编辑模式会重新 `GET` 回填，全程不写后端）

#### 前置条件

1. 已进入意图配置页面（视图模式，已发布）。
2. 分别构造两种状态：① 进入编辑模式后**不做任何改动**；② 进入编辑模式后**改动全局最小置信度**（或问题列表）。

#### 测试步骤

1. 状态 ①：点击「退出编辑模式」按钮，观察是否弹出确认框、页面是否回到视图模式。
2. 状态 ②：点击「退出编辑模式」按钮，观察是否弹出确认框；确认框弹出后观察页面模式。
3. 在确认框中点击「确定」，观察提示文案、页面模式与全局阈值取值。

#### 预期结果

1. 状态 ①（`isDirty` 为假）：**不弹**确认框，直接退出编辑模式；右上角恢复为「进入编辑模式」，全局阈值回到纯文案展示且等于快照值。
2. 状态 ②（`isDirty` 为真）：弹出确认框，标题「信息提示」、正文「当前有未提交的改动，退出编辑模式将丢弃这些改动，确认退出？」；**确定前仍停留编辑模式**（改动未被丢弃）。
3. 点击「确定」（`onOk` → `performExitEditMode()`）：
   - 出现提示「已退出编辑模式」（`intentConfig.exitDone`）；
   - 页面回到视图模式（右上角恢复「进入编辑模式」、「添加问题」消失）；
   - 全局「最小置信度」**回滚为进入编辑模式时的快照值**（本地改动被丢弃），并重新 `GET /intent-config` 回填；
   - 全程不产生 `PUT /intent-config` 写请求（丢弃的是本地草稿，不是回写后端）。

#### 测试数据

- 管理员账号：`role=system_admin`
- 快照值：自动化前置经 `GET /intent-config` 读环境真实 `min_confidence`，回滚断言比对**同一快照值**（不硬编码 0.6）
- 改动值：`快照值 ≠ 0.6 ? 0.6 : 0.8`
- **数据策略（自动化）**：与 IC-DR-01 同一 spec 的 `beforeAll` / `afterAll`；本期用例零写入，环境已发布时不造数。

#### 补充说明

- 本用例是既有 IC-L-11（未修改退出）与 IC-L-12（已修改确认回滚）的**合并专项**：IC-L-11/12 已在 `tests/intent-config/test_01_intent_config_global_mode.spec.js` 覆盖（断言版本文案），本用例额外钉住三点——① 确认框正文按 `.ivu-modal-confirm-body` **精确取值**；② 回滚目标用环境快照而非硬编码阈值；③ 全程无 `PUT` 写入。二者可同时存在，不互相替代。
- 退出编辑模式链路（`index.vue:373-396`）：`exitEditMode()` → `isDirty ? $Modal.confirm(...) : performExitEditMode()`；`performExitEditMode()` 回滚 `minConfidence` / `questions` 后 `fetchConfig()` 重新拉取。
- 与 IC-DR-01 的区别：本用例的确认框由「退出编辑模式」按钮触发（`onOk` 回滚并留在本页），IC-DR-01 由**应用内路由跳转**触发（`onOk` 放行跳走）；两者共用同一文案 key。
