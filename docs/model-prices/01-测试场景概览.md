# 模型定价（Model Prices）模块 - 测试场景概览

## 模块概述

模型定价管理模块负责维护 AI 网关中各个 Provider / 模型的定价信息，是计费、用量统计、成本分析的基础配置数据。对应 API 端点：`/model-prices`。

| 功能区域 | 说明 |
| --- | --- |
| 模型定价列表 | 分页展示所有模型定价记录，支持按 provider、mode 筛选，按 model 搜索，支持分页 |
| 单条 CRUD | 新增、编辑、删除单条模型定价记录，字段含 provider（可下拉选择 / 手写的自动补全框）/model/base_model/mode/prices 等 |
| 详情页 | 点击某条记录查看全部字段详情，由「基本信息 / 限制对象 / 价格 / 元数据」四个 Card 组成；创建/更新时间位于「基本信息」Card 底部 |
| YAML 导入 | 支持通过 YAML 文件批量导入模型定价，支持 replace（全量替换，默认）与 merge（增量合并）两种模式 |
| 分时段价格 | 价格 Card 双配置块：默认价格（prices，必填）+ 分时段价格（tier_prices.peak，可选）；未命中 tier 时 fallback 默认价格 |
| 字段校验 | 必填、长度、枚举、非负、唯一性等完整校验矩阵 |

记录唯一性约束：`(provider, model, mode)` 三元组必须唯一。

---

## 配置顺序 / 依赖关系

模型定价为**独立数据模块**，与模型服务商**不强关联**：不要求先创建服务商，也不阻塞集群配置。`provider` 字段通常填服务商名以便计费归集，但仅为软关联。真正的强依赖链路是：**先创建模型服务商 → 集群「大模型配置」才能引用该服务商**（模型定价不在这条必选链路上）。

```text
（主链路 · 强依赖）
① 配置模型服务商（Providers） → ② 集群大模型配置引用服务商（Clusters） → ③ 路由规则 / 全链路

（独立模块 · 软关联）
模型定价（Model Prices）    为 provider / 模型维护默认价格 + 分时段价格，供计费 / 报表 / 成本分析；
                            provider 通常填服务商名（可选，不强校验）；删除服务商不级联删除定价
```

**依赖关系说明**：

| 关系 | 说明 |
| --- | --- |
| Model Prices 与 Providers（软关联，非强依赖） | 定价 `provider` 字段通常填服务商名（非必填）；服务商列表「查询模型价格」直达本模块并自动打开详情；删除服务商**不级联删除**定价记录 |
| Model Prices 与 Clusters（数据对应，非配置依赖） | 集群转发模型与服务商模型一致时，定价记录用于该模型的计费；定价缺失不影响集群配置 |
| 下游 | 计费 / 报表 / 成本分析依赖本模块价格数据准确性 |

- **可独立使用**：不强制要求服务商存在，可直接创建 / 编辑 / 删除定价记录（YAML 导入可独立初始化）
- **推荐流程**：先建服务商 → 再配置定价（保证 provider 名称一致，便于计费归集），但**不阻塞**集群配置

### 场景七：为服务商模型配置定价（跨模块，软关联）

**场景描述**：管理员按真实操作习惯，**为已创建的模型服务商**的模型配置模型定价（provider 关联服务商名，含默认价格与分时段价格），再从服务商列表直达定价详情；主链路上集群「大模型配置」引用服务商（先建服务商 → 再配集群），验证定价记录与集群转发模型的数据对应关系，以及服务商删除后定价记录的保留行为。定价为独立数据模块，**不强关联服务商**，本场景仅验证真实流程下的数据对应与软关联行为。

| 步骤 | 操作 | 对应编号 | 优先级 |
| --- | --- | --- | --- |
| 1 | 前置：已创建模型服务商（含探测模型） | PR-C-01 | P0 |
| 2 | 新增定价：provider 填服务商名，model 填服务商模型，配置默认价格 | MP-LINK-01 | P0 |
| 3 | 为同一模型配置分时段价格（忙时 peak） | MP-T-01 / MP-T-07 | P0 |
| 4 | 从服务商列表「查询模型价格」直达并自动打开该定价详情 | MP-LINK-02 / PR-L-11 | P0 |
| 5 | （主链路）集群「大模型配置」引用该服务商，转发模型选择该模型（数据对应） | MP-LINK-03 / RM-BC-71 | P1 |
| 6 | 删除服务商后，该模型定价记录保留（计费数据不丢失） | MP-LINK-04 / PR-LINK-08 | P1 |

**测试目标**：验证模型定价的 provider 软关联、直达跳转、与集群转发模型的数据对应，及删除服务商后的数据保留；确认定价**不阻塞**集群配置（主链路为 服务商 → 集群），与 `model-prices.md` / `providers.md` 接口一致。
