# 模型定价模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。

> 变更记录（2026-08-27）：
>
> - 新增/编辑表单「提供商」字段由纯文本输入改为**可下拉选择 / 手写的自动补全框**（候选来自 `GET /providers/actions/get-provider-names`），「模型名」仍为手写输入；相应用例 MP-C-01、MP-LINK-01、MP-V-01-1、MP-V-02-1 已同步。
> - 详情页「创建时间 / 更新时间」由独立时间戳 Card 并入「基本信息」Card 底部；用例 MP-D-01 已同步。
