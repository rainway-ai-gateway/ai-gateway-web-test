## 1. 列表页用例

### MP-L-01：列表页加载与数据展示

**功能模块**: 列表页  
**优先级**: P1  
**用例编号**: MP-L-01

#### 前置条件

- 系统中已存在至少 1 条模型定价记录

#### 测试步骤

1. 管理员登录系统，进入左侧菜单「模型定价」页面
2. 观察页面加载状态与表格内容

#### 预期结果

1. 页面成功加载，URL 包含 `/model-prices`
2. 调用 `GET /model-prices` 接口，返回 200
3. 表格展示列至少包含：Provider、Model、Base Model、Mode、Prices、创建时间（create_time）、更新时间（update_time）、操作列
4. 表格中每行数据与接口返回 `data.list` 中的对应字段值一致（含 `create_time` / `update_time`，与接口 Unix 时间戳转换后的日期时间一致，秒级精度）
5. 分页栏显示正确的总条数（与接口 `data.total` 一致）

## 2. CRUD 用例

### MP-C-01：创建模型定价成功

**功能模块**: CRUD  
**优先级**: P0  
**用例编号**: MP-C-01

#### 前置条件

- 不存在待创建的 (provider, model, mode) 组合

#### 测试步骤

1. 进入模型定价列表页
2. 点击「新增」按钮，打开新增表单弹窗
3. 填写如下字段：
   - Provider: `test-provider`（Provider 为可下拉选择 / 手写的自动补全框，候选来自 `GET /providers/actions/get-provider-names`；可直接输入或从下拉选中）
   - Model: `test-model`（手写输入）
   - Base Model: `test-base-model`
   - Mode: `chat`
   - Prices: 添加 `input_cost_per_token = 0.00003`
4. 点击「确定」提交

#### 预期结果

1. 点击「确定」后调用 `POST /model-prices`，请求体字段与填写值一致
2. 接口返回 200，返回体包含新记录的 `id`
3. 弹窗关闭，列表自动刷新，新记录出现在列表中
4. 新记录的 provider / model / base_model / mode 字段值与提交值一致
5. 页面显示成功提示（如「创建成功」）

---

### MP-C-02：编辑模型定价成功

**功能模块**: CRUD  
**优先级**: P0  
**用例编号**: MP-C-02

#### 前置条件

- 列表中存在一条可编辑的模型定价记录（id 已知）

#### 测试步骤

1. 进入模型定价列表页
2. 点击目标记录操作列的「编辑」按钮
3. 观察表单回显数据是否正确
4. 修改部分字段（如 prices 中的 `input_cost_per_token` 改为 `0.00005`）
5. 点击「确定」提交

#### 预期结果

1. 编辑弹窗打开时调用 `GET /model-prices/{id}`，表单字段与接口返回值一致
2. 点击「确定」后调用 `PUT /model-prices/{id}`，请求体包含修改后的字段值
3. 接口返回 200，弹窗关闭，列表刷新
4. 列表中对应记录的字段值已更新，与提交值一致
5. 页面显示成功提示（如「修改成功」）

---
