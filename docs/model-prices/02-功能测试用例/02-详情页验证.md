## 3. 详情页验证

### MP-D-01：详情页全字段与接口数据一致性

**功能模块**: 详情页  
**优先级**: P0  
**用例编号**: MP-D-01

#### 前置条件

- 系统中存在一条字段完整的模型定价记录，且各字段均有值（含 capabilities、supported_parameters、limits、prices 多个键、metadata 等）

#### 测试数据参考（接口 GET /model-prices/{id} 返回体示例）

```json
{
  "id": 12345,
  "provider": "openai",
  "model": "gpt-4-turbo",
  "base_model": "gpt-4",
  "mode": "chat",
  "capabilities": ["chat", "vision", "reasoning", "tools"],
  "supported_parameters": ["temperature", "top_p", "max_tokens", "stream"],
  "limits": {
    "context_window": 128000,
    "max_input_tokens": 128000,
    "max_output_tokens": 4096
  },
  "prices": {
    "input_cost_per_token": 0.00003,
    "output_cost_per_token": 0.00006,
    "cache_creation_input_token_cost": 0.000015,
    "cache_read_input_token_cost": 0.0000075
  },
  "price_currency": "RMB",
  "metadata": {
    "source": "https://openai.com/pricing",
    "notes": "2024 年最新定价"
  },
  "create_time": 1718000000,
  "update_time": 1719000000
}
```

#### 测试步骤

1. 管理员登录系统，进入「模型定价」列表页
2. 找到上述预置记录，点击「查看详情」（或点击行进入详情页）
3. 页面加载完成后，逐一比对详情页展示的字段值与接口返回值
4. 观察「基本信息」Card 的字段排布，确认「创建时间」「更新时间」位于该 Card 底部

#### 预期结果

布局说明：详情页由「基本信息」「限制对象（limits）」「价格」「元数据」四个 Card 组成；**创建时间（create_time）与更新时间（update_time）展示在「基本信息」Card 底部，不再单独作为独立时间戳 Card**。

字段比对（校验方式 = 文本/数值/数组逐项比对，与接口返回 JSON 一致）：

- **id**（文本一致）：与接口 `id` 相同（int64 原样展示）
- **provider**（文本一致）：与接口 `provider` 相同
- **model**（文本一致）：与接口 `model` 相同
- **base_model**（文本一致）：与接口 `base_model` 相同
- **mode**（文本一致，含中英文映射）：与接口 `mode` 相同（若 UI 显示为中文标签，需与枚举映射表一致，如 chat → 对话）
- **capabilities**（数组逐项比对，顺序不限）：标签/列表中展示的值集合与接口 `capabilities` 数组完全一致，不多不少
- **supported_parameters**（数组逐项比对，顺序不限）：标签/列表中展示的值集合与接口 `supported_parameters` 数组完全一致
- **limits.context_window**（数值一致）：与接口 `limits.context_window` 相同
- **limits.max_input_tokens**（数值一致）：与接口 `limits.max_input_tokens` 相同
- **limits.max_output_tokens**（数值一致）：与接口 `limits.max_output_tokens` 相同
- **prices.input_cost_per_token**（数值一致）：与接口 `prices.input_cost_per_token` 相同（小数精度一致）
- **prices.output_cost_per_token**（数值一致）：与接口 `prices.output_cost_per_token` 相同
- **prices 其他键**（键值对完全匹配）：所有 prices 的键与值均在详情页有对应展示，且与接口返回一致
- **price_currency**（文本一致）：固定为 `RMB`，与接口返回一致
- **metadata.source**（文本一致）：与接口 `metadata.source` 相同；若为 URL，应为可点击的链接
- **metadata.notes**（文本一致）：与接口 `metadata.notes` 相同
- **create_time**（时间戳转换一致）：与接口 `create_time` Unix 时间戳转换后的日期时间一致（秒级精度）
- **update_time**（时间戳转换一致）：与接口 `update_time` Unix 时间戳转换后的日期时间一致（秒级精度）

**整体预期**：

1. 进入详情页时调用 `GET /model-prices/{id}`，接口返回 200
2. 详情页展示的所有字段值均与接口返回的 JSON 字段值一一对应，无遗漏、无错配
3. 面包屑导航正确（如「模型定价 / 详情」），点击「返回列表」可回到列表页
4. 若存在「编辑」按钮，点击后跳转至编辑表单且回显数据与详情一致
