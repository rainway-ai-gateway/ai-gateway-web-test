## 5. 分时段价格（tier_prices）

> 对应接口：`model-prices.md` — `tier_prices` 字段（键为 tier name，初期仅 `peak`，值为价格对象；未命中 tier 时使用 `prices` 作为 fallback）。
> 变更背景（2026-08-25 Part II/III）：模型定价「价格」Card 合并展示两个同级配置块——**默认价格**（`prices`，必填）与**分时段价格**（`tier_prices.peak`，可选）。

### MP-T-01：价格 Card 双配置块

**功能模块**: 分时段价格  
**优先级**: P0  
**用例编号**: MP-T-01

#### 前置条件

- 打开模型定价创建 / 编辑抽屉

#### 测试步骤

1. 观察「价格」Card 布局

#### 预期结果

1. 「价格」Card 内为 `.price-config-group`，包含**两个同级并列**的 `.price-config-block`：
   - ① **默认价格**（`prices`）：必填
   - ② **分时段价格**（`tier_prices.peak`）：可选
2. 文案为「默认价格」「分时段价格」（非「价格对象」「分时段价格对象」）
3. 基础信息（模型能力、支持参数等）不单独成 Card，与价格区同抽屉展示

### MP-T-07：提交 tier_prices 结构

**功能模块**: 分时段价格  
**优先级**: P0  
**用例编号**: MP-T-07

#### 前置条件

- 打开模型定价创建抽屉，填写默认价格 + 分时段价格

#### 测试步骤

1. 填写默认价格 `prices` 与分时段价格 `tier_prices.peak` 各若干字段
2. 提交并抓取请求体

#### 预期结果

1. 提交调用 `POST /model-prices`（创建）或 `PUT /model-prices/{id}`（编辑），返回 200
2. 请求体结构示例：

   ```json
   {
     "provider": "deepseek",
     "model": "deepseek-v3",
     "base_model": "deepseek-v3",
     "mode": "chat",
     "prices": { "input_cost_per_token": 0.000002, "output_cost_per_token": 0.000008 },
     "tier_prices": { "peak": { "input_cost_per_token": 0.000004, "output_cost_per_token": 0.000016 } }
   }
   ```

3. `tier_prices` 键为 tier name（`peak`）；值对象键名与 `prices` 枚举一致
4. 请求体不含 `price_currency`（固定 RMB）、`id`、`create_time` / `update_time`
