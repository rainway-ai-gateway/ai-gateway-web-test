## 9. 只读管理员视角（写操作隐藏）

> 变更背景：后端引入「系统管理员（只读）」角色（`role` 枚举取代 `is_admin`，新增 `system_admin_readonly`）；只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。
>
> 前端实现：全局 Vue 自定义指令 `v-has`，只读登录态给元素加 `.v-has-hidden { display:none !important; }`（`src/utils/directive.js`、`src/assets/css/global.less`）。
>
> 接口 / 原型依据：`ai-gateway-web/design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md` §3.4（`pages/model-prices.html` 只读保留「详情」，隐藏「新增定价」「YAML 导入」等写操作）。  
> 归属场景：场景九：只读管理员视角（写操作隐藏）。

**管理员视角对照**：管理员（`role === 'system_admin'`）可见「新增定价」「YAML 导入」及操作列写入口；只读视角下这些写操作均隐藏。

---

### MP-RO-01：只读视角列表工具栏写按钮隐藏

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: MP-RO-01  
**设计依据**: `src/modules/ModelPrices/index.vue`（`.action-bar` 整体挂 `v-has`，含「+ 新增定价」「YAML 导入」）

#### 前置条件

- 以「系统管理员（只读）」角色登录（`role === 'system_admin_readonly'`）
- 进入模型定价列表页

#### 测试步骤

1. 观察页头工具栏（`.action-bar`）
2. 确认「+ 新增定价」按钮是否存在
3. 确认「YAML 导入」按钮是否存在
4. 尝试通过页面定位 / 键盘聚焦访问上述写操作入口

#### 预期结果

1. 「+ 新增定价」按钮不可见（`display:none !important`）
2. 「YAML 导入」按钮不可见
3. 仅保留只读相关内容（筛选、搜索、分页等）
4. 无任何写操作入口可被触发

#### 测试数据

- 只读账号：`viewer` / `viewer123`（`role=system_admin_readonly`，见 `utils/readonly.js` 的 `READONLY_USER`）
- 管理员账号：`conf.json` 配置的 `system_admin`（对照组）
- 数据策略：**复用环境数据、不造数**——本用例只断言页头写入口可见性，不依赖列表具体记录

#### 补充说明

- 对照管理员视角：管理员可见「+ 新增定价」与「YAML 导入」。
- 隐藏实现：`.action-bar` 整体挂全局指令 `v-has`（`src/modules/ModelPrices/index.vue`），只读视角加 `.v-has-hidden`，元素仍在 DOM 中；自动化用 `expectVHasHidden` 同时钉住「仍在 DOM + 带该 class + 不可见」，并对两个写按钮补一次 `trial` 点击检查（`expectWriteEntryUntriggerable`），落实预期 4「无任何写操作入口可被触发」。

### MP-RO-02：只读视角列表操作列写操作隐藏、只读入口「详情」保留

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: MP-RO-02  
**设计依据**: `pages/model-prices.html` 只读保留「详情」（隐藏新增 / 编辑 / 删除等写操作）

#### 前置条件

- 以「系统管理员（只读）」角色登录
- 列表中存在模型定价记录

#### 测试步骤

1. 观察某行操作列
2. 确认「详情」入口是否存在且可点击
3. 确认「编辑」「删除」等写操作是否展示
4. 点击「详情」进入详情页

#### 预期结果

1. 操作列中写操作入口（如「编辑」「删除」）不展示
2. 只读入口「详情」保留且可点击
3. 点击「详情」可正常进入该记录详情页

#### 测试数据

- 只读账号：`viewer` / `viewer123`（`role=system_admin_readonly`）
- 管理员账号：`conf.json` 配置的 `system_admin`（对照组）
- 列表记录：**复用环境既有数据、不造数**——优先取环境基线 `deepseek / deepseek-v3 / chat`（`test-files/model-prices/model-list.yaml` 基线含该条），不存在时回退为列表首条；自动化以 (provider, model, mode) 三重文本定位该行，全程无写入、无需清理
- 环境说明：该记录可能被同目录 spec（YAML 导入 / 分页）的基线重置（replace 模式重建表，`id` 会变）重建，故自动化按 `id` 读不到时回退按组合复查

#### 补充说明

- 对照管理员视角：管理员操作列可见写操作入口；只读视角仅保留「详情」。
- **文案偏差**：本文档称只读入口为「详情」，UI 实际按钮文案为「查看」（`com.see`，`ai-gateway-web src/i18n/zh.js`），两者为同一只读入口；自动化按 UI 实际文案「查看」定位。
- 隐藏实现：操作列由 JS 分支 `store.isReadonly()` 收敛（`src/modules/ModelPrices/index.vue` 的 `columns` render），只读视角下**根本不渲染**「编辑」「删除」，故自动化用 `expectHidden`（对应「不渲染」而非 `v-has` 类隐藏）。

### MP-RO-03：只读视角详情页纯只读、无写操作入口

**功能模块**: 只读视角  
**优先级**: P0  
**用例编号**: MP-RO-03  
**设计依据**: `src/modules/ModelPrices/index.vue` 详情抽屉为纯只读展示

#### 前置条件

- 以「系统管理员（只读）」角色登录
- 已通过列表进入某条记录详情

#### 测试步骤

1. 查看详情页全部 Card（基本信息 / 限制对象 / 价格 / 元数据）
2. 确认是否存在任何写操作按钮（编辑 / 删除 / 保存 / YAML 导入等）
3. 核对详情字段与接口返回一致

#### 预期结果

1. 详情页仅展示字段，无任何写操作入口
2. 页面不出现「编辑」「删除」「保存」等按钮
3. 详情字段值与 `GET /model-prices/{id}` 返回一致

#### 测试数据

- 只读账号：`viewer` / `viewer123`（`role=system_admin_readonly`）
- 管理员账号：`conf.json` 配置的 `system_admin`（对照组，详情抽屉本身即纯只读，两视角展示一致）
- 列表记录：**复用环境既有数据、不造数**（同 MP-RO-02：优先 `deepseek / deepseek-v3 / chat`，缺失时回退列表首条）
- 字段比对基准：只读视角下以自身会话调 `GET /model-prices/{id}`（读接口对只读角色放行）取基准值，与详情抽屉渲染值逐项比对

#### 补充说明

- 详情页本身为只读抽屉，不含写操作，只读视角下与管理员视角展示一致。
- 实现依据：详情抽屉组件 `src/modules/ModelPrices/components/ModelPriceView.vue` 为纯展示（无任何 `Button`），故断言取「内容区按钮数 = 0」+「抽屉内无 `编辑 / 删除 / 保存 / 导入` 按钮」；字段一致性覆盖基本信息 4 字段（provider / model / base_model / mode）、价格（数值等价比对）与限制对象（键序无关 map 比对）。
