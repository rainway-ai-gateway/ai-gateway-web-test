# 模型服务商（Providers）模块 - 测试场景概览

## 模块概述

模型服务商模块负责维护 AI 网关的第三方模型服务商（Provider），是集群 LLM 配置、模型定价的**上游基础数据**。对应 API 端点：`/providers`。

对应接口文档：`design-docs/api-define/OpenAPI接口定义/providers.md`；对应原型：`design-docs/prototype-design/pages/providers.html`。

| 功能区域 | 说明 |
| --- | --- |
| 服务商列表 | **全量拉取**（`GET /providers` 不传 `page` / `page_size`），前端筛选（名称 / 描述 / 协议 / 模型）+ 前端分页 |
| 创建 / 编辑 | 基本信息（名称、描述）、实例池（IP / 服务商域名两种形态）、模型服务配置（协议、模型列表接口、模型发现回填 + 手动输入）、服务鉴权 Keys |
| 详情页 | 基本信息（含创建 / 更新时间）、实例池、模型服务配置、服务鉴权 Keys（Key 值脱敏）、分段计价配置 Card |
| 分段计价配置 | 独立 Drawer：时区（IANA 文本输入 + `Intl` 校验）、计价时段（忙时 peak）、时间段（适用时段 Checkbox + 快捷链接 + 时间输入），提交 `PUT /providers/{name}/pricing-tiers` |
| 删除 | 被集群引用时返回 `409` 不可删除；存在 `/model-prices` 同名记录不阻塞删除 |
| 模型价格跳转 | 列表操作列「查询模型价格」→ 跳转模型定价列表并自动打开详情 |

**核心变更依据**（2026-08-24 / 2026-08-25 / 2026-08-27 UI 变更）：

- Provider 为新增独立对象，实例池 / 模型协议 / 模型发现端点 / Key 明文从 Cluster 迁入；Cluster 仅通过 `llm_config.provider` 引用。
- 列表改为**全量拉取 + 前端筛选/分页**；模型列 2 Tag + `+N`。
- 新增「分段计价配置」Drawer 与详情 Card；`tier_prices` 支持分段计价。
- 模型列表支持「获取」探测回填 + **手动输入**（`filterable + allow-create`）。

## 配置顺序 / 依赖关系

模块间**真实配置链路**（用户操作顺序，主链路为强依赖）：

```text
① 配置模型服务商（Providers）          基础数据：实例池 / 模型协议 / 模型发现端点 / Keys / 分段计价
        │ 服务商名称、探测到的模型、Keys
        ▼
② 集群大模型配置引用服务商（Clusters）  llm_config.provider 指向服务商 → 转发模型 / Keys 均引用服务商数据
        ▼
③ 路由规则 / 全链路                     将请求转发至集群实例池

（并行 / 独立，不进主链路）
模型定价（Model Prices）                独立数据模块：provider 字段通常填服务商名（软关联，非必填，不阻塞集群配置）
```

**依赖关系说明**：

| 关系 | 说明 |
| --- | --- |
| Providers → Clusters（**强依赖**） | **必须先创建服务商，才能配置集群**：集群「大模型配置」的所属服务商下拉、转发模型、Keys 均来自服务商数据；服务商不存在时集群无法完成大模型配置 |
| Providers → Model Prices（软关联） | 定价记录 `provider` 字段通常填服务商名（非必填、不强校验）；从服务商列表「查询模型价格」直达定价列表；服务商删除不级联删除定价 |
| Clusters → Providers 联动 | 修改服务商 `instance_pool` 会同步更新引用该 provider 的集群实例池；Key `name` 变更影响引用集群 |

- **无前置依赖**：服务商可独立创建、编辑、删除；模型定价可独立维护，与集群配置互不阻塞
- **被引用约束**：已被集群引用的服务商不可删除（409）

### 场景七：搭建可用的 AI 业务集群（服务商 → 集群联动，定价软关联）

## 测试数据准备

| 数据类别 | 准备内容 | 用途 |
| --- | --- | --- |
| 基础服务商 | name=deepseek，description 有值，instance_pool 多实例，model_protocols=[openai]，keys 2 个 | 列表 / 详情 / 编辑 / 删除 |
| 域名模式服务商 | 仅服务商域名形态，提交后 instance_pool 单实例 port=443 weight=100 | 创建用例 |
| 被引用服务商 | 已被某集群 `llm_config.provider` 引用 | 删除 409 |
| 模型定价同名记录 | `/model-prices` 中存在 provider=该服务商名的记录 | 删除不阻塞 |
| 分段计价配置 | 时区 Asia/Shanghai，peak 含 2 个时间段 | 分段计价回显 / 详情 Card |
| 联动集群 | 引用 deepseek 服务商的集群（转发模型 / Keys 已配置） | 跨模块联动（同步更新 / 删除 409） |
| 联动定价 | provider=deepseek 的模型定价记录（含 tier_prices） | 跨模块联动（查询模型价格直达 / 删除保留） |

| 数据项 | 说明 | 示例值 |
| --- | --- | --- |
| name | ProviderName，1–64，字母/数字/`_`/`-`/`.`，首尾不能为 `.`/`-`/`_` | deepseek |
| description | 可选，0–256，不能含控制字符 | DeepSeek 官方 API |
| instance_pool | 必填 ≥1；addr 必填（Hostname）；port 1–65535；weight 0–100，至少一个 >0 | {addr: api.deepseek.com, port: 443, weight: 100} |
| model_protocols | 必填 ≥1 且不重复；枚举 openai / anthropic | ["openai"] |
| model_endpoint | schema http/https（默认 https）；uri 以 `/` 开头（默认 /v1/models） | {schema: https, uri: /v1/models} |
| models | 可选，元素非空不重复；可通过发现接口回填或手动输入 | ["deepseek-chat"] |
| keys | 可选；name 1–128 组内唯一；key 1–512 | {name: key-primary, key: sk-xxx} |
| time_zone | 合法 IANA 时区名 | Asia/Shanghai |
| tiers | 初期仅 peak；time_ranges 至少 1 个，end > start，组内不重叠 | [{name: peak, time_ranges: [...]}] |
