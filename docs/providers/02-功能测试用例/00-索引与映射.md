# 模型服务商模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。

用例覆盖 2026-08-24 / 2026-08-25 / 2026-08-27 UI 变更涉及的 Provider 模块全部交互；字段校验依据 `design-docs/api-define/OpenAPI接口定义/providers.md` §3 校验规则。
