## 1. 服务商列表

### PR-L-01：列表加载与全量拉取

**功能模块**: 服务商列表  
**优先级**: P0  
**用例编号**: PR-L-01

#### 前置条件

- 系统中存在 ≥3 个服务商（覆盖不同协议、多个模型、不同实例形态）

#### 测试步骤

1. 管理员登录，进入「资源管理 → 模型服务商」列表页
2. 观察列表加载过程中的网络请求
3. 检查表格列与数据展示

#### 预期结果

1. 列表请求为 `GET /providers`，**不携带** `page` / `page_size` / `model_protocol` 等分页或筛选 Query（对应变更：全量拉取 + 前端筛选）
2. 表格展示全部服务商记录；列包含：**名称、描述、协议、模型、操作**（对齐原型 `providers.html`）
3. 协议列为 `model_protocols` join 展示；模型列为 Tag 展示（2 个 + `+N`，见 PR-L-08）
4. 加载成功后列表正常渲染，无报错；再次点击「筛选 / 翻页」不触发列表请求（见 PR-L-02 / PR-L-07）

### PR-L-11：「查询模型价格」跳转与自动打开详情

**功能模块**: 服务商列表  
**优先级**: P0  
**用例编号**: PR-L-11

#### 前置条件

- 存在服务商；其中部分服务商在 `/model-prices` 有定价记录

#### 测试步骤

1. 点击某服务商行的「查询模型价格」
2. 在模型定价列表页观察筛选条件与详情打开行为

#### 预期结果

1. 跳转到模型定价列表并携带 `provider={name}&autoView=1`（对应接口 `/model-prices`，筛选该 provider）
2. 列表加载后**自动打开第一条**该 provider 定价记录的详情
3. 若该 provider 无定价记录，展示提示「未找到提供商 {provider} 的模型定价」，不打开详情、不报错
