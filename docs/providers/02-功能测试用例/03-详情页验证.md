## 3. 详情页验证

### PR-D-01：详情页全字段与接口数据一致性

**功能模块**: 详情页  
**优先级**: P0  
**用例编号**: PR-D-01  
**设计依据**: 原型 `providers.html`（详情抽屉）；`providers.md` §2.3 Provider 详情  

#### 前置条件

- 存在一条字段完整的服务商记录（含实例池多实例、多协议、多个 keys、已配置分段计价），且未被任何集群引用或已配置完整

#### 测试数据参考（接口 GET /providers/{provider_name} 返回体示例）

```json
{
  "name": "deepseek",
  "description": "DeepSeek 官方 API",
  "model_endpoint": { "schema": "https", "uri": "/v1/models" },
  "models": ["deepseek-chat", "deepseek-coder", "deepseek-reasoner"],
  "keys": [
    { "name": "key-primary", "key": "sk-aaaaaaaaaaaa" },
    { "name": "key-secondary", "key": "sk-bbbbbbbbbbbb" }
  ],
  "instance_pool": [
    { "name": "backend-1", "addr": "api.deepseek.com", "weight": 100, "port": 443 }
  ],
  "model_protocols": ["openai"],
  "time_zone": "Asia/Shanghai",
  "tiers": [
    { "name": "peak", "time_ranges": [
      { "weekdays": [1,2,3,4,5], "start": "09:00", "end": "12:00" },
      { "weekdays": [1,2,3,4,5], "start": "14:00", "end": "18:00" }
    ]}
  ],
  "create_time": 1716883200,
  "update_time": 1716883200
}
```

#### 测试步骤

1. 列表页点击「详情」，打开详情 Drawer
2. 逐一比对详情页各字段与接口返回值

#### 预期结果

区域比对（校验方式 = 文本 / 列表 / 脱敏逐项比对，与接口返回 JSON 一致）：

- **基本信息**：名称、描述、**创建时间 / 更新时间**（时间戳转换后展示，并入基本信息 Card，不再有独立「时间戳」Card）
- **实例池**：实例列表：地址 / 端口 / 权重（IP 或域名），与接口 `instance_pool` 一致；多实例逐行展示
- **模型服务配置**：模型协议（join 展示）、模型列表接口 schema / uri / addr:port、模型列表（tags），与接口一致
- **服务鉴权 Keys**：Key 名称 + **Key 值脱敏**（如 `sk-a****aaaa`，首尾保留少量字符中间掩码），不展示明文
- **分段计价配置**：时区、忙时（peak）、时间段表（适用时段 / 开始时间 / 结束时间），与接口 `time_zone` / `tiers` 一致

**整体预期**：

1. 进入详情调用 `GET /providers/{name}` 返回 200
2. 全部字段展示值与接口 JSON 一一对应，无遗漏、无错配
3. 详情不渲染禁用输入框（只读卡片形态）
4. 面包屑 / 返回列表正确

### PR-D-04：详情页 K8s 分支展示

**功能模块**: 详情页  
**优先级**: P0  
**用例编号**: PR-D-04  
**设计依据**: `src/modules/Providers/components/ProviderView.vue` `isK8sPool` 分支；`ui-code-changes.md` §3.3 缺陷 B / §3.4 第 4 点 / §4.3  
**OpenAPI**: `providers.md` §1 数据模型（`instance_source=k8s_pool` 模式响应示例）

#### 前置条件

- 存在 `instance_source=k8s_pool` 的服务商（`k8s_pool_name` 有值，`k8s_instance_pool` 含 ≥1 个镜像实例）

#### 测试数据参考（`GET /providers/{provider_name}` 返回体 K8s 分支）

```json
{
  "name": "svc-a-provider",
  "instance_source": "k8s_pool",
  "k8s_pool_name": "svc-a",
  "instance_pool": [],
  "k8s_instance_pool": [
    {"addr": "10.0.0.1", "port": 8000, "weight": 100},
    {"addr": "10.0.0.2", "port": 8000, "weight": 100}
  ]
}
```

#### 测试步骤

1. 列表页点击该服务商「详情」，打开详情 Drawer
2. 查看「服务商实例池」Card 的实例来源分支
3. 查看 K8s 池名称与镜像实例列表

#### 预期结果

1. 「服务商实例池」Card 正确进入 **K8s 分支**（不得因变量未定义而失效，即原型缺陷 B 不得复现）
2. 展示「实例来源 = `K8s 实例池（k8s_pool）`」
3. 展示「K8s 池名称 = `{k8s_pool_name}`」
4. 展示**只读镜像实例列表**（列：IP 地址 / 端口 / 权重），数据取 `k8s_instance_pool`，与 `GET /providers/{name}` 返回一致
5. `k8s_instance_pool` 为空数组时展示空态「暂无镜像实例（池不存在 ≡ 零实例）」
6. 不渲染人工实例表单 / 编辑控件（详情为只读卡片形态）
