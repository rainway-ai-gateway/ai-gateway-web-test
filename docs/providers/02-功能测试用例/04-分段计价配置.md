## 4. 分段计价配置

> 对应接口：`PUT /providers/{provider_name}/pricing-tiers`（Body：`{time_zone, tiers:[{name:"peak", time_ranges:[...]}]}`）。
> 时间段语义：`weekdays` 为空数组表示每天；`start`/`end` 为 `HH:MM`，`end > start`；同 tier 内时间段不得重叠。

### PR-T-01：打开分段计价 Drawer

**功能模块**: 分段计价配置  
**优先级**: P0  
**用例编号**: PR-T-01

#### 前置条件

- 存在至少 1 个服务商

#### 测试步骤

1. 服务商列表点击某行「分段计价配置」
2. 观察 Drawer 结构

#### 预期结果

1. 打开**独立 Drawer**，标题固定为「分段计价配置」
2. 顶部展示**只读服务商名**
3. 表单包含：时区（文本输入）、计价时段（只读「忙时」Tag + `peak` 代码）、时间段表格
4. 已配置过的时间段正确回填（见 PR-T-09）；未配置时默认一行 `weekdays=[1,2,3,4,5]`、`09:00-12:00`，时区默认 `Asia/Shanghai`

### PR-T-02：时区输入与 IANA 校验

**功能模块**: 分段计价配置  
**优先级**: P0  
**用例编号**: PR-T-02

#### 前置条件

- 打开分段计价 Drawer

#### 测试步骤

1. 时区输入框依次输入合法时区 `Asia/Shanghai`、`America/New_York`、非法值 `abc/123`、留空
2. 提交

#### 预期结果

1. 控件为**文本输入框**（非下拉），占位如 `Asia/Shanghai`
2. 校验调用 `isValidIanaTimeZone()`（`Intl.DateTimeFormat(undefined, {timeZone})` 不抛错即合法）
3. 合法时区可提交；非法时区提示「时区须为合法 IANA 时区名」，提交被拦截
4. 留空提示「请填写时区」
5. 极少数时区可能因浏览器 / 后端时区库版本差异导致结果不一致时，以后端 API 422 为准

### PR-T-06：时间格式校验（HH:MM、end > start）

**功能模块**: 分段计价配置  
**优先级**: P0  
**用例编号**: PR-T-06

#### 前置条件

- 打开分段计价 Drawer

#### 测试步骤

1. 开始时间 / 结束时间输入非法格式（如 `9:00`、`25:00`、`12:60`）
2. 输入合法格式但 `end <= start`（如 12:00-09:00、09:00-09:00）

#### 预期结果

1. 非 `HH:MM` 格式提示「…须为 HH:MM 格式」
2. 小时 0-23、分钟 0-59 越界提示「…时间无效」
3. `end <= start` 提示「结束时间须大于开始时间」，提交被拦截
4. 跨午夜须拆成两段（如 22:00-23:59 + 00:00-06:00），单段跨午夜 `end <= start` 不合法

### PR-T-07：同 tier 时间段重叠校验

**功能模块**: 分段计价配置  
**优先级**: P0  
**用例编号**: PR-T-07

#### 前置条件

- 打开分段计价 Drawer

#### 测试步骤

1. 添加两个时间段：`09:00-12:00` 与 `10:00-11:00`（适用时段有交集，如均为工作日）
2. 提交
3. 改为不重叠（`09:00-12:00` 与 `13:00-18:00`）再提交

#### 预期结果

1. 重叠时段提交被拦截，提示「第 N 与第 M 个时间段存在重叠」
2. 重叠判定按「适用时段有交集 + 时间区间相交」计算；不同适用时段（如工作日 vs 周末）即使时间相交也不算重叠
3. 不重叠时提交通过

### PR-T-08：提交 PUT pricing-tiers

**功能模块**: 分段计价配置  
**优先级**: P0  
**用例编号**: PR-T-08

#### 前置条件

- 打开分段计价 Drawer，填写合法数据

#### 测试步骤

1. 填写合法时区与时间段（如时区 `Asia/Shanghai`，peak 含 2 段）
2. 点击「提交」
3. 抓取请求体

#### 预期结果

1. 调用 `PUT /providers/{provider_name}/pricing-tiers`，返回 200
2. 请求体结构：

   ```json
   {
     "time_zone": "Asia/Shanghai",
     "tiers": [
       { "name": "peak", "time_ranges": [
         { "weekdays": [1,2,3,4,5], "start": "09:00", "end": "12:00" },
         { "weekdays": [1,2,3,4,5], "start": "14:00", "end": "18:00" }
       ]}
     ]
   }
   ```

3. 全选 / 全不选时 `weekdays` 提交为 `[]`
4. 提交成功关闭 Drawer，服务商详情「分段计价配置」Card 同步更新
