## 5. 删除与引用保护

### PR-DEL-01：删除服务商-成功

**功能模块**: 删除与引用保护  
**优先级**: P0  
**用例编号**: PR-DEL-01

#### 前置条件

- 存在一个**未被任何集群引用**的服务商

#### 测试步骤

1. 列表页点击该服务商「删除」
2. 在确认弹窗中点击「确认」
3. 观察请求与列表

#### 预期结果

1. 弹出删除二次确认（展示服务商名称）
2. 确认后调用 `DELETE /providers/{name}`，返回 200，`Data` 为 null
3. 删除成功后关闭弹窗，列表**全量刷新**，该服务商消失
4. 后续「删除」错误场景（被引用）见 PR-DEL-02

### PR-DEL-02：删除服务商-被集群引用 409

**功能模块**: 删除与引用保护  
**优先级**: P0  
**用例编号**: PR-DEL-02

#### 前置条件

- 存在一个被某集群 `llm_config.provider` 引用的服务商

#### 测试步骤

1. 列表页点击被引用服务商「删除」
2. 确认删除

#### 预期结果

1. 后端返回 `409 Conflict`（校验无 cluster 引用）
2. 前端提示不可删除（如「该服务商已被集群引用，无法删除」），**不**关闭确认框 / 列表不变
3. 服务商仍保留在列表中，其余操作（详情 / 编辑）不受影响

### PR-DEL-04：删除服务商-有 model-prices 记录不阻塞

**功能模块**: 删除与引用保护  
**优先级**: P1  
**用例编号**: PR-DEL-04

#### 前置条件

- 存在一个未被集群引用、但 `/model-prices` 中有同名 provider 记录的服务商

#### 测试步骤

1. 删除该服务商并确认

#### 预期结果

1. 删除**成功**（`/model-prices` 同名记录**不再作为阻塞条件**）
2. 返回 200；列表刷新后服务商消失
3. 模型定价列表中的同名 provider 记录不受影响（价格归集标识仍保留）
