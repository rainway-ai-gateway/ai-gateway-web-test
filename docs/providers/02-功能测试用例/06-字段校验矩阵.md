### PR-V-21：k8s_pool 模式 instance_pool 休眠保留

**功能模块**: 字段校验  
**优先级**: P1  
**用例编号**: PR-V-21  
**设计依据**: `ProviderUpsert.vue` `buildPayload`（K8s 分支不加 `instance_pool`）；`ui-code-changes.md` §2.4 / §3.4  
**OpenAPI**: `providers.md` §2.4（有效池定义与 PATCH 省略保留语义）

#### 前置条件

- 已存在 `instance_source=instance_pool` 且含多实例的服务商

#### 测试步骤

1. 编辑该服务商，切换「实例来源」为 `k8s_pool`，填写池名并提交，抓包
2. 再次编辑，切换回 `instance_pool`，观察人工实例
3. 构造 `PATCH /providers/{name}` 请求，传 `instance_source=k8s_pool` 且**省略** `instance_pool`

#### 预期结果

1. 切到 `k8s_pool` 时提交体**省略** `instance_pool`（不清空），服务端保留原 `instance_pool`
2. 切回 `instance_pool` 时原人工实例**恢复可编辑、原值保留**
3. **有效池 = `instance_source == "k8s_pool" ? k8s_instance_pool : instance_pool`**；K8s 模式下 `instance_pool` 休眠、不参与生效
4. 接口层传 `instance_source=k8s_pool` 且省略 `instance_pool` 返回 **200**，且响应中 `instance_pool` 原值保留
