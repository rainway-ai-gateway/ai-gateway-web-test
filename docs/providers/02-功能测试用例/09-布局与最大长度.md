# 服务商管理 - 布局与最大长度

> **背景（2026-11-02）**：项目无视觉回归测试（见 [覆盖缺口清单 §27](../../覆盖缺口清单.md)）。本文件用 **DOM 指标断言**（`utils/layout.js`）覆盖服务商满载（名称 64 + 描述 256）场景。
>
> **断言工具**：`utils/layout.js`（`expectNoHorizontalOverflow` / `expectCellLineCap` / `expectFooterVisibleInViewport` / `readLayoutMetrics`）。

## PR-LAY-01 列表行满载布局（P1）

- **测试数据**：API 创建服务商（名称 64、描述 256 ASCII）；afterEach 清理。
- **步骤**：
  1. 列表页定位目标行（跨分页搜索）；
  2. 列表表格容器（`.ivu-table-wrapper`）无横向溢出；
  3. 名称单元格行数 ≤3 行（`scrollHeight / lineHeight` 估算），或 ellipsis 截切实效；
  4. 描述单元格行数 ≤3 行，或 ellipsis 截切实效。
- **预期**：通过（2026-11-02 修复后真实通过）。
- **修复记录（2026-11-02）**：原缺陷——名称/描述列无溢出处理，256 字符描述在 ~139px 列宽下折行约 13 行（单元格 scrollHeight=524px、行高 525px；64 字符名称 4 行 / 146px，探针实测）。修复：`Providers/index.vue` 名称/描述列 `ellipsis: true, tooltip: true`。**同批缺陷**：EM-LAY-02 / RT-LAY-01 / TM-LAY-01 / AC-LAY-01（详见覆盖缺口清单 §二十七）。
- **自动化**：`tests/providers/test_09_provider_layout_max_length.spec.js`

## PR-LAY-02 编辑抽屉满载布局（P1）

- **测试数据**：同 PR-LAY-01；打开该服务商编辑抽屉（名称/描述回显满载值）。
- **步骤**：
  1. 打开编辑抽屉，断言「名称」「描述」输入值等于满载值（回显正确是布局断言的前提）；
  2. 抽屉内容区（`.ivu-drawer-body`）无横向溢出；
  3. 底部按钮区（`ProviderUpsert.vue:303` `.com-btn-box.drawer-footer`，仅「提交」）完整落在视口内；
  4. 抽屉 X 关闭（未修改数据，无未保存拦截）。
- **预期**：真实通过（2026-11-02 定向通过）。
- **备注**：`ProviderUpsert` 底部**只有「提交」无「取消」**，关闭入口为抽屉 X——属既有设计，本用例顺带记录。
- **自动化**：`tests/providers/test_09_provider_layout_max_length.spec.js`
