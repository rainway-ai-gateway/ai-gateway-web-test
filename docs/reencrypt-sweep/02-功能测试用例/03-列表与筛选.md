### RS-L-04：按枚举过滤命中

**功能模块**: 密钥收敛列表
**优先级**: P1
**用例编号**: RS-L-04
**生命周期**: 已评审
**OpenAPI**: `GET /open-api/v1/security/reencrypt-sweeps`

#### 前置条件

1. 列表中存在覆盖 `status` / `mode` / `scope` / `dry_run` 各取值的任务样本。

#### 测试步骤

1. 将「任务状态」设为「成功」，核对请求与返回结果。
2. 依次将「变换方向」设为「解密」、「扫描范围」设为「仅 api_keys 表」、「预演模式」设为「是」，分别核对请求与结果。
3. 逐项核对结果集中每条记录均满足筛选条件。

#### 预期结果

1. 选择「成功」→ 请求携带 `status=succeeded`，返回 `list` 中每条任务 `status` 均为 `succeeded`。
2. 选择「解密」→ 请求携带 `mode=decrypt`，返回每条任务 `mode` 均为 `decrypt`。
3. 选择「仅 api_keys 表」→ 请求携带 `scope=api_keys`，返回每条任务 `scope` 均为 `api_keys`。
4. 选择「是」→ 请求携带 `dry_run=true`，返回每条任务 `dry_run` 均为 `true`。
5. 组合筛选（如 `status=succeeded` + `dry_run=true`）时，返回结果同时满足所有条件；`pagination.total` 为**过滤后**总数。
6. 无命中时表格展示空态「暂无历史任务。」（详见 RS-L-10）。

#### 测试数据

- **过滤值**：`status`∈{running,succeeded,failed}；`mode`∈{reencrypt,decrypt}；`scope`∈{all,providers,api_keys}；`dry_run`∈{true,false}

#### 补充说明

- **响应归因**：「重置」等动作可能连发多次列表请求，前一次动作的残留响应会先到达。自动化断言请求参数时必须按**本次动作的 query 谓词**（如 `mode=decrypt`）筛选响应，不能只等「下一条列表响应」，否则会抓到未生效的那一次（产品行为本身正确）。

### RS-L-05：时间范围过滤（含边界）

**功能模块**: 密钥收敛列表
**优先级**: P1
**用例编号**: RS-L-05
**生命周期**: 已评审
**OpenAPI**: `GET /open-api/v1/security/reencrypt-sweeps`

#### 前置条件

1. 列表中存在多条 `started_at` 不同的任务，且已知某条任务的确切 `started_at`（含时:分:秒）。

#### 测试步骤

1. 记录某条历史任务 `A` 的 `started_at`。
2. 「开始时间起」设置为 `A.started_at` 的同一时刻，「开始时间止」设置为同一时刻，点击「查询」。
3. 抓取请求参数并核对结果集是否包含边界任务。
4. 单独设置「开始时间起」为上界之后、「开始时间止」为下界之前，核对边界包含性。

#### 预期结果

1. 设置时间后请求携带 `start_time` / `end_time`，值为 **RFC3339** 格式（本地时间经转换，含时区）。
2. 过滤按 `started_at` 生效，**下界含**（`started_at >= start_time`）、**上界含**（`started_at <= end_time`）。
3. 当 `start_time == end_time == A.started_at` 时，结果集中**包含**任务 `A`（边界闭合）。
4. 仅设置一端（只填 `start_time` 或只填 `end_time`）时，另一端不参与过滤；`pagination.total` 为过滤后总数。
5. 结果行顺序遵循列表**默认排序** `sort_by=started_at`、`sort_order=desc`（较新任务在前）；断言结果集顺序时按 desc 排列，例如 `started_at >= 12:00` 命中 12:00 与 14:00 两条时顺序为「14:00 的行 → 12:00 的行」。

#### 测试数据

- **`start_time`**：RFC3339 下界（含）
- **`end_time`**：RFC3339 上界（含）

字段比对（校验方式 = 文本一致/数值一致/时间戳转换一致，与接口返回 JSON 一致）：

- **任务ID**（文本一致）：表格「任务ID」列 = `task_id`（原样文本，未截断）
