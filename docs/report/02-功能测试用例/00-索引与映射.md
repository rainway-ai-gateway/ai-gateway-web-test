# 数据报表模块 - 功能测试用例索引与映射

## 文档定位

本文档是数据报表（Report）模块功能测试用例的**索引与映射**，按**功能模块**组织测试用例，是对 [01-测试场景概览](../01-测试场景概览.md) 中用户使用场景的**功能拆解与详细描述**。每个用例包含完整的「前置条件、测试步骤、预期结果」，可直接用于手工执行或作为 Playwright 自动化用例的编写依据。

本模块本次变更范围为 **#5「报表缓存 / 镜像 / 意图新字段」**：明细表 +10 列、聚合表 +3 维度，报表消费 ai-cache / 流量镜像 / ai-intent 三组访问日志字段。字段与接口语义依据 `design-docs/api-define/OpenAPI接口定义/report.md`，UI 行为对齐 `src/modules/Report/index.vue`、`components/Overview.vue`、`components/Logs.vue`。

> 本索引已合并模块此前的旧版基线（旧版覆盖缓存 / 镜像 / 意图字段上线前的总览、明细与过滤交互）。旧版按 RP-O / RP-L / RP-D / RP-F 组织，其中过时用例已按源码校正后并入对应章节（RP-O-14~18、RP-L-16~23、RP-F-01~08），旧文件已删除；本版按 RP-O / RP-T / RP-R / RP-L / RP-V / RP-F 六类编排，编号含义以本索引为准。

> 本批次（2026-10-03，#5「报表 · 3 新维度 Doris 对齐」，见 [ui-code-changes.md](../../../../ai-gateway-web/design-docs/modifications/2026-10-03-ai-context-cache-semantic/ui-code-changes.md) §2.6 / §3.2 / §4.2 / §5）：三个新维度 `ai_intent_answer` / `ai_cache_status` / `mirror_hit` 由「仅 MySQL（Doris 返回 422）」改为**两后端均可用**；筛选栏 Doris 门控橙色提示（i18n `report.dorisNewDimHint`）与 `unneedTips` 静默逻辑一并移除；`mirror_hit` 排行 `0`/`1`、分布 `"0"`/`"1"` 桶语义不变。前置：接口层已放开两后端，但需 Doris 侧表结构先行升级。

> 本批次（2026-10-14，#6「报表图表维度下钻与过滤栏清理」，见 [ui-code-changes.md](../../../../ai-gateway-web/design-docs/modifications/2026-10-14-report-dimension-drilldown/ui-code-changes.md) §1 / §3 / §7）：总览图表暴露维度下钻（排行图 10 项维度下拉、两个饼图各 7 项维度下拉、过滤栏行尾「拆分维度」点查询生效）；总览过滤栏移除「缓存状态 / 镜像命中 / 意图答案」3 个死控件。新增 RP-T-09~14、RP-R-13~17、RP-F-09，共 12 条；阶段 4 收尾改写被本变更推翻前提的 RP-R-08 / RP-R-09 / RP-R-11 / RP-R-12（编号与优先级不变，RP-R-08 / RP-R-11 更名，见 §「Playwright 自动化映射表」下方执行结果）。
