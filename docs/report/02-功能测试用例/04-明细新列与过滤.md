## 4. 明细新列与过滤

### RP-L-01：明细新增缓存列

**功能模块**: 明细新列与过滤  
**优先级**: P0  
**用例编号**: RP-L-01  
**设计依据**: `Logs.vue` `columns` 中 `title: report.colCache`、`key: 'ai_cache_status'`、`width: 80`、`render: params.row.ai_cache_status || '-'`

#### 前置条件

- 以系统管理员登录，进入「数据报表」→「明细」页签
- 窗口内存在含缓存状态（`hit` / `miss` / `skip` / `''`）的明细记录

#### 测试步骤

1. 切换到「明细」页签，等待列表加载
2. 定位表格中标题为「缓存」的列
3. 对比列表值与接口返回的缓存状态

#### 预期结果

1. 明细表存在标题为「缓存」的列（i18n `report.colCache`），列宽 80
2. 单元格直接展示缓存状态原值（`hit` / `miss` / `skip`）
3. 该列位于「费用」列之后、「镜像」列之前
4. 空串 / null 时展示占位符 `-`

### RP-L-12：详情空值显示占位符
