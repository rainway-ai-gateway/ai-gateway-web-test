## 5. 字段校验与后端门控

### RP-V-01：起始结束时间必填

**功能模块**: 字段校验与后端门控  
**优先级**: P0  
**用例编号**: RP-V-01  
**设计依据**: `report.md` §1.1（`start` / `end` 必填）；`index.vue` `validateTimeRange()` / `applyFilters()`；`report.md` §3（参数缺失 → HTTP 422 / ErrNum 422）

#### 前置条件

- 进入「数据报表」页面；浏览器 DevTools Network 面板已打开

#### 测试步骤

1. 观察筛选栏「时间」区开始 / 结束时间是否已默认填充
2. 清空开始时间后点击「查询」
3. 清空结束时间后点击「查询」
4. 直接调用 `GET report/overview`，不传 `start` / `end`

#### 预期结果

1. 页面默认已填充 `start`（近 1 小时前）与 `end`（当前），默认快捷选项为「1 小时」
2. 清空开始或结束时间后点击「查询」，`validateTimeRange()` 判定 `!start || !end` 为真，弹出「查询时间范围不合法，请重新选择」（i18n `report.timeRangeInvalid`），不发起请求
3. 直接不传 `start` / `end` 调用接口时返回参数校验错误：HTTP 422（ErrNum 422）
4. 正常填写时请求 Query 携带秒级时间戳 `start` / `end`
