## 2. 路由规则详情

> 归属场景：场景二（查看详情）、场景三（编辑并提交生效）  
> 入口：路由表列表 → 点击「查看」

### 2.1 查看 Global 路由表详情

**功能模块**：路由规则详情  
**优先级**：P0  
**用例编号**：RT-D-01  
**设计依据**：`ai-gateway-web/design-docs/prototype-design/pages/route.html`

前置条件：

- 已进入路由表列表页，且 Global 路由表存在

测试步骤：

- 在 Global 路由表行点击「查看」按钮

预期结果：

- 页面切换为路由规则详情
- 面包屑显示 `路由规则 - Global / Global`
- 调用 `GET /open-api/v1/global-route-rules`
- 详情页初始为**查看模式**：
  - 不展示「添加规则」按钮
  - 表格操作列仅显示「查看」按钮
  - 启用状态下拉框禁用
- 表格展示规则名称、表达式、目标集群和模型、备用集群和模型

### 2.12 提交并生效（Global）

**功能模块**：路由规则详情  
**优先级**：P0  
**用例编号**：RT-D-12  
**设计依据**：`ai-gateway-web/design-docs/prototype-design/pages/route.html`

前置条件：

- 已进入 Global 路由表详情编辑模式，且已修改启用状态或规则

测试步骤：

- 修改规则或启用状态
- 点击「提交并生效」按钮

预期结果：

- 调用 `PUT /open-api/v1/global-route-rules`
- 请求体包含 `enabled` 和完整 `rules` 数组，例如：

```json
{
  "enabled": true,
  "rules": [
    {
      "name": "global-rule-01",
      "cond": "default_t()",
      "targets": [
        { "cluster_name": "cluster-A", "model": "", "weight": 100 }
      ],
      "fallbacks": []
    }
  ]
}
```

- 返回 200 后退出编辑模式，返回路由表列表并刷新
- Toast 提示成功

- 用户可继续修改后重新提交
