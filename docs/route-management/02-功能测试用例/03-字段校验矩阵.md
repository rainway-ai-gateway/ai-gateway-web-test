### 3.0 (cluster_name, model) 去重规则总则

> **验收依据**：当前 UI（`RuleForm.vue` 的 `validateTargetModelUnique` / `validateFallbackModelUnique`）与 `test_07_route_target_model_dedup.spec.js`；**不是**旧版「下拉过滤已选 ClusterName」。targets、fallbacks **各自列表内去重**，且 **targets ↔ fallbacks 之间跨列表合并去重**（同一 `(cluster_name, model)` 组合不得同时出现在目标与备用中）。

| 范围 | 规则 | 用例 | 本地保存 |
| ------ | ------ | ------ | ---------- |
| **targets 内** | 同一规则的目标行之间，`(cluster_name, model)` 不可重复；空 model 视为 `""` | RT-V-03-4 | 拦截，`route.targetDuplicate` |
| **fallbacks 内** | 同一规则的备用行之间，`(cluster_name, model)` 不可重复 | RT-V-12-1 B | 拦截，`route.fallbackDuplicate` |
| **targets ↔ fallbacks 之间** | 同一 `(cluster_name, model)` 组合**不可**同时出现在目标与备用中（跨列表合并校验） | RT-V-12-1 A | 拦截，`route.clusterModelUsedInFallback` / `route.clusterModelUsedInTarget` |
| **同 cluster_name 不同 model** | targets 内、或 target 与 fallback 之间均允许 | RT-V-03-3、RT-V-12-1 C | 保存成功 |
| **下拉行为** | 不再按已选 cluster_name 或 model 过滤；同集群、同 model 仍可被选中，重复组合由保存时 `validateDuplicate` 拦截 | RT-V-03-3、RT-V-12-1 B | — |

**已废弃**：

- **RT-V-03-1**：下拉隐藏已选 ClusterName → 见 §3.7c

### 3.15 目标+备用 (cluster_name, model) 组合去重

**功能模块**：字段校验  
**优先级**：P0  
**用例编号**：RT-V-12-1  
**设计依据**：`00-common.md` RouteRule；与 RT-V-03-4 **同一去重键**  
**去重维度**：`(cluster_name, model)`，空 model 视为 `""`  
**去重范围**：本地保存时 **fallbacks 内独立去重**（scenario B）；scenario A 验证 **targets ↔ fallbacks 跨列表合并去重**（同键拦截）；scenario C 验证同 cluster_name 不同 model 的合法对照  
**自动化**：`tests/route/test_07_route_target_model_dedup.spec.js`（scenario A、B、C）

> **修订说明（2026-08-17）**：当前 UI 为 **targets、fallbacks 各自列表内去重 + 跨列表合并去重**：同一 `(cluster_name, model)` 组合不得同时出现在 targets 与 fallbacks 中，拦截提示 `route.clusterModelUsedInFallback`（该组合已在备用集群中使用）/ `route.clusterModelUsedInTarget`（该组合已在目标集群中使用）。历史修订（2026-07-31 曾放宽为分列表校验）已随 UI 收紧失效。
>
> **修订说明（fallbacks 功能完善）**：去重维度为 `(cluster_name, model)`，fallbacks 内独立去重，与 targets 去重互不影响；fallbacks 行无 weight 字段。

前置条件：

- 已进入路由规则详情编辑模式，并打开规则编辑抽屉
- 集群 `test` 下存在 model `gpt-4`（或两行均留空 model）；scenario C 需至少两个 model

测试步骤：

**A. targets 与 fallbacks 相同键 — 拦截（跨列表合并校验）**

- 目标行 1：集群 `test`，model `gpt-4`（或均留空），权重 100
- 添加备用行 1：集群 `test`，model 与目标行相同
- 点击「本地保存」

**B. fallbacks 内重复**（**已自动化**，分两个子场景）

- **B1 仅 cluster_name 重复（model 留空）**
  - 目标行 1：集群 `prod`，model 留空，权重 100
  - 备用行 1、2：均选集群 `test`，model 均留空
  - 点击「本地保存」
- **B2 cluster_name + model 均重复**
  - 目标行 1：集群 `prod`，model `gpt-4`，权重 100
  - 备用行 1、2：均选集群 `test`，model 均选 `gpt-4`
  - 点击「本地保存」

**C. 合法对照 — 同集群不同 model**（**已自动化**）

- 目标行：集群 `test`，model `gpt-4`，权重 100
- 备用行：集群 `test`，model `gpt-3.5`（与目标不同）
- 点击「本地保存」

预期结果：

- **A**：拦截（`route.clusterModelUsedInFallback`：该组合已在备用集群中使用 / `route.clusterModelUsedInTarget`：该组合已在目标集群中使用；与 §3.0 一致）
- **B**：拦截（`route.fallbackDuplicate`）
- **C**：保存成功
