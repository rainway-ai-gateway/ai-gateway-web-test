## 6. 只读管理员视角（写操作隐藏）

> 变更依据：`design-docs/modifications/2026-10-12-readonly-admin/ui-code-changes.md`（已 Review 通过）。
> 后端以 `role` 枚举取代 `is_admin`（`system_admin` / `system_admin_readonly`）；只读视角（`role === 'system_admin_readonly'`）**全站隐藏所有写操作按钮**，仅保留只读入口（查看 / 详情 / 查询）。前端实现为全局指令 `v-has`：只读登录态下给挂载元素加 `.v-has-hidden { display:none !important; }`。
> 本模块依据变更记录 §3.4：`pages/route-tables.html` 只读视角仅保留「查看」；`pages/route.html` 只读视角保留「查看」，隐藏「添加规则 / 进入(退出)编辑 / 提交并生效」。

### RT-RO-01：路由表列表页只读视角仅保留查看

**功能模块**: 路由表列表
**优先级**: P0
**用例编号**: RT-RO-01
**OpenAPI**: `GET /route-tables`

#### 前置条件

1. 以**只读系统管理员**登录（`role=system_admin_readonly`），「路由管理 → 路由表列表」菜单可达。
2. 路由表列表存在 Global / Entity / API-Key 至少各一条记录。

#### 测试步骤

1. 进入「路由表列表」页面。
2. 观察列表工具栏与行尾「操作」列（含「查看」与「启用 / 停用」按钮）。
3. 逐项核对写操作入口的可见性。

#### 预期结果

1. 操作列**隐藏**「启用」「停用」等写操作按钮（对应 RT-L-10~RT-L-15 中管理员可见的启用 / 停用入口）。
2. 操作列**保留**「查看」只读入口，点击可进入路由规则详情页。
3. 列表仅保留检索 / 筛选 / 分页等只读控件，无任何新增 / 创建写入口。
4. 切换为系统管理员（`role=system_admin`）登录时，「启用 / 停用」按钮正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 管理员账号：`role=system_admin`
- 列表数据：Global / Entity / API-Key 类型各 ≥1 条

#### 补充说明

- 依据变更记录 §3.4：`pages/route-tables.html` 只读视角仅保留「查看」。隐藏实现为全局指令 `v-has`，只读视角加 `.v-has-hidden`；前端隐藏外，后端对写端点做 403 兜底。

### RT-RO-02：路由规则详情页只读视角工具栏写按钮隐藏

**功能模块**: 路由规则详情
**优先级**: P0
**用例编号**: RT-RO-02
**OpenAPI**: `GET /route-tables`、`GET /route-tables/{type}/{owner}`

#### 前置条件

1. 以**只读系统管理员**登录，从路由表列表进入某张路由表的规则详情页。
2. 该路由表已有至少一条规则。

#### 测试步骤

1. 进入路由规则详情页，观察页面工具栏按钮区。
2. 逐项核对「添加规则」「进入编辑模式」等写操作入口的可见性。
3. 观察页面当前所处的模式（视图 / 编辑）。

#### 预期结果

1. 工具栏**隐藏**「添加规则」写操作按钮（对应 RT-D-09 中管理员可见的添加入口）。
2. 工具栏**隐藏**「进入编辑模式」按钮，页面**恒停留视图模式**，不出现「退出编辑模式」。
3. 由于无法进入编辑模式，**不出现**「提交并生效」提交类写按钮（对应 RT-D-12~RT-D-14）。
4. 切换为系统管理员（`role=system_admin`）登录时，「添加规则」「进入编辑模式」「提交并生效」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 存在 ≥1 条规则的路由表（Global / Entity / API-Key 任一）

#### 补充说明

- 依据变更记录 §3.4：`pages/route.html` 只读视角隐藏「添加规则 / 进入(退出)编辑 / 提交并生效」。模式切换按钮与提交按钮挂全局指令 `v-has`。

### RT-RO-03：路由规则详情页只读视角规则行写按钮隐藏

**功能模块**: 路由规则详情
**优先级**: P0
**用例编号**: RT-RO-03
**OpenAPI**: `GET /route-tables/{type}/{owner}`

#### 前置条件

1. 以**只读系统管理员**登录，已进入路由规则详情页（视图模式）。
2. 规则列表存在至少一条规则。

#### 测试步骤

1. 进入路由规则详情页，观察规则列表每行行尾的「操作」列。
2. 逐项核对规则行写操作入口的可见性。
3. 点击规则行的「查看」入口。

#### 预期结果

1. 规则行操作列**隐藏**「编辑」「删除」等写操作按钮（对应 RT-D-10、RT-D-11）。
2. 规则行操作列**保留**「查看」只读入口，点击可打开规则详情（含 fallbacks 展示）。
3. 管理员视角下规则行操作列的「编辑」「删除」正常显示（对照组）。

#### 测试数据

- 只读账号：`role=system_admin_readonly`
- 存在 ≥1 条规则（含 fallbacks 更佳）的路由表

#### 补充说明

- 依据变更记录 §3.4：`pages/route.html` 只读视角仅保留「查看」只读入口，规则行的编辑 / 删除写按钮隐藏；render 操作列写按钮加 `directives: [{ name: 'has' }]`。
