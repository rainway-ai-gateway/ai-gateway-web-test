## RT-LAY-01 规则名满载行布局（P1）

- **测试数据**：编辑模式「添加规则」本地保存（不写后端）；afterEach `restoreRouteTestData` 还原。**规则名取满载 64 字符**（路由规则名上限 1–64，RT-V-14 / `RuleForm.vue` `min:1, max:64`——与流量镜像/AI 缓存的 128 不同，勿混用）。
- **步骤**：
  1. 编辑模式本地保存规则名 64 字符（表达式 `default_t()` + 目标集群/模型/权重）；
  2. 规则表格容器无横向溢出；
  3. 规则名单元格（第 1 列）行数 ≤3 行，或 ellipsis 截切实效。
- **预期**：通过（2026-11-02 修复后真实通过）。
- **修复记录（2026-11-02）**：原缺陷——64 字符规则名在 ~120px 列宽下折行约 4 行（scrollHeight=83px / lineHeight=21px，实测）。修复：`RouteRules.vue` 规则名列 `ellipsis: true` + render span `.cell-ellipsis` + `title` 悬浮全文。**同批缺陷**：EM-LAY-02 / PR-LAY-01 / TM-LAY-01 / AC-LAY-01（iView 表格单元格 `white-space:normal; word-break:break-all` 且长文本列未配 ellipsis，详见覆盖缺口清单 §二十七）。
- **自动化**：`tests/route/test_13_route_layout_max_length.spec.js`
