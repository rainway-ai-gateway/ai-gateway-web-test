# 流量镜像规则 - 测试场景概览

## 模块概述

流量镜像规则模块负责 AI 网关「流量镜像」（shadow traffic）集合级规则的配置。生产请求正常转发的同时，把请求副本按规则异步发往镜像目标集群，响应读空丢弃、仅入统计。集合级全量读写，**不提供单条规则接口**。

|功能区域|说明|
|---|---|
|集合级规则列表|以 pageTable 展示规则名称、生效条件、镜像集群、采样比例、头部剔除、路径改写 7 列，支持按名称/条件/集群搜索与列排序；视图模式下行操作仅「查看」|
|视图/编辑双模式|右上角「进入编辑模式」进入编辑态，可新增/编辑/删除规则，并以「提交并生效」全量提交；退出编辑时有未提交改动的二次确认与回滚|
|规则抽屉（新增/编辑）|RuleForm 配置规则名称、生效条件、镜像集群、采样比例、头部剔除三态、设置请求头、请求体改写、路径改写；「本地保存」写入内存集合，「重置」恢复|
|规则抽屉（查看）|RuleView 为纯文案只读展示，不含输入控件，也无必填星号|
|集合提交|PUT /traffic-mirror-rules 整组替换；数组顺序即优先级（first-match-wins）；`{"rules":[]}` 表示清空全部规则（镜像总开关关闭）|

导航路径：路由管理 → 功能增强 → 流量镜像规则（页面路由名 `TrafficMirrorRule.list`）。

- **优先顺序**：集合内规则按数组顺序匹配，**首条命中生效**（first-match-wins）；不支持 `priority` 字段。
- **单条停用方式**：集合无 `enabled` 字段，「删除规则」= 从集合移除后提交；单条临时停用 = 采样比例 `0`（命中但不采样）。
- **提交生效**：「提交并生效」写入整组规则；生效时延 = conf-agent 轮询周期 + BFE 热加载时间。

## 配置顺序

流量镜像依赖已存在的镜像目标集群；规则集合本身为单例，无需逐条创建。

```text
集群（镜像目标，控制面已创建）
        │
        ▼
路由管理 → 功能增强 → 流量镜像规则
        │
        ▼
进入编辑模式 → 添加规则（名称 / 生效条件 / 镜像集群 / 采样比例 / 头部剔除 / 设置请求头 / 请求体改写 / 路径改写）→ 提交并生效
```

- **镜像集群**：下拉选项来自 `GET clusters`（仅取 `name`）；规则引用不存在的集群由服务端校验（不存在 → 422）。
- **规则集合**：进入编辑模式后才可新增/编辑/删除；退出编辑模式时若有未提交改动将二次确认并回滚。
- **查看详情**：视图模式下点击行「查看」打开纯文案抽屉；编辑模式下无「查看」入口。
