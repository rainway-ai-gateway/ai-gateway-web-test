## 4. 字段校验矩阵

本章汇总流量镜像规则表单的字段校验规则，并与 OpenAPI 接口约束逐项对照。校验分两层：前端 `RuleForm.vue` 的 `ruleValidate` 与 `handleSubmit` 拦截为**第一道**，服务端接口约束（如引用校验）为**第二道兜底**。

### 字段校验索引

|模块|字段/场景|校验规则|错误提示|用例编号|
|---|---|---|---|---|
|规则名称|必填|trim 后非空|请输入规则名称|TM-V-01|
|规则名称|长度|1-128 字符（length>128 报错，非 maxlength）|规则名称长度应为 1-128 字符|TM-V-02|
|规则名称|唯一性|集合内唯一（排除自身）|规则名称已存在，集合内必须唯一|TM-V-03|
|生效条件|必填|非空且无编译错误|请填写生效条件|TM-V-04|
|生效条件|唯一性|集合内唯一（排除自身）|生效条件重复，集合内必须唯一|TM-V-05|
|生效条件|全量匹配|须显式 `default_t()`|（标签提示）全量匹配请显式使用 default_t()|TM-V-06|
|镜像集群|必填|选中非空|请选择镜像集群|TM-V-07|
|镜像集群|引用校验|服务端校验存在性|不存在返回 422|TM-V-08|
|采样比例|范围|0-100 的整数|采样比例必须为 0-100 的整数|TM-V-09|
|采样比例|边界语义|0 合法=命中不采样|（无错误）|TM-V-10|
|头部剔除|自定义元素|元素非空（trim 后过滤空项）|自定义剔除列表不能为空|TM-V-11|
|设置请求头|KV 非空|key 与 value trim 后均非空|设置请求头的名称与值均不能为空|TM-V-12|
|设置请求头|保留头|不建议配置 X-Bfe-Mirror|（无拦截，规范建议）|TM-V-13|
|请求体改写|值非空|value trim 后非空|请求体改写的值不能为空|TM-V-14|
|请求体改写|路径|一期仅允许 model|（下拉仅 model）|TM-V-15|
|路径改写|前缀|非空须以 `/` 开头|路径改写必须以 / 开头|TM-V-16|
|路径改写|留空|空串/缺省=不改写|（无错误）|TM-V-17|

### OpenAPI 对照索引

|字段|OpenAPI 约束|UI 校验|触发时机|用例编号|
|---|---|---|---|---|
|name|必填，1-128 字符，集合内唯一|validateName（trim 判空 + length>128）+ onFormSubmit/submitRules 集合内查重|blur / 提交|TM-V-01/02/03|
|cond|必填，全匹配须显式 default_t()，集合内不得重复|validateCond（condErrmsg 优先）+ 集合内查重|change / 提交|TM-V-04/05/06|
|mirror_cluster|必填，1-128 字符，引用校验（不存在 422）|required + 下拉仅列集群 name|change / 服务端 422|TM-V-07/08|
|percentage|非必填，默认 100，0-100|validator（空/越界报错）+ InputNumber(0-100)|change|TM-V-09/10|
|remove_headers|非必填，元素非空|headerMode=custom 时 split→trim→filter(Boolean)|提交（本地保存）|TM-V-11|

|path_rewrite|非必填，空串/缺省=不改写，非空须以 / 开头|validator（trim 后首字符为 /）|blur|TM-V-16/17|

### TM-V-17：路径改写留空表示不改写

**功能模块**: 字段校验
**优先级**: P1
**用例编号**: TM-V-17
**设计依据**: `RuleForm.vue ruleValidate.path_rewrite`（`text && text.charAt(0) !== '/'`）、OpenAPI path_rewrite（空串/缺省=不改写）

#### 前置条件

- 已进入编辑模式并打开新增抽屉

#### 测试步骤

1. 路径改写保持为空，点击「本地保存」
2. 路径改写仅填入空格，失焦并提交
3. 观察提交体路径改写值

#### 预期结果

1. 路径改写为空时校验通过（非必填），语义为**不改写**请求路径

3. 提交体路径改写为 trim 后的空串 `""`，服务端按不改写处理
4. 与「非空须以 / 开头」互斥：非空才触发斜杠前缀校验（见 TM-V-16）
