# 用户管理模块 - 功能测试用例

## 文档定位

本文档按**功能模块**组织测试用例，是对[01-测试场景概览](../01-测试场景概览.md)中用户使用场景的**功能拆解与详细描述**。功能用例（UM-xx）与场景串联用例（RT-J-01、EM-J-01 复用）共同支撑完整覆盖。

## 与场景概览的映射关系

| 01中的使用场景 | 涉及的功能模块 | 场景编号范围 | 场景数量 |
|--------------|--------------|------------|---------|
| 场景一: 管理员入职新员工 | 用户管理主页面、添加用户、登录认证 | UM-01~UM-10, UM-32, UM-36~38 | 14个 |
| 场景二: 管理员日常用户维护 | 用户管理主页面、修改密码、删除用户 | UM-02, UM-11~UM-19, UM-14-2 | 11个 |
| 场景三: 管理员配置API访问凭证 | Token管理 | UM-21~UM-31、UM-39~40 | 13个 |
| 场景四: 用户登录与退出 | 登录认证、注销功能 | UM-32~33、UM-33-2、UM-34~35 | 5个 |
