## 1. 用户管理主页面

> **归属场景**: 场景一(管理员入职新员工)、场景二(管理员日常用户维护)

### 1.1 用户列表展示

**功能模块**: 用户管理主页面  
**优先级**: P1  
**用例编号**: UM-01

#### 前置条件

- 系统已正常运行
- 已使用管理员账号登录系统
- 系统中已存在至少一个用户

#### 测试步骤

1. 打开浏览器，访问AI网关管理控制台
2. 在左侧导航栏中，找到并点击"用户管理"菜单项
3. 观察页面加载情况
4. 查看页面中间区域的用户列表表格

#### 预期结果

- 页面成功加载，显示"用户管理"标题
- 页面顶部显示两个Tab页签："用户"和"Token"，默认选中"用户"Tab
- 左侧显示蓝色"添加用户"按钮
- 下方显示搜索框，占位文字为"请输入用户查询"
- 用户列表表格正确显示，包含以下列：
  - 用户列：显示用户名（如admin）
  - 角色列：显示用户角色（如"系统管理员"）
  - 操作列：包含"修改密码"（蓝色按钮）和"删除"（红色按钮）
- 页面底部显示分页控件，包含：
  - 每页显示条数下拉框（默认"20条/页"）
  - 页码导航按钮（上一页、页码、下一页）
- 列表中的用户信息与数据库中存储的数据一致
- **长文本布局**：表格列长文本截断或折行，不撑破列宽

#### 测试数据

- 用户名：admin
- 角色：系统管理员

#### 备注

- 需要验证列表是否支持排序功能（如有排序图标）
- 验证空数据状态下的页面展示（如系统中无任何用户）

---

### 1.2 用户搜索功能

**功能模块**: 用户管理主页面  
**优先级**: P1  
**用例编号**: UM-02

#### 前置条件

- 已登录系统并进入用户管理页面
- 系统中存在多个用户（至少2个不同用户名）

#### 测试步骤

1. 在用户管理页面的搜索框中，输入已存在用户的部分用户名（如"adm"）
2. 观察列表变化
3. 清空搜索框内容，再次观察列表变化
4. 输入不存在的用户名（如"testuser999"）
5. 观察列表变化

#### 预期结果

- 步骤2：列表实时过滤，仅显示用户名包含"adm"的用户记录
- 步骤3：列表恢复显示所有用户
- 步骤5：列表显示为空，或提示"未找到匹配的用户"
- 搜索过程中页面不刷新，实现实时过滤或回车后过滤

#### 测试数据

- 搜索关键字1：adm（部分匹配）
- 搜索关键字2：admin（完全匹配）
- 搜索关键字3：testuser999（不存在的用户）

#### 备注

- 验证搜索是否支持模糊匹配
- 验证搜索是否区分大小写
- 验证搜索结果数量较大时的分页显示

### 1.3 分页功能

**功能模块**: 用户管理主页面  
**优先级**: P1  
**用例编号**: UM-03

#### 前置条件

- 已登录系统并进入用户管理页面
- 系统中用户数量超过20个

#### 测试步骤

1. 查看页面底部的分页控件显示
2. 点击第2页页码按钮
3. 观察列表内容和页码高亮状态
4. 点击"下一页"按钮
5. 点击"上一页"按钮
6. 点击"每页显示条数"下拉框，选择"50条/页"
7. 观察列表和分页控件变化

#### 预期结果

- 步骤1：分页控件显示总页数、当前页码（高亮）、上一页/下一页按钮
- 步骤2：列表显示第2页的用户数据，页码"2"高亮显示
- 步骤3：列表显示第3页数据（如有），对应页码高亮
- 步骤4：列表显示第2页数据，页码"2"高亮
- 步骤5：列表每页显示50条记录，总页数减少
- 分页切换过程中页面数据正确加载，无报错

#### 测试数据

- 用户总数：> 20个
- 每页显示条数：20条、50条

#### 备注

- 验证最后一页数据较少时的显示
- 验证快速翻页时的数据加载稳定性
