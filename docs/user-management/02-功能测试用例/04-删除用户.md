## 4. 删除用户

> **归属场景**: 场景二(管理员日常用户维护)

### 4.1 删除用户-成功场景

**功能模块**: 删除用户  
**优先级**: P0  
**用例编号**: UM-18

#### 前置条件

- 已登录系统并进入用户管理页面
- 用户列表中存在需要删除的用户（非当前登录用户）

#### 测试步骤

1. 在用户列表中找到目标用户
2. 点击该用户操作列中的"删除"红色按钮
3. 页面中间弹出"信息提示"确认对话框
4. 确认对话框内容显示："是否删除用户{用户名}？"
5. 点击对话框中的"确定"蓝色按钮
6. 观察对话框是否关闭
7. 在搜索框中输入刚删除的用户名进行搜索
8. 验证用户是否从列表中消失

#### 预期结果

- 步骤3：弹出模态确认对话框，背景变灰
- 步骤4：对话框标题为"信息提示"，带有黄色问号图标
- 步骤5：点击"确定"后
- 步骤6：对话框关闭
- 步骤7-8：搜索结果显示为空，用户已从列表中删除
- 页面可能显示成功提示信息
- 该用户无法再登录系统
- **确认弹窗**：弹窗包含超长用户名时文案正常展示，按钮可点击

#### 测试数据

- 目标用户：之前创建用于测试的用户

#### 备注

- 验证删除操作是否可撤销
- 验证删除后相关数据（如Token）的处理

### 4.2 删除用户-取消操作

**功能模块**: 删除用户  
**优先级**: P1  
**用例编号**: UM-19

#### 前置条件

- 已登录系统并进入用户管理页面
- 用户列表中存在用户

#### 测试步骤

1. 在用户列表中找到目标用户
2. 点击该用户操作列中的"删除"红色按钮
3. 页面中间弹出"信息提示"确认对话框
4. 点击对话框中的"取消"按钮
5. 观察对话框是否关闭
6. 验证用户是否仍在列表中

#### 预期结果

- 步骤4：点击"取消"按钮后
- 步骤5：对话框关闭，页面恢复正常状态
- 步骤6：用户仍在列表中，未被删除
- 用户可以继续正常使用

#### 测试数据

- 目标用户：列表中存在的用户

#### 备注

- 验证取消操作无副作用
- 验证可以再次尝试删除
