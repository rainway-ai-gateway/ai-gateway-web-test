**功能模块**: Token管理  
**优先级**: P1  
**用例编号**: UM-21

#### 前置条件

#### 测试步骤

1. 点击页面顶部的"Token" Tab页签
2. 页面切换到Token管理界面
3. 观察页面加载情况
4. 查看Token列表展示

#### 预期结果

- 步骤2：页面显示Token管理界面，包含Token列表和创建按钮
- 步骤4：列表正确展示Token信息，包含名称、scope、操作列（详情、删除）
- 页面顶部显示提示信息："Token 是内部程序访问APIServer的鉴权凭证，请按需创建，谨慎删除"
- 分页控件正常显示（默认20条/页）
- **长文本布局**：表格列长文本截断或折行，不撑破列宽

#### 测试数据

#### 备注

- 验证空列表状态下的页面展示
- 验证列表字段显示是否完整

### 5.2 Token-创建成功

**功能模块**: Token管理  
**优先级**: P0  
**用例编号**: UM-22

#### 前置条件

- 已登录系统并进入Token管理页面

#### 测试步骤

1. 点击"创建"蓝色按钮
2. 页面右侧弹出Token创建抽屉面板
3. 在"名称"输入框中输入：token_20260702203000
4. 在"角色"下拉框中选择：系统管理
5. 点击"提交"蓝色按钮
6. 观察抽屉面板是否关闭
7. 在Token列表中查找刚创建的Token

#### 预期结果

- 步骤2：右侧弹出Token创建抽屉，标题为"创建Token"，右上角有关闭按钮（X）
- 步骤5：提交成功，抽屉面板自动关闭
- 步骤6-7：Token列表中显示新创建的Token，名称和角色信息正确
- 页面可能显示Token的密钥信息（仅显示一次）
- **表单标签**：长标签文本折行或截断，不与输入框重叠；下拉框选项文本截断或折行，不溢出下拉面板

#### 测试数据

- Token名称：token_20260702203000
- 角色：系统管理

#### 备注

- Token密钥可能仅创建时显示一次，注意保存
- 验证Token名称的唯一性要求

### 5.8 Token-删除成功

**功能模块**: Token管理  
**优先级**: P1  
**用例编号**: UM-28

#### 前置条件

- 已登录系统并进入Token管理页面
- Token列表中存在需要删除的Token

#### 测试步骤

1. 在Token列表中找到目标Token
2. 点击该Token操作列中的"删除"按钮
3. 页面弹出确认对话框，确认对话框内容显示："是否删除{token名称}？"
4. 点击"确定"按钮
5. 观察对话框是否关闭
6. 在Token列表中查找该Token

#### 预期结果

- 步骤3：弹出模态确认对话框
- 步骤4：点击"确定"后
- 步骤5：对话框关闭
- 步骤6：Token从列表中消失，删除成功
- 该Token失效，无法再用于API调用
- **确认弹窗**：弹窗包含超长Token名称时文案正常展示，按钮可点击

#### 测试数据

- 目标Token：之前创建用于测试的Token

#### 备注

- 验证删除后Token是否立即失效
- 验证删除操作是否可撤销
