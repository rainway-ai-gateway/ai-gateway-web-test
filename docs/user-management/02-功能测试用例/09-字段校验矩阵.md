### 9.2 Password 规则（新版 OpenAPI）

| 规则 | 说明 |
|------|------|
| 长度 | 8–128 字符 |
| 空白 | 不得含空白字符（空格、制表符等） |
| 与用户名关系 | 不得等于 `user_name`；不得等于 `user_name` 的字符逆序（不区分大小写） |
| 合规示例 | `password123`、`MySecure8` |
| 不合规示例 | `1234567`（过短）、含空格的 `pass word123`、`admin12345`（当用户名为 `54321nimda` 时等于逆序） |

### 9.3 UserName / TokenName 规则

| 类型 | 长度 | 字符集 | 首尾限制 | 保留名 |
|------|------|--------|----------|--------|
| UserName | 1–64 | `[A-Za-z0-9._-]` | 不得以 `.`、`-`、`_` 开头或结尾 | `admin`、`root`、`system` |
| TokenName | 1–64 | 同上 | 同上 | `admin`、`system`、`default` |
