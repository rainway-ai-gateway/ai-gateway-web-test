# 全量回归报告归档

本目录归档每一轮**全量回归**的报告，受版本控制、可长期引用；每轮生成一份，不覆盖历史。

- **命名**：`TEST-REPORT-YYYY-MM-DD.md`；同一天第二次全量回归追加 `-HHmmss`（如 `TEST-REPORT-2026-10-17-233755.md`）。
- **生成**：跑完全量后执行 `npm run report:tracked`（脚本 `scripts/aggregate-report.js`）；定向批次不会写入本目录。
- **最新**：下表第一行即最近一次全量回归；历史归档只读不改。
